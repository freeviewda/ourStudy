# y_train.value_counts - AI 파이썬 학습 노트

파이썬 머신러닝 데이터 분석에서 데이터의 균형을 확인할 때 자주 쓰이는 `y_train.value_counts()` 함수에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 하나씩 친절하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`y_train.value_counts()`는 판다스(Pandas) 데이터 구조에서 **각 고유한 값(데이터)이 몇 번 등장하는지(빈도수)를 세어주는 함수**입니다. 주로 머신러닝에서 정답 데이터(Label)인 `y_train`의 클래스(범주)별 개수가 골고루 잘 들어있는지(클래스 불균형이 없는지) 확인할 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `y_train.value_counts()`를 보면, 괄호 `()` 안에 **아무런 값도 전달되지 않은 것**을 볼 수 있습니다. 

* **인자가 없는 이유:** 기본적으로 이 함수는 `y_train` 안에 있는 모든 데이터의 종류를 알아서 파악하고, 각 데이터가 나온 개수를 자동으로 전부 세어주기 때문에 별도의 설정값이 필요 없습니다.
* **(참고) 자주 쓰이는 숨겨진 옵션들:** 만약 필요하다면 다음과 같은 옵션을 괄호 안에 넣을 수도 있습니다.
  * `ascending=True`: 개수가 적은 것부터 오름차순으로 정렬 (기본값은 개수가 많은 것부터 내림차순인 `False`)
  * `normalize=True`: 개수 대신 전체 데이터 대비 **비율(백분율)**로 출력

---

### 3. 📤 반환값/할당 변수
이 코드는 별도의 변수에 값을 저장하지 않고, `print()` 함수 안에서 바로 문자열로 변환되어 출력됩니다.

* **반환되는 데이터 형태:** 판다스 **시리즈(Series)** 형태로 반환됩니다.
  * **왼쪽(인덱스):** `y_train`에 들어있던 고유한 값들 (예: 고양이, 강아지 / 또는 0, 1)
  * **오른쪽(값):** 그 값이 각각 몇 개나 존재하는지 나타내는 숫자(빈도수)
* **출력 결과 예시:**
  ```text
  Train 클래스 분포:
  0    700
  1    300
  Name: count, dtype: int64
  ```
  *(해석: `0`이라는 정답 데이터가 700개, `1`이라는 정답 데이터가 300개 들어있다는 뜻입니다.)*

---

### 4. 🎁 요약 및 실행 예시
백문이 불여일견! 초보자분들이 주피터 노트북이나 파이썬 환경에서 직접 복사해서 실행해 볼 수 있는 간단한 코드입니다.

**[실습 코드]**
```python
import pandas as pd

# 1. 정답 데이터(y_train) 역할을 하는 판다스 시리즈 생성
# (여기서는 사과, 바나나, 바나나, 사과, 사과가 들어있다고 가정해 봅시다)
y_train = pd.Series(['사과', '바나나', '바나나', '사과', '사과'])

# 2. value_counts() 함수 호출 및 출력
print(f"\nTrain 클래스 분포:\n{y_train.value_counts()}")
```

**[예상 결과]**
```text
Train 클래스 분포:
사과    3
바나나    2
dtype: int64
```
> **Tip:** 결과창을 보니 '사과'는 3개, '바나나'는 2개 들어있다는 것을 한눈에 쉽게 파악할 수 있죠? 이처럼 데이터 분석 전 내가 가진 데이터의 쏠림 현상을 확인할 때 유용하게 쓰이는 필수 함수입니다!

# GridSearchCV - AI 파이썬 학습 노트

---

파이썬 머신러닝 라이브러리인 Scikit-Learn(사이킷런)에서 사용하는 `GridSearchCV` 함수에 대해 초보자의 눈높이에 맞춰 쉽고 명쾌하게 해설해 드리겠습니다.

---

### 1. 📌 함수 개요
`GridSearchCV`는 **머신러닝 모델의 성능을 가장 높여주는 최적의 하이퍼파라미터(사람이 직접 설정해야 하는 설정값)를 찾아주는 마법 같은 도구**입니다. 우리가 일일이 모델을 만들고 테스트해 볼 필요 없이, 후보로 지정한 여러 파라미터 조합들을 자동으로 전부 테스트한 뒤 가장 좋은 조합을 찾아줍니다.

---

### 2. 🔍 입력 인자(매개변수) 분석

제시해주신 코드에 사용된 6가지 인자의 의미는 다음과 같습니다.

*   **`rf_clf` (첫 번째 위치 인자)**
    *   **의미**: 최적화를 수행할 기본 머신러닝 모델 (여기서는 Random Forest Classifier 모델)
    *   **설명**: "이 모델을 가지고 가장 좋은 성능을 내는 튜닝을 해줘"라고 대상 모델을 지정해 주는 것입니다.
*   **`param_grid`**
    *   **의미**: 테스트해 볼 파라미터들의 후보 목록 (딕셔너리 형태로 전달)
    *   **설명**: 예를 들어 `{'n_estimators': [10, 50, 100], 'max_depth': [3, 5]}`와 같이 전달하면, 이 조합들(총 6가지 경우의 수)을 모두 대입해 보며 어떤 것이 가장 성능이 좋은지 실험합니다.
*   **`cv=StratifiedKFold(5)`**
    *   **의미**: 교차 검증(Cross Validation)을 수행할 방식과 폴드(데이터를 나누는 조각) 수
    *   **설명**: 데이터를 5개 조각으로 나누어 4개 조각은 학습에, 1개 조각은 테스트에 사용하는 과정을 5번 반복합니다. 특히 `StratifiedKFold`는 정답(레이블)의 비율이 골고루 유지되도록 데이터를 나눕니다.
*   **`scoring='accuracy'`**
    *   **의미**: 모델의 성능을 평가할 기준 (평가지표)
    *   **설명**: 모델이 얼마나 정확하게 맞혔는가(**정확도**)를 기준으로 가장 성능이 좋은 파라미터 조합을 평가하겠다는 뜻입니다. (이외에도 'f1', 'roc_auc' 등으로 변경 가능)
*   **`n_jobs=-1`**
    *   **의미**: 연산에 사용할 컴퓨터 CPU 코어의 개수
    *   **설명**: `-1`은 **"내 컴퓨터에 있는 모든 CPU 코어를 총동원해서 빠르게 계산해 줘!"**라는 뜻입니다. 데이터가 많을 때 시간을 엄청나게 단축해 줍니다.
*   **`verbose=1`**
    *   **의미**: 학습 과정의 출력(로그)을 얼마나 자세히 보여줄 것인가
    *   **설명**: `1`로 설정하면 코드가 실행되는 동안 "지금 몇 번째 실험을 하고 있는지" 진행 상황을 터미널 창에 간단하게 출력해 줍니다. (0이면 아무 말 없이 조용히 실행됨)

---

### 3. 📤 반환값/할당 변수

*   **할당된 변수: `grid_clf`**
    *   **의미**: 설정이 완료된 `GridSearchCV` 객체(물건)가 변수에 담깁니다.
    *   **설명**: 이 시점에서는 아직 최적의 파라미터를 찾은 것이 아닙니다. 이후에 `grid_clf.fit(X_train, y_train)` 코드를 실행해야 비로소 내부적으로 모든 조합을 테스트하고 최적의 학습을 마칩니다. 
    *   학습이 끝난 뒤에는 `grid_clf.best_params_`로 가장 좋은 파라미터를 확인하거나, `grid_clf.predict()`로 바로 예측을 수행할 수도 있습니다.

---

### 4. 🎁 요약 및 실행 예시

초보자분들이 전체 흐름을 이해할 수 있도록 가장 간단한 전체 실행 예시 코드를 보여드립니다.

```python
from sklearn.datasets import load_iris
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import GridSearchCV, StratifiedKFold
from sklearn.model_selection import train_test_split

# 1. 데이터 불러오기 및 나누기
iris = load_iris()
X_train, X_test, y_train, y_test = train_test_split(
    iris.data, iris.target, random_state=42
)

# 2. 기본 모델 생성
rf_clf = RandomForestClassifier(random_state=42)

# 3. 테스트할 파라미터 후보 설정
param_grid = {
    'n_estimators': [10, 50, 100],  # 나무의 개수 후보
    'max_depth': [None, 3, 5],  # 나무의 최대 깊이 후보
}

# 4. GridSearchCV 설정 (질문하신 바로 그 코드!)
grid_clf = GridSearchCV(
    rf_clf,
    param_grid,
    cv=StratifiedKFold(5),
    scoring='accuracy',
    n_jobs=-1,
    verbose=1,
)

# 5. 최적의 파라미터 찾기 (학습 시작!)
grid_clf.fit(X_train, y_train)

# 6. 결과 확인
print('가장 좋은 파라미터 조합:', grid_clf.best_params_)
print('최고 정확도 스코어:', grid_clf.best_score_)
```

**💡 한 줄 요약:**
`GridSearchCV`는 **"내가 지정해 준 여러 옵션(파라미터) 조합 중, 컴퓨터의 모든 코어(`n_jobs=-1`)를 써서 5겹 교차 검증(`cv`)을 통해 가장 정확도(`scoring='accuracy'`)가 높은 최고의 세팅을 찾아주는 똑똑한 도구"**입니다!

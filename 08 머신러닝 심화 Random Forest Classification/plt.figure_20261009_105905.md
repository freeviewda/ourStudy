파이썬의 데이터 시각화 라이브러리인 **Matplotlib**에서 가장 자주 쓰이는 `plt.figure()` 함수에 대해 초보자의 눈높이에 맞춰 친절하고 명쾌하게 해설해 드리겠습니다.

---

### 1. 📌 함수 개요
`plt.figure()`는 새로운 도화지(캔버스)를 생성하는 함수입니다. 파이썬에서 그래프를 그리기 전에 "여기에 새로운 그림을 그릴 것이다"라고 판을 깔아주는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `plt.figure(figsize=(6, 4))`에 사용된 인자의 역할은 다음과 같습니다.

*   **`figsize` (도화지 크기 설정)**
    *   **설정값:** `(6, 4)`
    *   **상세 설명:** 생성할 도화지의 가로, 세로 크기를 인치(inch) 단위로 지정합니다. 
        *   숫 `6`: 가로 길이 (6인치)
        *   숫자 `4`: 세로 길이 (4인치)
    *   이 값을 조절하면 화면에 출력되는 그래프의 전체적인 비율과 크기를 키우거나 줄일 수 있습니다. (예: 널찍한 그래프를 원하면 `figsize=(10, 5)`처럼 설정합니다.)

---

### 3. 📤 반환값/할당 변수
질문하신 코드 `plt.figure(figsize=(6, 4))`에는 별도의 변수가 앞에 할당되지 않았습니다. 

*   **동작 방식:** 이 경우, Matplotlib 내부의 현재 작업 공간(Current Figure)에 직접 도화지가 생성됩니다.
*   **응용 (참고):** 나중에 도화지를 정교하게 다루고 싶을 때는 다음과 같이 변수에 담아 사용하기도 합니다.
    ```python
    fig = plt.figure(figsize=(6, 4))  # fig 변수에 도화지(Figure) 객체가 저장됨
    ```

---

### 4. 🎁 요약 및 실행 예시
초보자분이 직접 복사해서 실행해 볼 수 있는 가장 간단한 그래프 그리기 코드입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 6x4 크기의 도화지 생성
plt.figure(figsize=(6, 4))

# 2. 데이터 준비 및 그래프 그리기
x = [1, 2, 3, 4]
y = [10, 20, 25, 30]
plt.plot(x, y, marker='o')

# 3. 그래프 제목과 눈금 설정
plt.title("My First Graph")
plt.xlabel("X Axis")
plt.ylabel("Y Axis")

# 4. 화면에 출력하기
plt.show()
```

**[예상 결과]**
*   가로 6인치, 세로 4인치 비율의 아담하고 보기 좋은 크기의 그래프 창(또는 주피터 노트북 출력 결과)이 뜹니다.
*   안에는 (1,10), (2,20), (3,25), (4,30)을 잇는 선 그래프가 파란색 선과 동그란 점(`marker='o'`)으로 그려지게 됩니다.

# optuna.create_study - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 22:55:37

---

파이썬의 머신러닝/딥러닝 최적화 라이브러리인 **Optuna**에서 사용되는 `optuna.create_study` 함수에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 쉽고 명쾌하게 정리해 드릴게요!

---

### 1. 📌 함수 개요
`optuna.create_study`는 **인공지능 모델의 성능을 가장 좋게 만드는 최적의 하이퍼파라미터(설정값)를 찾기 위한 '연구(Study) 공간'을 생성하는 함수**입니다. 이 함수를 호출하면 앞으로 진행될 최적화 실험들을 기록하고 관리할 수 있는 빈 노트(Study 객체)가 만들어진다고 생각하시면 됩니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제공해주신 코드에서 사용된 인자는 다음과 같습니다.

*   **`direction='maximize'`**
    *   **역할:** 우리가 최적화하려는 목표(Objective)의 방향을 설정합니다.
    *   **설정값의 의미:** `'maximize'`는 우리가 찾는 값(예: 정확도(Accuracy), 점수 등)을 **'최대화'**하겠다는 뜻입니다. (반대로 오차를 줄이는 것이 목적이라면 `'minimize'`를 사용합니다.) 즉, "점수가 높을수록 좋은 거야!"라고 Optuna에게 알려주는 설정입니다.

---

### 3. 📤 반환값/할당 변수
*   **할당 변수: `study`**
    *   **데이터 종류:** `optuna.study.Study` 객체
    *   **의미:** 함수가 생성한 '연구(Study) 공간' 전체가 이 변수에 담깁니다. 이 `study` 변수를 통해 앞으로 실험을 몇 번이나 할 것인지 지시(`study.optimize()`)하고, 실험이 끝난 후 가장 좋은 결과가 무엇이었는지 확인(`study.best_value`, `study.best_params`)할 수 있습니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 코드를 실행해 보고 감을 잡을 수 있도록 간단한 전체 예시 코드를 준비했습니다.

#### 💡 따라 하기 예시 코드
```python
import optuna


# 1. 목적 함수 정의 (간단한 예: x값을 조절해 (x-2)^2 + 1의 최솟값...이 아니라 최댓값을 찾는다고 가정)
# 여기서는 x를 조절해서 y = - (x - 2)^2 + 10 의 값을 '최대화' 해보겠습니다.
def objective(trial):
    # -10부터 10 사이의 실수 x를 하나 정해달라고 요청
    x = trial.suggest_float("x", -10, 10)

    # 우리가 최대화하고 싶은 값 계산
    score = -((x - 2) ** 2) + 10
    return score


# 2. Study 생성 (오늘 배운 핵심 코드!)
# 점수를 '최대화'하는 연구소를 만듭니다.
study = optuna.create_study(direction="maximize")

# 3. 최적화 시작 (실험을 50번 반복)
study.optimize(objective, n_trials=50)

# 4. 결과 확인
print("가장 높은 점수:", study.best_value)
print("이때의 최적 x값:", study.best_params)
```

#### 🎯 예상 결과
*   Optuna가 50번의 실험을 거치며 `x`값을 이리저리 바꿔봅니다.
*   최대화(`maximize`)가 목표이므로, $y = -(x - 2)^2 + 10$ 식에서 가장 큰 값인 **10**을 찾아냅니다.
*   그때의 `x`값인 **2.0**에 가장 가까운 숫자를 찾아내어 출력해 줍니다!

# IPython.display - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 23:09:07

---

IPython.display는 주피터 노트북이라는 파이썬 도구 안에서 글자뿐만 아니라 그림, 표, 소리 같은 시각적인 자료들을 예쁘게 화면에 띄워주는 마법 같은 도구예요. 

우리가 흔히 쓰는 파이썬의 print문이 단순히 텍스트만 보여주는 칠판이라면, 이 기능은 사진이나 동영상을 척척 보여주는 스마트  телевизор(티비) 같은 역할을 한답니다. 

그래서 분석한 결과물이나 예쁜 그래프, 혹은 유튜브 영상 같은 것을 코드 실행 창 바로 아래에 보기 좋게 띄우고 싶을 때 주로 사용해요.

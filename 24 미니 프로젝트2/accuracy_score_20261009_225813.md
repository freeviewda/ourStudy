# accuracy_score - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 22:58:13

---

파이썬 머신러닝에서 모델의 성능을 평가할 때 가장 자주 쓰이는 **`accuracy_score`** 함수에 대해 초보자의 눈높이에 맞춰 친절하고 명쾌하게 해설해 드리겠습니다.

---

### 1. 📌 함수 개요
`accuracy_score`는 머신러닝 모델이 예측한 결과가 실제 정답과 얼마나 일치하는지 비율(정확도)을 계산해 주는 함수입니다. 사이킷런(Scikit-Learn) 라이브러리의 `metrics` 모듈에 포함되어 있으며, **"전체 예측 중 맞춘 것의 비율(0.0 ~ 1.0 사이의 값)"**을 반환합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `accuracy_score(y_te, y_pred)`에서 사용된 두 개의 인자의 역할은 다음과 같습니다.

*   **첫 번째 인자: `y_te` (실제 정답)**
    *   **역할:** 테스트 데이터셋에 해당하는 **실제 정답(True Labels)** 값들의 모음입니다. (보통 NumPy 배열이나 판다스 시리즈 형태)
    *   **의미:** 모델이 맞추어야 하는 '진짜 참값'입니다.
*   **두 번째 인자: `y_pred` (모델의 예측값)**
    *   **역할:** 머신러닝 모델이 테스트 데이터를 보고 **예측한 결과(Predicted Labels)** 값들의 모음입니다.
    *   **의미:** 모델이 "이 데이터는 이럴 것이다"라고 판단한 '가짜(예측)값'입니다.

> 💡 **작동 방식:** 함수는 `y_te`의 값들과 `y_pred`의 값들을 일대일로 비교하여, 몇 개나 정확히 일치하는지 세어 전체 개수로 나눈 뒤 정확도 점수를 산출합니다.

---

### 3. 📤 반환값/할당 변수
코드 전체 문맥을 보면 이 함수는 단독으로 쓰이지 않고 딕셔너리를 통해 리스트(`results`)에 추가되고 있습니다.

*   **반환값:** `0.0`에서 `1.0` 사이의 **실수(Float)** 값을 반환합니다.
    *   예를 들어 반환값이 `0.85`라면, 테스트한 데이터 100개 중 85개를 맞췄다는 뜻이며 퍼센트(%)로는 **85%의 정확도**를 의미합니다.
*   **할당 및 활용:** 계산된 정확도 숫자(예: `0.85`)가 `'Accuracy'`라는 🔑(Key)의 밸류(Value)로 딕셔너리에 쏙 들어가서, 최종적으로 `results` 리스트에 차곡차곡 쌓이게 됩니다.

---

### 4. 🎁 요약 및 실행 예시
이해를 돕기 위해 아주 간단한 파이썬 코드로 직접 실행해 보겠습니다.

**[간단한 실습 코드]**
```python
from sklearn.metrics import accuracy_score

# 1. 실제 정답 (강아지=1, 고양이=0 이라고 가정)
y_true = [1, 0, 1, 1, 0]

# 2. 모델이 예측한 값
y_pred = [1, 0, 0, 1, 0]

# 3. accuracy_score 함수 호출
score = accuracy_score(y_true, y_pred)

print(f"모델의 정확도: {score}")
```

**[예상 결과]**
```text
모델의 정확도: 0.8
```
*   **해설:** 총 5개의 데이터 중 3번째 데이터만 모델이 틀렸고(실제 1인데 0으로 예측), 나머지 4개는 맞췄습니다. 따라서 $\frac{4}{5} = 0.8$ (즉, 80%의 정확도)이 출력됩니다!

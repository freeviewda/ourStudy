파이썬 데이터 분석 및 시각화에서 가장 많이 쓰이는 라이브러리인 **Matplotlib**의 `plt.ylabel()` 함수에 대해 초보자의 눈높이에 맞춰 쉽고 명쾌하게 설명해 드리겠습니다.

---

### 1. 📌 함수 개요
`plt.ylabel()`은 **그래프의 Y축(세로축)에 이름(라벨)을 달아주는 함수**입니다. 이 함수를 사용하면 그래프를 보는 사람이 세로축이 무엇을 나타내는지 직관적으로 이해할 수 있습니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시된 코드 `plt.ylabel('Actual')`에서 사용된 인자의 역할은 다음과 같습니다.

*   **`'Actual'` (문자열, string)**
    *   **역할:** Y축에 표시될 텍스트(이름)를 지정합니다.
    *   **설정된 값의 의미:** 'Actual(실제값)'이라는 글자를 Y축 옆에 띄우겠다는 뜻입니다. 보통 머신러닝이나 통계 모델에서 예측값(Predicted)과 실제값(Actual)을 비교할 때 Y축을 실제값으로 설정하기 위해 자주 사용됩니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값 없음 (None 또는 Text 객체 반환)**
    *   `plt.ylabel()`은 주로 화면에 바로 글자를 출력(렌더링)하는 용도로 사용되기 때문에, 별도의 변수에 값을 할당받아 쓰는 경우는 초보 단계에서는 거의 없습니다. 
    *   내부적으로는 생성된 텍스트 객체를 반환하지만, 코드처럼 단독으로 사용할 때는 값을 반환받지 않고 함수 실행 자체로 끝납니다.

---

### 4. 🎁 요약 및 실행 예시
백문이 불여일견! 직접 코드를 실행해서 Y축 라벨이 어떻게 생기는지 확인해 봅시다. 아래 코드를 복사해서 파이썬 환경(주피터 노트북 등)에서 실행해 보세요.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 간단한 데이터 준비
x = [1, 2, 3, 4]
y = [10, 20, 25, 30]

# 2. 그래프 그리기
plt.plot(x, y)

# 3. X축과 Y축에 이름(라벨) 달기
plt.xlabel('Predicted')  # 가로축 이름
plt.ylabel('Actual')     # 세로축 이름 (오늘 배운 함수!)

# 4. 그래프 화면에 보여주기
plt.show()
```

**[예상 결과]**
*   창이 뜨면서 선 그래프가 나타납니다.
*   가로축(X축) 아래에는 **'Predicted'**라는 글자가 적힙니다.
*   세로축(Y축) 왼쪽에는 오늘 배운 **'Actual'**이라는 글자가 세로로 예쁘게 표시됩니다.

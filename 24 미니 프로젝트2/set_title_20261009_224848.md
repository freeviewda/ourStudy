# set_title - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 22:48:48

---

파이썬 데이터 분석(특히 `matplotlib` 라이브러리)에서 자주 사용되는 `set_title` 함수에 대한 상세 해설입니다. 초보자분들도 쉽게 이해할 수 있도록 차근차근 설명해 드릴게요!

---

### 1. 📌 함수 개요
`set_title()`은 **그래프(Axes)의 상단에 제목(Title)을 달아주는 함수**입니다. 여러 개의 그래프를 그릴 때 각각의 그래프가 무엇을 나타내는지 이름을 붙여주어 시각화의 가독성을 높일 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `axes[0, 1].set_title('Age Distribution')`에서 전달된 인자와 관련 요소를 뜯어보겠습니다.

*   **`'Age Distribution'` (문자열, 필수 인자)**
    *   **역할:** 그래프에 표시할 **제목의 내용**을 지정합니다.
    *   **설정된 값의 의미:** 영어로 '나이 분포'라는 뜻으로, 이 그래프가 데이터의 연령대 분포를 시각화한 것임을 알려줍니다.
*   **(`axes[0, 1]` 부분 참고)**
    *   `set_title`을 호출하는 주체입니다. 전체 도화지(Figure)에서 **0행 1열(첫 번째 행, 두 번째 열)에 위치한 특정 그래프 상자**를 지정하여, 거기에만 제목을 설정하겠다는 의미입니다.

---

### 3. 📤 반환값/할당 변수
`set_title()` 함수는 별도의 데이터를 반환(Return)하여 변수에 담아 쓰는 함수가 아닙니다. 
*   **특징:** 지정한 그래프(Axes 객체) 내부의 제목 속성을 직접 변경(In-place modification)하고 끝나는 **실행형 함수**입니다. 따라서 별도의 변수에 결과를 담을 필요가 없습니다.

---

### 4. 🎁 요약 및 실행 예시
백문이 불여일견! 초보자분들이 주피터 노트북이나 파이썬 환경에서 직접 복사해서 실행해 볼 수 있는 가장 간단한 전체 코드를 준비했습니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 1행 2열짜리 도화지(Figure)와 그래프 상자(Axes)들 생성
fig, axes = plt.subplots(1, 2, figsize=(10, 4))

# 2. 첫 번째 그래프에 제목 설정 (0번 인덱스)
axes[0].set_title('First Graph')

# 3. 두 번째 그래프에 제목 설정 (1번 인덱스) -> 질문하신 문맥과 유사한 형태!
axes[1].set_title('Second Graph')

# 4. 화면에 출력
plt.show()
```

**[예상 결과]**
*   가로로 나란히 2개의 빈 그래프 상자가 그려집니다.
*   왼쪽 그래프 상단에는 **'First Graph'**라는 제목이, 오른쪽 그래프 상단에는 **'Second Graph'**라는 제목이 각각 깔끔하게 표시됩니다.

# warnings.filterwarnings - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 22:45:06

---

파이썬 코드에서 사용된 `warnings.filterwarnings('ignore')`에 대한 상세 해설입니다. 초보자분들도 쉽게 이해하실 수 있도록 항목별로 나누어 설명해 드릴게요!

---

### 1. 📌 함수 개요
`warnings.filterwarnings()` 함수는 **파이썬 실행 중에 발생하는 '경고(Warning)' 메시지의 출력 여부나 방식을 제어(필터링)하는 함수**입니다. 프로그램 실행에 치명적인 오류(Error)는 아니지만, "이 부분은 나중에 수정하는 게 좋아요"라고 알려주는 거슬리는 경고 메시지들을 화면에 안 보이게 숨기고 싶을 때 주로 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제공해주신 코드에서는 하나의 인자가 전달되었습니다.

* **`'ignore'`**
  * **역할:** 경고 메시지를 어떻게 처리할지 결정하는 필터 규칙(action)입니다.
  * **설정된 값의 의미:** 파이썬 실행 중 발생하는 **모든 경고 메시지를 무시(Ignore)**하고 화면에 출력하지 않겠다는 뜻입니다.
  * *참고 (다른 옵션들):* 
    * `'default'`: 처음 발생한 경고만 출력
    * `'always'`: 발생할 때마다 모든 경고 출력
    * `'error'`: 경고를 무시하지 않고, 에러(Exception)로 취급하여 프로그램을 멈춤

---

### 3. 📤 반환값/할당 변수
* **반환값 없음 (`None`)**
  * 이 함수는 화면에 출력되는 경고 설정을 내부적으로 변경해주는 역할만 수행합니다. 
  * 따라서 별도의 값을 반환하지 않으며, 변수에 대입(`=` 기호 사용)하여 받을 필요가 없습니다.

---

### 4. 🎁 요약 및 실행 예시

**💡 한 줄 요약:** 
> `"앞으로 코드 실행할 때 짜증나는 경고 창 좀 다 숨겨줘!"` 라고 파이썬에게 명령하는 코드입니다. (특히 데이터 분석 시 버전 차이로 뜨는 불필요한 경고를 숨길 때 유용하게 쓰입니다.)

**🧪 초보자용 실습 코드:**
```python
import warnings

# 1. 경고 숨기기 전 (경고 메시지가 그대로 출력됨)
print("--- 1. 경고 숨기기 전 ---")
warnings.warn("이것은 첫 번째 경고 메시지입니다!", UserWarning)

# 2. 경고 숨기기 실행
warnings.filterwarnings('ignore')

# 3. 경고 숨긴 후 (메시지가 출력되지 않음)
print("--- 2. 경고 숨긴 후 ---")
warnings.warn("이것은 두 번째 경고 메시지입니다! (안 보일 거예요)", UserWarning)

print("프로그램이 정상적으로 끝났습니다.")
```

**📺 예상 실행 결과:**
```text

<script>:5: UserWarning: 이것은 첫 번째 경고 메시지입니다!
  warnings.warn("이것은 첫 번째 경고 메시지입니다!", UserWarning)
--- 2. 경고 숨긴 후 ---
프로그램이 정상적으로 끝났습니다.
```
*설명: 두 번째 경고는 `warnings.filterwarnings('ignore')` 덕분에 화면에 나타나지 않고 깔끔하게 무시된 것을 확인할 수 있습니다!*

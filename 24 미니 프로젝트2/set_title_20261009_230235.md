# set_title - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 23:02:35

---

파이썬 데이터 분석 및 시각화(주로 `matplotlib` 라이브러리)에서 자주 사용되는 `set_title` 함수에 대한 상세 해설입니다.

---

### 1. 📌 함수 개요
`set_title` 함수는 **그래프(Axes)의 상단 중앙에 제목(Title)을 달아주는 함수**입니다. 여러 개의 그래프를 나란히 그릴 때, 특정 그래프가 어떤 데이터를 보여주는지 명확하게 설명하기 위해 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `axes[1].set_title('ROC-AUC: Base vs GridSearch vs Optuna')`에서 함수에 전달된 인자를 분석해 보겠습니다.

*   **`'ROC-AUC: Base vs GridSearch vs Optuna'` (문자열, 위치 인자)**
    *   **역할:** 그래프에 표시할 **제목의 텍스트**를 지정합니다.
    *   **설정된 값의 의미:** 
        *   `ROC-AUC`: 이 그래프가 'ROC-AUC' 성능 지표를 시각화하고 있음을 나타냅니다.
        *   `Base vs GridSearch vs Optuna`: 기본 모델(Base)과 하이퍼파라미터 튜닝 방식인 GridSearch, 그리고 Optuna의 성능을 비교(vs)하는 그래프라는 것을 직관적으로 설명하고 있습니다.

*(참고: 이외에도 글자 크기를 키우는 `fontsize`, 글자 색상을 바꾸는 `color`, 제목 위치를 조정하는 `loc` 등 다양한 추가 인자를 넣을 수 있습니다.)*

---

### 3. 📤 반환값/할당 변수
*   **반환값:** `set_title()` 함수는 제목을 설정한 해당 그래프 객체(`Text` 객체)를 반환합니다.
*   **할당 변수:** 위 코드에서는 함수가 반환하는 값을 별도의 변수에 저장(`=` 대입 연산자 사용)하지 않고, **함수 자체의 실행 결과(그래프에 제목이 바로 적용되는 부수 효과)만 사용**하고 있습니다. 파이썬 시각화 코드에서는 이처럼 변수에 담지 않고 바로 실행하는 형태가 매우 흔합니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들도 Jupyter Notebook이나 파이썬 환경에서 복사해서 바로 실행해 볼 수 있는 간단한 전체 코드 예시입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 1개의 행과 2개의 열을 가진 도화지(fig)와 그래프 공간(axes) 생성
fig, axes = plt.subplots(1, 2, figsize=(10, 4))

# 2. 첫 번째 그래프(왼쪽, index 0)에 제목 설정
axes[0].set_title('First Graph')

# 3. 두 번째 그래프(오른쪽, index 1)에 문제의 코드 적용
axes[1].set_title('ROC-AUC: Base vs GridSearch vs Optuna')

# 4. 그래프 화면에 출력
plt.show()
```

**[예상 결과]**
*   좌우로 나란히 2개의 빈 그래프 창이 생성됩니다.
*   오른쪽 그래프(`axes[1]`)의 상단 중앙에 **"ROC-AUC: Base vs GridSearch vs Optuna"** 라는 제목이 깔끔하게 표시됩니다.

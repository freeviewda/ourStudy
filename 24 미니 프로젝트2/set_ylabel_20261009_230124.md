# set_ylabel - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 23:01:24

---

파이썬 데이터 시각화 라이브러리인 맷플롯립(Matplotlib)에서 사용되는 `set_ylabel` 함수에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 친절하고 명쾌하게 정리해 드릴게요!

---

### 1. 📌 함수 개요
`set_ylabel`은 그래프의 **세로축(Y축) 이름(라벨)**을 설정해 주는 함수입니다. 그래프를 보는 사람이 "세로축에 표시된 숫자들이 무엇을 의미하는지" 쉽게 알 수 있도록 이름을 달아주는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `axes[0].set_ylabel('Accuracy')`에서 사용된 인자를 자세히 살펴볼까요?

*   **`'Accuracy'` (문자열, string)**
    *   **역할:** Y축에 표시할 이름을 지정합니다.
    *   **설정된 값의 의미:** 'Accuracy'는 영어로 **'정확도'**를 뜻합니다. 즉, 이 그래프의 세로축이 머신러닝 모델 등의 '정확도' 수치를 나타내고 있음을 시각적으로 알려줍니다.
    *   *참고:* 이 자리에는 원하는 어떤 글자든 넣을 수 있습니다. (예: `'Loss'`, `'Price'`, `'Temperature'` 등)

*(참고로 앞에 있는 `axes[0]`은 여러 개의 그래프(서브플롯) 중 **첫 번째 그래프**를 선택하겠다는 의미입니다.)*

---

### 3. 📤 반환값/할당 변수
*   **반환값:** `Text` 객체 (Y축에 표시된 텍스트 속성을 담고 있는 객체)
*   **할당 변수:** 별도의 변수에 대입하지 않고 함수만 단독으로 호출(`axes[0].set_ylabel('Accuracy')`)했습니다. 
*   **의미:** 텍스트의 색상이나 글꼴 크기 등을 나중에 따로 수정할 일이 없다면, 보통은 위 코드처럼 변수에 담지 않고 곧바로 실행하여 화면에 라벨만 띄우는 방식으로 사용합니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 주피터 노트북이나 파이썬 파일에서 직접 복사해서 실행해 볼 수 있는 가장 간단한 예시 코드입니다.

**💻 실행 코드:**
```python
import matplotlib.pyplot as plt

# 1. 1개의 그래프 영역 생성
fig, ax = plt.subplots()

# 2. 간단한 데이터로 선 그래프 그리기
x_values = [1, 2, 3, 4]
y_values = [0.60, 0.75, 0.85, 0.95]
ax.plot(x_values, y_values)

# 3. Y축 이름 설정 (오늘 배운 함수!)
ax.set_ylabel('Accuracy')

# 4. X축 이름 설정 (보너스)
ax.set_xlabel('Epoch')

# 5. 그래프 화면에 출력
plt.show()
```

**✨ 예상 결과:**
창이 뜨면서 꺾은선 그래프가 나타납니다. 이때 **왼쪽 세로축(Y축) 중앙에 'Accuracy'라는 글자가 세로로 예쁘게 출력**되어, 이 그래프가 정확도를 나타낸다는 것을 한눈에 알 수 있게 됩니다.

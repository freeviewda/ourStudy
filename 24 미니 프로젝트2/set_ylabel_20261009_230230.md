# set_ylabel - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 23:02:30

---

파이썬 데이터 시각화 라이브러리인 **Matplotlib**에서 사용되는 `set_ylabel` 함수에 대해 초보자의 눈높이에 맞춰 친절하고 명쾌하게 해설해 드리겠습니다.

---

### 1. 📌 함수 개요
`set_ylabel`은 **그래프의 Y축(세로축)에 이름(제목, 라벨)을 달아주는 함수**입니다. 그래프를 보는 사람이 세로축이 무엇을 나타내는지(예: 가격, 정확도, 확률 등) 직관적으로 알 수 있도록 설명해 주는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제공해주신 코드 `axes[1].set_ylabel('ROC-AUC')`에서 함수에 전달된 인자는 다음과 같습니다.

*   **`'ROC-AUC'` (위치 인자 / 문자열)**
    *   **역할:** Y축에 표시할 텍스트를 지정합니다.
    *   **설정값의 의미:** 이 그래프의 세로축이 기계학습 모델의 성능 평가 지표 중 하나인 **'ROC-AUC'** 값(0과 1 사이의 모델 성능 수치)을 나타내고 있음을 사용자에게 알려줍니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값:** 이 함수는 별도의 데이터를 리턴하지 않고, 내부적으로 Y축의 텍스트 설정만 변경한 뒤 **`Text` 객체(라벨 텍스트를 관리하는 객체)**를 반환합니다.
*   **할당 변수:** 현재 코드에서는 반환값을 별도의 변수에 저장(`result = ...` 형태)하지 않고 **함수만 단독으로 호출**하여 사용했습니다. 이처럼 파이썬 시각화에서는 반환값을 받지 않고 화면을 꾸미는 용도로 바로 사용하는 경우가 많습니다.

---

### 4. 🎁 요약 및 실행 예시
이 코드가 포함된 전체 흐름을 이해할 수 있도록, 초보자도 직접 실행해 볼 수 있는 가장 간단한 예제 코드를 준비했습니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 1개의 행과 2개의 열을 가진 그래프 판(fig)과 축(axes) 생성
fig, axes = plt.subplots(1, 2, figsize=(10, 4))

# 2. 두 번째 그래프(오른쪽, 인덱스 1)의 Y축 이름을 'ROC-AUC'로 설정
axes[1].set_ylabel('ROC-AUC')

# 3. 그래프 화면에 띄우기
plt.show()
```

**[예상 결과]**
*   화면에 나란히 놓인 두 개의 빈 그래프가 나타납니다.
*   그중 **오른쪽 그래프의 세로축(Y축) 왼쪽에 정확히 'ROC-AUC'라는 글자가 표시**되어 있는 것을 확인할 수 있습니다.

### 1. 📌 함수 개요
`plt.xlabel()`은 파이썬의 대표적인 시각화 라이브러리인 **Matplotlib**에서 그래프의 **가로축(X축) 이름(라벨)을 지정**해 주는 함수입니다. 그래프만 보고는 X축이 무엇을 나타내는지 알기 어려울 때, 보는 사람이 직관적으로 이해할 수 있도록 이름을 달아주는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제공해주신 코드 `plt.xlabel('Importance')`에서 사용된 인자의 역할과 의미는 다음과 같습니다.

*   **`'Importance'` (문자열, String)**
    *   **역할:** X축에 표시될 텍스트(이름)를 지정합니다.
    *   **의미:** 여기서는 '중요도'라는 뜻을 가진 `'Importance'`를 전달했으므로, 그래프의 X축 아래에 **"Importance"**라는 글자가 나타나게 됩니다. (예: 머신러닝 모델에서 어떤 특성(Feature)이 얼마나 중요한지 나타내는 막대 그래프 등에 주로 사용됩니다.)
    *   *참고 팁:* 한글을 입력하고 싶다면 따옴표 안에 `'중요도'`처럼 적어주셔도 됩니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값 없음 (None)**
*   이 함수는 별도의 데이터를 반환(Return)하여 변수에 담아두는 함수가 아닙니다. 
*   단순히 현재 그려지고 있는 그래프의 X축 설정을 '변경'하는 명령(Action)을 수행하므로, 코드처럼 변수에 대입하지 않고 `plt.xlabel('Importance')` 형태로 단독으로 호출하여 사용합니다.

---

### 4. 🎁 요약 및 실행 예시
`plt.xlabel`을 포함하여 초보자도 바로 실행해 볼 수 있는 가장 간단한 전체 그래프 그리기 예시 코드를 준비했습니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. X축과 Y축에 들어갈 데이터 준비
features = ['Age', 'Income', 'Score']
importance_values = [0.15, 0.65, 0.20]

# 2. 막대 그래프 그리기
plt.bar(features, importance_values)

# 3. 축 이름 및 제목 달기 (오늘 배운 함수!)
plt.xlabel('Importance')  # X축 이름 설정
plt.ylabel('Features')    # Y축 이름 설정
plt.title('Feature Importance Chart') # 그래프 제목 설정

# 4. 화면에 그래프 띄우기
plt.show()
```

**[예상 결과]**
*   세 개의 막대가 있는 막대 그래프가 생성됩니다.
*   **가로축(X축) 아래**에 **"Importance"**라는 이름이 선명하게 표시되어, 이 축이 '중요도'를 의미함을 한눈에 알 수 있게 됩니다.

# plt.figure - AI 파이썬 학습 노트

---

파이썬 데이터 시각화 라이브러리인 Matplotlib에서 자주 사용되는 `plt.figure()` 함수에 대한 상세 해설입니다. 초보자분들도 쉽게 이해할 수 있도록 항목별로 친절하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`plt.figure()`는 새로운 도화지(캔버스)를 생성하는 함수입니다. 그림(Figure)의 전체적인 크기, 해상도, 배경색 등을 설정하여 앞으로 그려질 그래프의 판을 깔아주는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `plt.figure(figsize=(10, 8))`에서 사용된 인자의 의미는 다음과 같습니다.

*   **`figsize=(10, 8)`**
    *   **역할:** 생성할 도화지의 가로, 세로 크기를 지정합니다.
    *   **설정된 값의 의미:** 가로 `10인치(inch)`, 세로 `8인치` 크기의 큼직한 도화지를 만듭니다. 숫자가 클수록 더 넓고 시원시원한 그래프를 그릴 수 있으며, 보통 데이터가 많거나 복잡한 그래프를 그릴 때 여유 있게 공간을 주기 위해 사용합니다. (참고로 단위는 인치이며, 화면 해상도에 따라 실제 픽셀 수는 달라질 수 있습니다.)

---

### 3. 📤 반환값/할당 변수
현재 제시된 코드 `plt.figure(figsize=(10, 8))`에는 반환값을 저장하는 변수(예: `fig = plt.figure(...)`)가 따로 없습니다. 
*   **동작 방식:** 변수에 할당하지 않고 단독으로 호출해도, 파이썬(Matplotlib) 내부적으로 '현재 작업 중인 기본 도화지'로 인식하여 이후에 작성되는 그래프 명령(`plt.plot()`, `plt.scatter()` 등)이 이 도화지 위에 그려지게 됩니다.
*   *(참고)* 만약 변수에 담는다면 `fig = plt.figure(...)` 형태로 쓰이며, 이때 `fig`는 생성된 도화지 전체 객체를 의미하게 되어 나중에 그림을 파일로 저장(`fig.savefig()`)할 때 유용하게 쓰입니다.

---

### 4. 🎁 요약 및 실행 예시
백문이 불여일견! 아래의 간단한 코드를 직접 복사해서 실행해 보세요. `plt.figure()`가 도화지 크기를 어떻게 바꾸는지 눈으로 확인할 수 있습니다.

**[실습 코드]**
```python
import matplotlib.pyplot as plt

# 1. 10x8 크기의 커다란 도화지 생성
plt.figure(figsize=(10, 8))

# 2. 간단한 선 그래프 그리기
x = [1, 2, 3, 4]
y = [10, 20, 25, 30]
plt.plot(x, y, marker='o', linestyle='-', color='blue', linewidth=3)

# 3. 그래프 제목과 축 이름 설정
plt.title("My First Big Figure", fontsize=16)
plt.xlabel("X Axis", fontsize=12)
plt.ylabel("Y Axis", fontsize=12)

# 4. 화면에 보여주기
plt.show()
```

**[예상 결과]**
*   가로로 넓고 세로로 넉넉한(`10x8` 비율) 커다란 창(윈도우)이 열리면서, 그 안에 파란색 선 그래프가 예쁘게 그려져 나타납니다. `figsize`를 지우고 기본값으로 실행했을 때와 비교해보면 도화지가 훨씬 넓어졌음을 체감할 수 있습니다!

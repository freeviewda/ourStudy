# len - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 23:07:01

---

파이썬 코드에서 사용된 **`len()`** 함수와 해당 문맥에 대한 상세 해설을 초보자의 눈높이에 맞춰 친절하고 명쾌하게 정리해 드리겠습니다.

---

### 1. 📌 함수 개요
`len()` 함수는 파이썬의 **내장 함수(Built-in Function)**로, 문자열, 리스트, 튜플, 딕셔너리 등 **데이터의 길이(항목의 개수)**를 세어 반환해 줍니다. 위 코드에서는 `normal_indices`라는 리스트에 들어있는 아이템(인덱스 번호들)의 개수가 몇 개인지를 확인하는 용도로 사용되었습니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드에서 `len()` 함수에 전달된 인자는 다음과 같습니다.

*   **`normal_indices`**
    *   **역할:** 정상 데이터로 판별된 데이터들의 위치(인덱스) 번호들이 담겨 있는 **리스트(List)**입니다.
    *   **코드 내 의미:** "정상 데이터가 과연 몇 개나 수집되었는가?"를 확인하기 위해 `len()` 함수의 재료로 전달되었습니다.

---

### 3. 📤 반환값/할당 변수
`len()` 함수는 계산된 결과를 어떻게 활용하고 있는지 조건문을 통해 살펴보겠습니다.

*   **반환값 (정수형, Integer):** 
    *   `len(normal_indices)`는 `normal_indices` 리스트에 들어있는 데이터의 개수를 **숫자(정수)**로 반환합니다. (예: 0개면 `0`, 3개면 `3`)
*   **코드 전체의 흐름 (`if len(normal_indices) > 0:`):**
    *   "정상 데이터의 개수가 0보다 크다면(즉, 정상 데이터가 **최소 1개 이상 존재한다면**)"이라는 조건문입니다.
    *   조건이 참(True)일 경우, `sample_indices.append(normal_indices[0])`을 실행하여 그중 **가장 첫 번째 정상 데이터의 인덱스(`0번 인덱스`)**를 `sample_indices`라는 다른 리스트에 쏙 집어넣습니다(추가합니다).

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 파이썬 인터프리터나 주피터 노트북에서 직접 실행해 보고 감을 잡을 수 있는 간단한 예시 코드입니다.

#### 📝 실습 코드
```python
# 1. 정상 데이터의 인덱스가 2개 있다고 가정해봅시다.
normal_indices = [10, 25]
sample_indices = []

# 2. len() 함수를 이용해 개수를 확인하고 조건문 실행
if len(normal_indices) > 0:
    # normal_indices의 길이는 2이므로 0보다 큽니다. 따라서 이 코드가 실행됩니다!
    sample_indices.append(normal_indices[0])  # 0번째 값인 10을 추가

print("정상 데이터 개수:", len(normal_indices))
print("샘플 인덱스 리스트:", sample_indices)
```

#### 🖥️ 예상 결과
```text
정상 데이터 개수: 2
샘플 인덱스 리스트: [10]
```

> **💡 핵심 팁:** 
> 만약 `normal_indices = []` (빈 리스트)였다면 `len()`의 결과는 `0`이 되고, `0 > 0`은 거짓(False)이 되므로 에러 없이 안전하게 건너뛰게 됩니다. 파이썬에서 리스트가 비어있는지 확인할 때 아주 자주 쓰이는 안전장치 같은 코드입니다!

# ax.set_title - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 23:13:35

---

파이썬 시각화 라이브러리인 맷플롯립(Matplotlib)을 사용할 때 자주 쓰는 `ax.set_title` 함수에 대해 초보자의 눈높이에 맞춰 아주 쉽게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`ax.set_title()`은 **그래프의 상단 중앙에 제목(Title)을 달아주는 함수**입니다. 그래프가 무엇을 나타내는지 보는 사람이 한눈에 알아볼 수 있도록 이름을 지어줄 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
전달된 코드 `ax.set_title('Final: Base vs GridSearch vs Optuna')`에서 사용된 인자를 자세히 살펴볼까요?

* **`'Final: Base vs GridSearch vs Optuna'` (문자열, string)**
  * **역할:** 그래프에 표시할 **제목의 내용**을 지정합니다.
  * **설정된 값의 의미:** 이 그래프가 머신러닝 모델들의 성능을 최종 비교하는 그래프임을 나타냅니다. 
    * `Base`: 기본 모델
    * `GridSearch`: 그리드 서치로 튜닝한 모델
    * `Optuna`: 옵튜나로 튜닝한 모델
    * 즉, "이 세 가지 모델을 최종 비교하는 그래프야!"라고 이름을 붙여준 것입니다.

> 💡 **참고 (자주 쓰는 추가 인자들):**
> * `fontsize`: 글자 크기 (예: `fontsize=14`)
> * `pad`: 제목과 그래프 사이의 간격 (예: `pad=10`)
> * `color`: 글자 색상 (예: `color='blue'`)

---

### 3. 📤 반환값/할당 변수
* **반환값:** `matplotlib.text.Text` 객체를 반환합니다.
* **특징:** 이 코드는 반환값을 별도의 변수에 저장(`title = ax.set_title(...)`)하지 않고 그냥 실행만 했습니다. 제목을 화면에 띄우는 역할만 하고 끝내기 때문에 **별도로 할당받는 변수는 없습니다.**

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 Jupyter Notebook이나 파이썬 파일에서 직접 복사해서 실행해 볼 수 있는 가장 간단한 코드입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 도화지(fig)와 축(ax) 만들기
fig, ax = plt.subplots()

# 2. 간단한 선 그래프 그리기
ax.plot([1, 2, 3], [10, 20, 15])

# 3. 그래프에 제목 달기 (오늘 배운 함수!)
ax.set_title('Final: Base vs GridSearch vs Optuna')

# 4. 화면에 보여주기
plt.show()
```

**[예상 결과]**
* 창이 하나 뜨면서 꺾은선 그래프가 그려지고, **그래프 바로 위 정가운데**에 `'Final: Base vs GridSearch vs Optuna'`라는 제목이 깔끔하게 적혀 있는 것을 확인할 수 있습니다!

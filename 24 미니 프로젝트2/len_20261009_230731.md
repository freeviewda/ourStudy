# len - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 23:07:31

---

파이썬의 내장 함수 `len()`과 제공해주신 코드 문맥(`if len(disease_indices) >= 2:`)에 대해 초보자도 이해하기 쉽도록 항목별로 친절하게 해설해 드리겠습니다.

---

### 1. 📌 함수 개요
`len()` 함수는 파이썬의 **기본 내장 함수(Built-in Function)**로, 리스트, 문자열, 튜플 등 **여러 개의 데이터를 담고 있는 객체의 길이(아이템의 개수)**를 세어 숫자로 알려주는 역할을 합니다. 위 코드에서는 `disease_indices`(질병 인덱스들)라는 리스트에 들어있는 항목의 개수가 2개 이상인지 확인하기 위해 사용되었습니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
`len()` 함수에 전달된 인자의 역할과 의미는 다음과 같습니다.

*   **전달된 인자:** `disease_indices`
*   **인자의 역할 및 의미:**
    *   `disease_indices`는 특정 질병 데이터가 저장된 위치(인덱스 번호들)를 모아놓은 **리스트(List)**입니다.
    *   `len()` 함수는 이 리스트 내부를 스캔하여 **"지금 질병 데이터가 총 몇 개 들어있지?"**를 계산합니다.
    *   *예를 들어,* `disease_indices = [3, 7, 15]` 라면, `len()`은 이 리스트의 길이인 `3`을 반환합니다.

> **💡 전체 조건문(`if len(disease_indices) >= 2:`)의 의미:**
> "만약 `disease_indices` 리스트에 들어있는 데이터의 개수가 **2개 이상**이라면~"이라는 뜻입니다.

---

### 3. 📤 반환값/할당 변수
`len()` 함수는 복잡한 데이터나 객체를 반환하지 않고, **오직 하나의 정수(Integer) 값**을 반환합니다.

*   **반환값:** 리스트의 개수를 센 **정수(예: `0`, `1`, `2`, `5`, `10` 등)**
*   **코드 내에서의 활용:**
    *   반환된 정수는 바로 뒤의 `>= 2`와 비교 연산에 사용됩니다.
    *   조건이 참(True)이 되면, 그 아래의 `sample_indices.extend(disease_indices[:2])` 코드가 실행되어 질병 인덱스 중 앞에서 최대 2개를 뽑아 다른 리스트(`sample_indices`)에 추가하게 됩니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 파이썬 환경에서 실행해보고 결과를 확인할 수 있는 간단한 예시 코드입니다.

**[실습 코드]**
```python
# 1. 질병 인덱스가 1개만 있는 경우
disease_indices_1 = [5]

print(f"리스트: {disease_indices_1}")
print(f"길이(len): {len(disease_indices_1)}")

if len(disease_indices_1) >= 2:
    print("조건 만족: 2개 이상입니다.")
else:
    print("조건 불만족: 2개 미만입니다.\n")


# 2. 질병 인덱스가 3개 있는 경우
disease_indices_2 = [10, 22, 35]

print(f"리스트: {disease_indices_2}")
print(f"길이(len): {len(disease_indices_2)}")

if len(disease_indices_2) >= 2:
    print("조건 만족: 2개 이상입니다.")
else:
    print("조건 불만족: 2개 미만입니다.")
```

**[예상 결과]**
```text
리스트: [5]
길이(len): 1
조건 불만족: 2개 미만입니다.

리스트: [10, 22, 35]
길이(len): 3
조건 만족: 2개 이상입니다.
```

**핵심 요약:** `len()`은 데이터의 **"개수를 세어주는 마법의 자(Ruler)"**라고 생각하시면 가장 쉽습니다!

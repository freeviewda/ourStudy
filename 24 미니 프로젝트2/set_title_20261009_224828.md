# set_title - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 22:48:28

---

파이썬의 데이터 시각화 라이브러리(Matplotlib 등)에서 자주 사용되는 `set_title` 함수에 대한 상세 해설입니다. 초보자도 쉽게 이해할 수 있도록 정리해 드립니다!

---

### 1. 📌 함수 개요
`set_title`은 **그래프(Axes)의 상단 중앙에 제목(Title)을 설정해 주는 함수**입니다. 여러 개의 그래프가 모여 있는 도화지(Figure)에서, 특정 그래프가 어떤 데이터를 보여주는지 이름을 붙여줄 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `axes[0, 0].set_title('Target Distribution')`에서 `set_title`에 전달된 인자는 다음과 같습니다.

*   **`'Target Distribution'` (문자열, string)**
    *   **역할:** 그래프에 표시할 **제목의 텍스트**를 지정합니다.
    *   **설정된 값의 의미:** 'Target Distribution'은 직역하면 **'타겟(목표) 분포'**라는 뜻입니다. 머신러닝이나 통계 분석에서 예측하고자 하는 데이터(Target)가 어떻게 퍼져있는지 보여주는 그래프임을 나타내기 위해 이 이름을 붙였습니다.

*(참고: 이외에도 글자 크기를 키우는 `fontsize=14`, 위치를 바꾸는 `loc='left'` 등 다양한 추가 인자를 넣을 수 있지만, 가장 기본은 위와 같이 텍스트만 1개 전달하는 것입니다.)*

---

### 3. 📤 반환값/할당 변수
`set_title` 함수는 그래프의 제목을 설정하는 **동작(Action)**을 수행한 후, 내부적으로 설정된 제목 객체를 반환합니다. 

*   하지만 일반적인 데이터 분석 코드에서는 이 반환값을 따로 변수에 저장(할당)해서 쓰지 않고, 그냥 **함수를 실행하는 것 자체(`axes[0, 0].set_title(...)`)로 목적이 달성**됩니다.

---

### 4. 🎁 요약 및 실행 예시

**💡 한 줄 요약**
> `axes[0, 0].set_title('Target Distribution')`은 **"첫 번째 행, 첫 번째 열에 있는 그래프의 이름을 'Target Distribution'(타겟 분포)이라고 지어줘!"** 라는 뜻입니다.

**💻 초보자를 위한 따라 하기 쉬운 전체 실행 예시**
아래 코드를 복사해서 주피터 노트북이나 파이썬 환경에서 그대로 실행해 보세요!

```python
import matplotlib.pyplot as plt

# 1. 1행 2열짜리 도화지(Figure)와 그래프(Axes) 만들기
fig, axes = plt.subplots(1, 2, figsize=(10, 4))

# 2. 첫 번째 그래프에 제목 설정하기 (오늘 배운 함수!)
axes[0].set_title('First Graph')

# 3. 두 번째 그래프에 제목 설정하기
axes[1].set_title('Second Graph')

# 4. 화면에 보여주기
plt.show()
```

이 코드를 실행하면 나란히 놓인 두 개의 그래프가 생기고, 각각 왼쪽에는 **'First Graph'**, 오른쪽에는 **'Second Graph'**라는 제목이 예쁘게 달리게 됩니다.

# plt.xlabel - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 23:04:20

---

파이썬의 데이터 시각화 라이브러리인 맷플롯립(Matplotlib)에서 사용되는 `plt.xlabel('Predicted')` 코드에 대한 상세 해설입니다.

---

### 1. 📌 함수 개요
`plt.xlabel()`은 **그림(Plot)의 X축(가로축)에 이름(라벨)을 붙여주는 함수**입니다. 그래프를 보는 사람이 X축이 무엇을 나타내는지 쉽게 알 수 있도록 설명글을 추가할 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
현재 코드 `plt.xlabel('Predicted')`에 전달된 인자의 역할과 의미는 다음과 같습니다.

*   **`'Predicted'` (문자열, Positional Argument)**
    *   **역할:** X축에 표시될 텍스트 내용을 지정합니다.
    *   **설정된 값의 의미:** '예측된(Predicted)'이라는 단어를 X축의 이름으로 설정했습니다. 
    *   *참고:* 주로 머신러닝에서 혼동 행렬(Confusion Matrix) 등을 시각화할 때, 모델이 **예측한 값**을 X축에 나타내기 위해 이와 같이 이름을 붙입니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값:** 이 함수는 X축 텍스트를 그린 후, 해당 텍스트를 제어할 수 있는 **`Text` 객체(오브젝트)**를 반환합니다.
*   **할당 변수:** 현재 코드에서는 반환값을 별도의 변수(예: `xlabel = plt.xlabel(...)`)에 담지 않고 바로 버렸습니다. 
*   **이유:** 단순히 X축에 글자만 띄우면 되므로 변수에 저장할 필요가 없기 때문입니다. 만약 글자의 색상을 바꾸거나 크기를 나중에 따로 조절하고 싶다면 변수에 담아서 사용하기도 합니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 주피터 노트북이나 파이썬 파일에서 실행해 볼 수 있는 가장 간단한 예시 코드입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 간단한 데이터를 가지고 산점도(점 그래프)를 그립니다.
plt.plot([1, 2, 3], [4, 5, 6])

# 2. X축과 Y축에 이름을 붙입니다.
plt.xlabel('Predicted')  # X축 이름
plt.ylabel('Actual')     # Y축 이름 (실제값)

# 3. 그래프를 화면에 보여줍니다.
plt.show()
```

**[예상 결과]**
*   창이 하나 뜨면서 선 그래프가 나타납니다.
*   그래프의 **가로축(아래쪽) 중앙에 `Predicted`**라는 글자가 예쁘게 적혀 있는 것을 확인할 수 있습니다.

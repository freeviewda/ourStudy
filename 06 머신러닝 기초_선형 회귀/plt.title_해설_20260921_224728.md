# 🤖 AI 파이썬 학습 노트: plt.title

- **기록 일시**: 2026-09-21 22:47:28
- **대상 코드/함수**: `plt.title`

---

파이썬의 데이터 시각화 라이브러리인 맷플롯립(Matplotlib)에서 사용되는 `plt.title` 함수에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 쉽고 명쾌하게 정리해 드리겠습니다!

---

### 1. 📌 함수 개요
`plt.title()`은 현재 그려지고 있는 그래프의 **상단 중앙에 제목(Title)을 추가해 주는 함수**입니다. 그래프가 무엇을 나타내는지 보는 사람이 직관적으로 이해할 수 있도록 이름을 붙여줄 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `plt.title("원본 Target Distribution")`에서 사용된 인자는 다음과 같습니다.

*   **`"원본 Target Distribution"` (문자열, 위치 인자)**
    *   **역할:** 그래프 상단에 표시될 텍스트 내용을 전달합니다.
    *   **설정된 값의 의미:** 'Target(타겟/정답 데이터)'의 원래 분포(Distribution)를 보여주는 그래프라는 것을 뜻합니다. 한국어와 영어가 섞여 있어, 데이터 분석 과정에서 원본 데이터의 타겟값 분포를 시각화한 그래프임을 한눈에 알 수 있게 해줍니다.
    *   *(참고)* 이 외에도 글자 크기를 키우는 `fontsize`, 글자 색상을 바꾸는 `color`, 위치를 조정하는 `loc` 등 다양한 추가 인자를 함께 사용할 수 있습니다.

---

### 3. 📤 반환값/할당 변수
`plt.title()` 함수는 별도의 데이터를 반환하거나 변수에 할당하여 사용하는 함수가 아닙니다. 

*   **반환값 없음 (`None`):** 이 함수는 그래프 객체에 "제목을 그려라"라는 명령을 내리는 **동작(Action)**을 수행합니다. 따라서 `title = plt.title(...)` 과 같이 변수에 담아 다른 용도로 사용하는 경우는 거의 없습니다.
*   **사용법:** 보통 데이터를 시각화하는 코드 중간에 단독으로 호출되며, 최종적으로 화면에 그래프를 띄우는 `plt.show()`가 실행될 때 지정한 제목이 함께 출력됩니다.

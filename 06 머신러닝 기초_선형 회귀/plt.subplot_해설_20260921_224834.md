# 🤖 AI 파이썬 학습 노트: plt.subplot

- **기록 일시**: 2026-09-21 22:48:34
- **대상 코드/함수**: `plt.subplot`

---

파이썬의 데이터 시각화 라이브러리인 `matplotlib.pyplot`에서 사용되는 `plt.subplot(1, 2, 2)` 코드에 대한 상세 해설입니다.

---

### 1. 📌 함수 개요
`plt.subplot()` 함수는 **전체 도화지(Figure)를 여러 개의 작은 칸(격자)으로 나누어, 특정 칸에 그림을 그리겠다고 지정하는 함수**입니다. 여러 개의 그래프를 하나의 화면에 비교하며 보여줄 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
코드에 전달된 `(1, 2, 2)`는 전체 도화지를 나누는 격자의 구조와 현재 선택할 칸의 위치를 나타냅니다.

*   **첫 번째 인자 (`1`): 행(Row)의 개수**
    *   도화지를 **세로 방향으로 몇 등분**할 것인지를 의미합니다. 여기서는 `1`이므로 세로 방향은 나누지 않고 통째로 씁니다.
*   **두 번째 인자 (`2`): 열(Column)의 개수**
    *   도화지를 **가로 방향으로 몇 등분**할 것인지를 의미합니다. 여기서는 `2`이므로 가로로 2등분합니다.
*   **세 번째 인자 (`2`): 인덱스(Index, 순번)**
    *   위에서 나눈 칸들 중 **몇 번째 칸에 그래프를 그릴지** 선택합니다. 
    *   번호는 왼쪽에서 오른쪽으로, 위에서 아래 순으로 **1부터 시작**합니다. 따라서 `2`는 **"가로 2등분 중 두 번째(오른쪽) 칸"**을 의미합니다.

> **💡 요약하자면:**  
> `plt.subplot(1, 2, 2)`는 *"도화지를 **1행 2열(총 2개 칸)**로 나눈 뒤, 그중 **오른쪽 칸(2번째)**에 앞으로 작성할 그래프를 그리겠다"*는 선언입니다. (보통 바로 이전에 `plt.subplot(1, 2, 1)`을 써서 왼쪽 칸에 첫 번째 그래프를 그렸을 것입니다.)

---

### 3. 📤 반환값/할당 변수
*   **반환값 없음 (None 또는 Subplot 객체)**
    *   이 코드 자체는 변수에 값을 할당(`fig, ax = ...` 형태)하지 않고 단독으로 사용되었습니다.
    *   따라서 특정 데이터를 반환한다기보다, **"현재 그릴 그림의 위치(도화지의 구역)를 바꾸는 상태 변경"**의 역할을 수행합니다. 이 함수를 실행한 직후에 `plt.plot()`이나 `plt.scatter()` 같은 그리기 함수를 쓰면, 지정된 오른쪽 칸에 그래프가 그려지게 됩니다.

# 🤖 AI 파이썬 학습 노트: plt.figure

- **기록 일시**: 2026-09-21 22:46:01
- **대상 코드/함수**: `plt.figure`

---

파이썬 데이터 시각화 라이브러리인 **Matplotlib**에서 사용되는 `plt.figure()` 함수와 코드 문맥에 대한 상세 해설입니다.

---

### 1. 📌 함수 개요
`plt.figure()`는 새로운 그래프(도화지)를 생성하는 함수입니다. 그림의 전체적인 크기나 해상도 등을 설정할 때 사용하며, 이 함수를 호출한 뒤에 `plt.plot()`이나 `plt.scatter()` 같은 그리기 함수를 사용하면 새로운 도화지 위에 그림이 그려지게 됩니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `plt.figure(figsize=(8, 5))`에서 사용된 인자의 역할과 의미는 다음과 같습니다.

*   **`figsize`** (튜플 형태: `(가로 길이, 세로 길이)`)
    *   **역할:** 생성할 그래프(도화지)의 전체 크기를 정합니다.
    *   **설정된 값의 의미 (`(8, 5)`):** 
        *   그래프의 **가로 길이를 8인치(inch)**, **세로 길이를 5인치(inch)** 크기로 설정하겠다는 뜻입니다.
        *   이 값을 조절하면 발표 자료나 보고서에 맞게 넓고 납작한 그래프, 혹은 정사각형 모양의 그래프 등 원하는 비율로 시각화 크기를 바꿀 수 있습니다.

---

### 3. 📤 반환값/할당 변수
질문해주신 코드 문맥(`plt.figure(figsize=(8, 5))`)에서는 별도의 변수에 반환값을 할당하지 않고, **Matplotlib의 현재 작업 공간(Current Figure)에 직접 도화지를 펼치는 방식**으로 사용되었습니다.

*   **반환값:** 이 함수는 생성된 Figure(도화지) 객체를 반환합니다.
*   **활용 예시:** 필요에 따라 다음과 같이 변수에 담아 관리할 수도 있습니다.
    ```python
    fig = plt.figure(figsize=(8, 5))
    ```
    이렇게 변수 `fig`에 담아두면, 나중에 그림 전체를 저장(`fig.savefig()`)하거나 세부 설정을 변경할 때 유용하게 사용할 수 있습니다.

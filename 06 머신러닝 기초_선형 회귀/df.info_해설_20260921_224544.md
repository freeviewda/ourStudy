# 🤖 AI 파이썬 학습 노트: df.info

- **기록 일시**: 2026-09-21 22:45:44
- **대상 코드/함수**: `df.info`

---

파이썬 데이터 분석 라이브러리인 판다스(Pandas)에서 자주 사용되는 `df.info()` 함수에 대해 초보자의 눈높이에 맞춰 친절하고 명쾌하게 해설해 드리겠습니다.

---

### 1. 📌 함수 개요
`df.info()`는 판다스 데이터프레임(DataFrame)의 **전반적인 구조와 요약 정보를 한눈에 확인할 수 있도록 출력해 주는 함수**입니다. 데이터 분석을 시작할 때 데이터가 잘 불러와졌는지, 결측치(누락된 데이터)나 잘못된 데이터 타입은 없는지 가장 먼저 파악하는 용도로 사용됩니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `df.info()` 안을 살펴보면 **괄호 안에 아무런 값(인자)도 전달되지 않은 것**을 볼 수 있습니다. 

* **인자 없음 (`()`)**: 
  * `df.info()`는 기본적으로 사용자가 특별한 설정을 하지 않아도 알아서 데이터프레임의 요약 정보를 척척 보여줍니다.
  * (참고) 만약 데이터의 메모리 사용량을 더 정확하게 계산하고 싶거나 세부적인 조절을 원할 때 쓰는 숨겨진 옵션들(`verbose`, `memory_usage` 등)이 있기는 하지만, 초보 단계에서는 **"인자 없이 빈 괄호로 실행해 전체 요약을 보는 함수"**로 기억하시면 충분합니다.

---

### 3. 📤 반환값/할당 변수
`display(df.info())` 형태로 코드가 작성되어 있지만, 사실 **`df.info()`는 반환값(return value)이 없는 함수**입니다.

* **반환값이란?**: 함수가 일을 끝낸 후 우리에게 돌려주는 결과물을 뜻합니다. 예를 들어 어떤 함수는 계산된 숫자를 돌려주기도 합니다.
* **`None` 반환**: `df.info()`는 화면(콘솔이나 주피터 노트북)에 표 형태의 텍스트 요약 정보를 '출력'해 줄 뿐, 코드 내부적으로 저장하거나 돌려주는 데이터는 없습니다. (파이썬에서는 결과물이 없을 때 `None`을 돌려준다고 표현합니다.)
* 따라서 이 함수는 어떤 변수에 결과를 할당(`result = df.info()`)하여 사용할 수 없으며, 화면에 정보를 띄워 눈으로 확인하는 용도로만 쓰입니다. `display()` 함수로 감싸져 있는 경우, 주피터 노트북 환경에서 요약 정보를 더 깔끔하게 보여주기 위한 용도입니다.

---

### 💡 덤으로 보는 `df.info()`가 출력해 주는 내용 (초보자용 팁)
이 함수를 실행하면 화면에 아래와 같은 정보들이 나타납니다. 무엇을 의미하는지 가볍게 알아두세요!

1. **RangeIndex**: 데이터프레임의 행(Row) 개수가 몇 개인지 알려줍니다. (예: `0 to 891` -> 총 892개의 행이 있음)
2. **Data columns**: 총 열(Column, 변수)이 몇 개인지 알려줍니다.
3. **Non-Null Count**: 각 열에 **'값이 들어있는(비어있지 않은) 개수'**를 뜻합니다. 전체 행 개수와 이 숫자가 다르면, 빈 칸(결측치)이 존재한다는 뜻이므로 정화 작업(데이터 전처리)이 필요합니다.
4. **Dtype**: 각 열에 들어있는 데이터의 형식(숫자형, 문자형 등)을 보여줍니다. (예: `int64`는 정수, `float64`는 실수, `object`는 주로 문자열을 의미합니다.)

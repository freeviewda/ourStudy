# len - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 22:34:43

---

파이썬에서 자주 사용되는 `len` 함수와 해당 코드 문맥(`if len(negative_indices) > 0:`)에 대한 상세 해설입니다. 초보자분들도 쉽게 이해하실 수 있도록 단계별로 정리해 드릴게요!

---

### 1. 📌 함수 개요
`len`은 파이썬의 내장 함수(Built-in Function)로, **문자열, 리스트, 튜플, 딕셔너리 등 데이터의 길이(항목의 개수)를 세어주는 역할**을 합니다. 영어 단어 **'Length(길이)'**의 줄임말입니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `len(negative_indices)`에서 괄호 안(`()`)에 들어가는 값은 함수에 전달되는 입력 인자입니다.

*   **`negative_indices` (음수 인덱스들)**
    *   **역할:** 데이터 안에서 '음수 값'이 발견된 위치(인덱스)들을 모아놓은 **리스트(List)** 또는 **배열(Array)**입니다.
    *   **의미:** 예를 들어 어떤 데이터 처리 결과, 음수가 총 3개 발견되었다면 이 변수 안에는 `[2, 5, 12]`와 같이 음수가 있는 위치 정보 3개가 담기게 됩니다.

---

### 3. 📤 반환값/할당 변수
`len` 함수는 인자로 받은 데이터의 개수를 **정수(Integer)** 형태로 반환(결과로 출력)합니다.

*   **반환값:** `negative_indices` 리스트에 들어있는 **항목의 개수 (정수)**
    *   만약 리스트가 비어있다면(`[]`), 반환값은 `0`이 됩니다.
    *   만약 리스트에 값이 3개 있다면(`[2, 5, 12]`), 반환값은 `3`이 됩니다.
*   **코드 전체의 의미 (`if len(negative_indices) > 0:`):**
    *   "만약 `negative_indices`에 들어있는 항목의 개수가 0보다 크다면(즉, 음수가 **하나라도 존재한다면**)"이라는 뜻의 조건문입니다. 음수가 발견되었을 때 경고를 주거나 후속 조치를 취하기 위해 자주 사용됩니다.

---

### 4. 🎁 요약 및 실행 예시
백문이 불여일견! 아래의 간단한 코드를 직접 복사해서 파이썬 환경에서 실행해 보세요. `len` 함수가 어떻게 동작하는지 한눈에 이해할 수 있습니다.

**[실행 코드]**
```python
# 음수 인덱스들이 담겨있는 리스트라고 가정해 봅시다.
negative_indices = [3, 7, 15]

# 리스트의 길이를 잼
length = len(negative_indices)
print(f"리스트에 들어있는 항목의 개수: {length}")

# 제시해주신 조건문 활용 예시
if len(negative_indices) > 0:
    print("⚠️ 경고: 데이터 안에 음수가 존재합니다!")
else:
    print("✅ 정상: 모든 데이터가 0 이상입니다.")
```

**[예상 결과]**
```text
리스트에 들어있는 항목의 개수: 3
⚠️ 경고: 데이터 안에 음수가 존재합니다!
```

# len - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 22:40:26

---

제시해주신 파이썬 코드 문맥(`print(f"\n잘못 예측된 샘플 수: {len(misclassified)}개 ({len(misclassified)/len(y_test)*100:.1f}%)")`)에서 사용된 **`len` 함수**에 대해 초보자의 눈높이에 맞춰 아주 쉽고 친절하게 해설해 드릴게요!

---

### 1. 📌 함수 개요
`len` 함수는 파이썬의 **내장 함수(Built-in Function)**로, 리스트, 문자열, 튜플 등 **여러 개의 데이터를 담고 있는 객체의 길(개수)을 세어주는 역할**을 합니다. 마치 상자 안에 물건이 몇 개 들어있는지 세어보는 것과 같습니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시된 코드에서는 `len` 함수가 총 2번 사용되었으며, 각각 다음과 같은 인자를 받았습니다.

* **첫 번째 사용 (`len(misclassified)`)**
  * **전달된 인자:** `misclassified`
  * **의미:** 머신러닝 모델이 **틀리게 예측한 데이터(샘플)들의 모음(리스트 또는 배열)**입니다.
  * **역할:** `len()`은 이 `misclassified` 상자 안에 들어있는 **틀린 데이터의 총 개수**를 세어줍니다. (예: 15개 틀렸다면 15를 반환)

* **두 번째 사용 (`len(y_test)`)**
  * **전달된 인자:** `y_test`
  * **의미:** 테스트를 위해 따로 빼두었던 **전체 정답 데이터들의 모음**입니다.
  * **역할:** 전체 테스트 데이터가 총 몇 개인지를 세어줍니다. 이를 통해 뒤에 나오는 코드(`len(misclassified)/len(y_test)*100`)에서 **"전체 데이터 중 틀린 데이터의 비율(오차율, %)"**을 계산하는 분모로 사용됩니다.

---

### 3. 📤 반환값/할당 변수
`len` 함수는 복잡한 데이터 구조를 반환하지 않고, 아주 직관적인 결과를 줍니다.

* **반환값:** 항상 **정수(Integer, `int`)** 형태의 숫자 하나를 반환합니다. 
* **코드 내 활용:** 
  * `len(misclassified)`는 틀린 개수(예: `15`)를 반환하여 출력 문구의 `잘못 예측된 샘플 수: 15개`를 완성합니다.
  * `len(misclassified) / len(y_test) * 100`은 `(틀린 개수 / 전체 개수 * 100)`을 계산하여 백분율(예: `5.2%`)을 구하는 데 사용됩니다.

---

### 4. 🎁 요약 및 실행 예시
`len` 함수가 어떻게 동작하는지 파이썬 코드로 직접 확인해 볼까요?

**[실행 코드]**
```python
# 전체 테스트 정답 (총 5개)
y_test = [0, 1, 1, 0, 1]

# 모델이 틀리게 예측한 샘플들 (총 2개)
misclassified = [1, 3]

# len 함수로 개수 세기
wrong_count = len(misclassified) # 2
total_count = len(y_test)        # 5

# 비율 계산
error_rate = (wrong_count / total_count) * 100

# 결과 출력
print(f"잘못 예측된 샘플 수: {wrong_count}개 ({error_rate:.1f}%)")
```

**[예상 결과]**
```text
잘못 예측된 샘플 수: 2개 (40.0%)
```

> **💡 한 줄 요약:** `len()`은 데이터의 **개수를 세어주는 마법의 자(Ruler)** 같은 존재로, 머신러닝에서는 모델의 성능이나 틀린 데이터의 비율을 계산할 때 필수적으로 사용됩니다!

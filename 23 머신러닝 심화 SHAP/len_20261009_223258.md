# len - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 22:32:58

---

파이썬 코드에서 사용된 `len` 함수와 인자에 대한 상세 해설을 초보자의 눈높이에 맞춰 친절하게 정리해 드리겠습니다.

---

### 1. 📌 함수 개요
`len` 함수는 파이썬의 **내장 함수(Built-in Function)**로, 리스트, 문자열, 튜플 등 **여러 개의 데이터를 담고 있는 객체의 길이(아이템의 개수)**를 세어 반환해 줍니다. 
위 코드에서는 `positive_indices`라는 데이터 모음 안에 과연 데이터가 몇 개 들어있는지(비어있지 않은지)를 확인하기 위해 사용되었습니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
위 코드에서 `len()` 괄호 안에 전달된 인자는 단 하나입니다.

*   **`positive_indices`**
    *   **역할:** 양수(Positive) 값들이 위치한 인덱스(번호)들의 목록을 담고 있는 **리스트(List)** 또는 이와 유사한 데이터 구조입니다.
    *   **의미:** 예를 들어 이 변수에 `[2, 5, 7]`이라는 값이 들어있다면, 이는 전체 데이터 중 2번, 5번, 7번 위치에 양수가 있다는 뜻입니다. `len()`은 이 리스트의 아이템 개수인 `3`을 계산해 내기 위해 이 인자를 입력받습니다.

---

### 3. 📤 반환값/할당 변수
`len()` 함수는 계산된 길이를 정수(Integer) 형태로 반환합니다.

*   **반환값:** `positive_indices` 리스트에 들어있는 **아이템의 총 개수 (정수형, 예: `0`, `3`, `15` 등)**
*   **코드 내에서의 활용:** 
    `if len(positive_indices) > 0:` 은 직역하면 **"양수 인덱스의 개수가 0보다 크다면?"** 이라는 뜻입니다. 즉, "데이터 안에 양수가 최소한 1개 이상 존재한다면"이라는 조건을 체크하는 안전장치(예외 처리)로 자주 사용됩니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 파이썬 인터프리터나 파일에서 실행해 보고 감을 잡을 수 있는 간단한 예시 코드입니다.

**[실행 코드]**
```python
# 양수들의 위치(인덱스)를 담고 있다고 가정하는 리스트
positive_indices = [3, 7, 12]

# 리스트의 길이를 구해서 0보다 큰지 확인
if len(positive_indices) > 0:
    print(f"양수가 총 {len(positive_indices)}개 존재합니다!")
else:
    print("양수가 하나도 없습니다.")
```

**[예상 결과]**
```text
양수가 총 3개 존재합니다!
```

> **💡 팁:** 만약 `positive_indices = []` (빈 리스트)였다면, `len()`은 `0`을 반환하므로 `0 > 0`은 거짓(`False`)이 되어 `else` 구문이 실행되었을 것입니다.

# accuracy_score - AI 파이썬 학습 노트

---

파이썬 머신러닝에서 가장 자주 쓰이는 평가 지표 중 하나인 `accuracy_score` 함수에 대해 초보자의 눈높이에 맞춰 쉽고 명쾌하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`accuracy_score`는 머신러닝 모델이 예측한 결과가 실제 정답과 얼마나 일치하는지, 즉 **'정확도(Accuracy)'를 계산해 주는 함수**입니다. 전체 데이터 중 모델이 맞춘 데이터의 비율을 0과 1 사이의 값(또는 0%~100%)으로 반환합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제공해주신 코드 `accuracy_score(y_test, lgbm_pred)`에서 사용된 두 가지 인자의 역할은 다음과 같습니다.

*   **첫 번째 인자: `y_test` (실제 정답)**
    *   **역할:** 모델이 맞추어야 하는 **실제 진짜 정답 데이터**입니다.
    *   **의미:** 테스트 셋(Test Set)의 실제 라벨(Label/Target) 값들이 들어있는 리스트나 판다스(Pandas) 시리즈 형태의 데이터입니다.
*   **두 번째 인자: `lgbm_pred` (모델의 예측값)**
    *   **역할:** LightGBM(`lgbm`) 모델이 학습 후 **예측해 낸 결과 값**입니다.
    *   **의미:** `y_test`와 1:1로 대응되는 모델의 예측 결과(예: 0 또는 1, 혹은 분류된 클래스 번호)가 담긴 데이터입니다.

> 💡 **핵심 포인트:** `accuracy_score`는 **"진짜 정답(`y_test`)"**과 **"모델이 푼 답안(`lgbm_pred`)"**을 나란히 놓고, 몇 개나 맞았는지 비교 채점하는 선생님 같은 역할을 합니다.

---

### 3. 📤 반환값/할당 변수
*   **할당 변수: `lgbm_acc`**
    *   **역할:** `accuracy_score` 함수가 계산을 끝내고 돌려주는 **최종 정확도 점수(실수형, Float)**를 저장하는 변수입니다.
    *   **의미:** 예를 들어 값이 `0.85`로 나왔다면, 모델이 전체 테스트 데이터 중 **85%를 맞췄다**는 뜻입니다. (최소 0.0에서 최대 1.0 사이의 값을 가집니다.)

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 코드를 실행해 감을 잡을 수 있도록 아주 간단한 예시를 준비했습니다.

**[코드 예시]**
```python
from sklearn.metrics import accuracy_score

# 1. 진짜 정답 (y_test)
y_test = [0, 1, 1, 0, 1]

# 2. 모델이 예측한 값 (lgbm_pred) -> 5개 중 4개를 맞춘 상황
lgbm_pred = [0, 1, 0, 0, 1]

# 3. 정확도 계산하기
lgbm_acc = accuracy_score(y_test, lgbm_pred)

# 4. 결과 출력
print(f"모델의 정확도: {lgbm_acc}")
print(f"백분율(%): {lgbm_acc * 100}%")
```

**[예상 결과]**
```text
모델의 정확도: 0.8
백분율(%): 80.0%
```
*(해설: 5개의 문제 중 3번째 값(`1`을 `0`으로 예측)을 틀렸기 때문에, 4/폭 = 0.8 즉 80%의 정확도가 출력됩니다.)*

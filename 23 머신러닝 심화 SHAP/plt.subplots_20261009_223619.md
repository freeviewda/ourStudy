파이썬 데이터 분석 및 시각화에서 가장 많이 쓰이는 라이브러리인 **Matplotlib**의 `plt.subplots` 함수에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 하나씩 친절하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`plt.subplots()`는 **여러 개의 그래프(도화지)를 한 번에 그리기 위해 판(Figure)과 각각의 그래프 공간(Axes)을 동시에 만들어주는 함수**입니다. 하나의 큰 도화지 위에 여러 개의 작은 칸을 나눠서 각각 다른 그래프를 그리고 싶을 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `plt.subplots(1, 3, figsize=(18, 5))`에 사용된 3개의 인자별 역할과 의미는 다음과 같습니다.

*   **첫 번째 인자 (`1`) : 행(Row)의 개수**
    *   생성할 그래프 판을 세로로 몇 줄로 나눌지 결정합니다. 여기서는 `1`이므로 그래프를 **가로로 1줄** 배치하겠다는 뜻입니다.
*   **두 번째 인자 (`3`) : 열(Column)의 개수**
    *   생성할 그래프 판을 가로로 몇 칸으로 나낼지 결정합니다. 여기서는 `3`이므로 **3개의 칸**으로 나눈다는 뜻입니다.
    *   *결과적으로 `1, 3`을 조합하면 1행 3열, 즉 **나란히 3개의 그래프가 들어갈 공간**이 만들어집니다.*
*   **`figsize=(18, 5)` : 전체 그림의 크기 (Width, Height)**
    *   생성되는 전체 도화지의 가로·세로 크기를 인치(inch) 단위로 설정합니다. 
    *   여기서는 **가로 18인치, 세로 5인치** 크기의 넓고 납작한 도화지를 만들라는 의미입니다. 그래프 3개가 나란히 들어가야 하므로 가로를 넓게(18) 설정한 것입니다.

---

### 3. 📤 반환값/할당 변수
`fig, axes = plt.subplots(...)` 형태로 호출하면 파이썬의 **언패킹(Unpacking)** 기능을 통해 2개의 서로 다른 객체가 각각 `fig`와 `axes` 변수에 담깁니다.

*   **`fig` (Figure 객체): 전체 도화지**
    *   그래프 전체를 담는 커다란 배경(판)입니다. 전체 제목(Suptitle)을 달거나, 저장(`plt.savefig()`)할 때 주로 이 `fig` 객체를 조작합니다.
*   **`axes` (Axes 객체들의 묶음): 개별 그래프 공간**
    *   실제 데이터(선 그래프, 막대 그래프 등)를 그려 넣을 수 있는 **작은 그래프 공간들의 모음**입니다. 
    *   여기서는 그래프를 3개 만들었기 때문에, `axes`는 3개의 공간을 담고 있는 **배열(리스트 형태)**이 됩니다. (`axes[0]`, `axes[1]`, `axes[2]`로 각각 접근하여 그림을 그립니다.)

---

### 4. 🎁 요약 및 실행 예시

초보자분들이 복사해서 바로 실행해 볼 수 있는 간단한 전체 코드와 설명입니다.

```python
import matplotlib.pyplot as plt

# 1. 1행 3열짜리 그래프 공간과 가로 18, 세로 5 크기의 도화지 생성
fig, axes = plt.subplots(1, 3, figsize=(18, 5))

# 2. 첫 번째 칸에 그래프 그리기
axes[0].plot([1, 2, 3], [1, 4, 9])
axes[0].set_title("First Graph")

# 3. 두 번째 칸에 그래프 그리기
axes[1].bar(["A", "B", "C"], [3, 7, 5])
axes[1].set_title("Second Graph")

# 4. 세 번째 칸에 그래프 그리기
axes[2].scatter([1, 2, 3], [3, 2, 1])
axes[2].set_title("Third Graph")

# 5. 화면에 출력하기
plt.show()
```

**💡 실행 결과 요약:**
*   화면에 **가로로 긴 하나의 큰 창**이 뜹니다.
*   그 창 안에는 **왼쪽(선 그래프), 가운데(막대 그래프), 오른쪽(산점도 그래프)** 이렇게 총 3개의 그래프가 나란히 예쁘게 배치되어 나타납니다.

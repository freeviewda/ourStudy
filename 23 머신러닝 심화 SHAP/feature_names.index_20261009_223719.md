# feature_names.index - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 22:37:19

---

파이썬 코드에서 사용된 **`feature_names.index(feature2)`**에 대해 초보자의 눈높이에 맞춰 아주 쉽고 친절하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`.index()`는 파이썬의 **리스트(List)**에서 아주 자주 쓰이는 기본 기능(메서드)입니다. 
괄호 안에 찾고 싶은 값을 넣으면, **그 값이 리스트 안에서 몇 번째(몇 번 인덱스)에 들어있는지 그 위치(숫자)를 찾아주는 역할**을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
이 코드에서 사용된 인자는 괄호 안에 들어있는 **`feature2`** 하나입니다.

* **`feature2` (찾을 값)**
  * **역할:** `feature_names`라는 이름의 목록(리스트) 안에서 위치를 찾아내고 싶은 **특정 특성(변수)의 이름**입니다.
  * **의미:** 예를 들어 머신러닝 모델에서 "나이", "소득", "키" 같은 특성 이름들이 쭉 들어있는 리스트가 있다면, 그중에서 `feature2`에 저장된 글자(예: `"소득"`)가 정확히 몇 번째 칸에 들어있는지 찾겠다는 뜻입니다.

---

### 3. 📤 반환값/할당 변수
함수가 실행된 결과로 무엇이 나오며, 어느 변수에 담기는지 살펴볼까요?

* **반환값 (Index 번호):** 
  * 파이썬은 숫자를 **0부터 세기 시작**합니다. 
  * 만약 `feature2`가 리스트의 맨 첫 번째에 있다면 `0`, 두 번째에 있다면 `1`이라는 **정수(Integer) 숫자**를 결과로 돌려줍니다.
* **할당 변수 (`feature2_idx`):**
  * `.index()`가 찾아낸 그 위치 번호(숫자)를 왼쪽의 **`feature2_idx`**라는 이름의 변수에 쏙 담아둡니다.
  * 변수 이름 끝에 붙은 `_idx`는 'Index(색인/번호)'의 약자로, **"아, 이 변수에는 위치 번호가 들어있구나!"**라고 초보자가 쉽게 알아볼 수 있게 지은 이름입니다.

---

### 4. 🎁 요약 및 실행 예시
말로만 들으면 어려우니, 직접 코드를 돌려본다고 생각하고 살펴봅시다!

**[파이썬 실습 코드]**
```python
# 1. 특성 이름들이 들어있는 리스트 준비
feature_names = ['나이', '소득', '키', '몸무게']

# 2. 찾고 싶은 특성 이름 지정
feature2 = '키'

# 3. .index() 함수 호출
feature2_idx = feature_names.index(feature2)

# 4. 결과 확인
print(f"'{feature2}'의 위치는 {feature2_idx}번째 입니다.")
```

**[예상 결과]**
```text
'키'의 위치는 2번째 입니다.
```
*(파이썬은 0부터 세므로: '나이'=0, '소득'=1, **'키'=2**, '몸무게'=3 이 되어 결과로 `2`가 나옵니다!)*

---

💡 **한 줄 요약:** 
`feature2_idx = feature_names.index(feature2)`는 **"특성 목록(`feature_names`)에서 `feature2`라는 이름이 정확히 몇 번째 칸에 들어있는지 찾아내어 그 번호를 `feature2_idx`에 저장한다"**는 뜻입니다!

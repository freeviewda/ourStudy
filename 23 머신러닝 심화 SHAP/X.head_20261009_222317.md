요청하신 `X.head()` 함수에 대한 상세 해설입니다. 데이터 분석 필수 라이브러리인 **판다스(Pandas)**를 기준으로 초보자 눈높이에 맞춰 작성했습니다.

---

### 1. 📌 함수 개요
`X.head()`는 데이터프레임(DataFrame)이나 시리즈(Series)의 **상위(맨 위) 데이터 몇 개만 쏙 뽑아서 눈으로 확인(미리보기)**할 때 사용하는 함수입니다. 데이터가 수천, 수만 개로 매우 클 때 전체를 다 출력하지 않고 구조를 빠르게 파악하기 위해 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
현재 작성된 코드 `X.head()`의 괄호 안은 비어 있습니다. 이는 **기본값(Default)**을 사용하겠다는 의미입니다.

* **`n` (기본값: `5`)**: 
  * 불러올 **행(Row)의 개수**를 지정하는 인자입니다.
  * 현재 코드에서는 아무 값도 넣지 않았으므로, **기본 설정값인 '상위 5개 행'**을 가져오게 됩니다.
  * *(참고)* 만약 상위 3개만 보고 싶다면 `X.head(3)`, 10개를 보고 싶다면 `X.head(10)`과 같이 숫자(인자)를 전달하면 됩니다.

---

### 3. 📤 반환값/할당 변수
* **반환값 (Return Value)**: 원본 데이터 `X`에서 지정한 개수(기본 5개)만큼의 행만 잘라낸 **새로운 데이터프레임(또는 시리즈)**을 반환합니다.
* **원본 유지**: 이 함수를 실행해도 원본 데이터인 `X` 자체는 **절대 변하거나 삭제되지 않습니다.**
* **코드에서의 동작**: `print(X.head())`는 반환된 상위 5개의 데이터를 변수에 저장하지 않고, **콘솔 화면에 바로 출력**해 줍니다.

---

### 4. 🎁 요약 및 실행 예시

파이썬 환경(Jupyter Notebook, VS Code 등)에서 직접 실행해 볼 수 있는 코드입니다.

#### 💻 실행 코드
```python
import pandas as pd

# 1. 6개의 데이터가 들어있는 가상의 데이터프레임(X) 생성
data = {
    "이름": ["김철수", "이영희", "박민수", "정지민", "최동현", "강수진"],
    "국어점수": [85, 92, 78, 95, 88, 90],
    "수학점수": [90, 88, 85, 100, 75, 92],
}
X = pd.DataFrame(data)

# 2. X.head() 실행 및 출력 (전체 6개 중 상위 5개만 출력됨)
print(X.head())
```

#### 🖥️ 예상 출력 결과
```text
    이름  국어점수  수학점수
0  김철수    85    90
1  이영희    92    88
2  박민수    78    85
3  정지민    95   100
4  최동현    88    75
```
*(마지막 5번째 데이터인 '강수진' 행은 출력되지 않고 상위 5개[0~4번 인덱스]만 깔끔하게 출력됩니다.)*

# ax.set_title - AI 파이썬 학습 노트

---

파이썬의 시각화 라이브러리인 **Matplotlib**에서 사용되는 `ax.set_title` 코드에 대한 상세 해설입니다. 초보자분들도 쉽게 이해하실 수 있도록 항목별로 차근차근 설명해 드릴게요!

---

### 1. 📌 함수 개요
`ax.set_title`은 **그래프의 제목(Title)을 설정해 주는 함수**입니다. 그래프가 무엇을 나타내는지 한눈에 알아볼 수 있도록 상단에 텍스트를 띄워주는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드에서는 총 3개의 인자가 사용되었습니다. 하나씩 뜯어볼까요?

*   **`'Feature Importance Comparison (3 Models)'` (첫 번째 위치 인자)**
    *   **역할:** 그래프 상단에 표시될 **실제 텍스트**입니다.
    *   **의미:** "3개 모델의 특성 중요도 비교"라는 뜻으로, 이 그래프가 어떤 데이터를 비교하고 있는지 보는 사람에게 알려줍니다.
*   **`fontsize=14`**
    *   **역할:** 글자의 **크기(Font Size)**를 조절합니다.
    *   **의미:** 기본 크기보다 조금 더 크게 설정하여(14포인트), 제목이 그래프 안에서 눈에 잘 띄도록 만들었습니다.
*   **`fontweight='bold'`**
    *   **역할:** 글자의 **두께(Font Weight)**를 조절합니다.
    *   **의미:** `'bold'`를 지정하여 글자를 **굵게** 만들었습니다. 제목에 힘을 주어 강조하는 효과가 있습니다.

---

### 3. 📤 반환값/할당 변수
*   `ax.set_title(...)` 함수는 특별한 데이터를 변수에 담아 반환하는 대신, 우리가 지정한 설정값을 **그래프(`ax`) 객체 자체에 직접 적용**합니다. 
*   따라서 별도의 변수에 대입(`result = ...`)할 필요 없이, 이 함수를 실행하는 것만으로 화면에 그려질 그래프의 제목이 꾸며집니다.

---

### 4. 🎁 요약 및 실행 예시
백문이 불여일견! 초보자분들도 Jupyter Notebook이나 파이썬 환경에서 복사해서 바로 실행해 볼 수 있는 가장 간단한 전체 예시 코드를 준비했습니다.

```python
import matplotlib.pyplot as plt

# 1. 도화지(fig)와 축(ax) 만들기
fig, ax = plt.subplots(figsize=(6, 4))

# 2. 간단한 막대그래프 그리기 (예시 데이터)
ax.bar(['Model A', 'Model B', 'Model C'], [0.8, 0.6, 0.9])

# 3. 오늘의 핵심 함수 사용하기!
ax.set_title('Feature Importance Comparison (3 Models)', fontsize=14, fontweight='bold')

# 4. 그래프 화면에 띄우기
plt.show()
```

**💡 예상 결과:**
창이 하나 뜨면서 아래와 같은 그래프가 나타납니다.
*   그래프 맨 위 중앙에 **"Feature Importance Comparison (3 Models)"** 라는 문구가 뜹니다.
*   글자 크기는 시원시원하며(**14px**), 굵은 글씨(**Bold**)로 강조되어 전문가가 만든 리포트 같은 깔끔한 느낌을 줍니다.

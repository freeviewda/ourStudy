# plt.title - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 22:37:36

---

파이썬의 시각화 라이브러리인 맷플롯립(Matplotlib)에서 사용되는 `plt.title` 함수에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 하나씩 친절하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`plt.title()`은 현재 그려지고 있는 그래프의 **상단 중앙에 제목(Title)을 추가해 주는 함수**입니다. 그래프가 무엇을 나타내는지 보는 사람이 직관적으로 이해할 수 있도록 이름을 지어줄 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드에서 사용된 인자들은 다음과 같습니다.

*   **첫 번째 위치 인자: `f'Interaction: {feature1} vs {feature2}'`**
    *   **역할:** 그래프에 표시될 텍스트(제목 내용)를 지정합니다.
    *   **값의 의미:** 파이썬의 f-string(포맷 문자열)을 사용하여, 변수 `feature1`과 `feature2`에 담긴 실제 데이터 이름을 문자열 안에 쏙 집어넣습니다. 예를 들어 두 변수가 각각 'Age'와 'Income'이라면, 제목은 **"Interaction: Age vs Income"**(두 특성 간의 상호작용)으로 동적으로 생성됩니다.
*   **키워드 인자: `fontsize=14`**
    *   **역할:** 제목 글자의 크기(Font Size)를 조절합니다.
    *   **값의 의미:** 기본 크기보다 조금 더 크게(`14` 포인트) 설정하여, 그래프 제목이 눈에 잘 띄도록 만듭니다.
*   **키워드 인자: `fontweight='bold'`**
    *   **역할:** 글자의 굵기(Font Weight)를 조절합니다.
    *   **값의 의미:** `'bold'`를 지정하여 제목 글씨를 **진하게** 만듭니다. 그래프 전체의 완성도와 가독성을 높여줍니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값:** `plt.title()` 함수는 설정된 텍스트 객체(`matplotlib.text.Text`)를 반환합니다.
*   **할당 변수:** 제시된 코드에서는 이 반환값을 따로 변수에 저장하지 않고(`title_obj = plt.title(...)` 처럼 쓰지 않음), 단순히 함수를 실행하여 **그래프에 제목을 바로 렌더링(출력)**하는 용도로만 사용했습니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 주피터 노트북이나 파이썬 파일에서 직접 복사해서 실행해 볼 수 있는 간단한 전체 코드 예시입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 예시 변수 정의
feature1 = 'Age'
feature2 = 'Income'

# 2. 간단한 더미 그래프 생성 (실행을 위해 필요)
plt.plot([1, 2, 3], [4, 5, 6])

# 3. 해설 대상 코드 실행
plt.title(f'Interaction: {feature1} vs {feature2}',
          fontsize=14, fontweight='bold')

# 4. 그래프 화면에 출력
plt.show()
```

**[예상 결과]**
*   창이 뜨거나 주피터 노트북 아래에 선 그래프가 그려집니다.
*   그래프 맨 위 중앙에 **"Interaction: Age vs Income"** 이라는 문구가 **굵고(bold) 큼직하게(14pt)** 나타나게 됩니다.

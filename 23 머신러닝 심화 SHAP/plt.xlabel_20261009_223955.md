---

### 1. 📌 함수 개요
`plt.xlabel`은 파이썬의 시각화 라이브러리인 **Matplotlib**에서 **그래프의 x축 제목(이름)을 설정**하는 함수입니다. 그래프를 보는 사람이 x축이 무엇을 나타내는지 쉽게 이해할 수 있도록 설명글을 달아주는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제공해주신 코드 `plt.xlabel('Predicted', fontweight='bold')`에서 사용된 두 개의 인자를 하나씩 뜯어볼까요?

*   **첫 번째 위치 인자: `'Predicted'`**
    *   **역할:** x축에 표시할 텍스트(이름)를 지정합니다.
    *   **의미:** 여기서는 '예측값'을 뜻하는 `'Predicted'`라는 문자열을 전달하여, x축 레이블에 이 단어가 나타나도록 설정했습니다. (주로 머신러닝의 혼동 행렬(Confusion Matrix) 등을 그릴 때 예측된 클래스를 x축에 놓을 때 자주 사용됩니다.)
*   **키워드 인자: `fontweight='bold'`**
    *   **역할:** 글자의 굵기(weight)를 설정합니다.
    *   **의미:** `'bold'` 값을 주어 x축 글씨를 **굵게(두껍게)** 강조했습니다. 그래프의 제목이나 축 이름을 눈에 띄게 만들고 싶을 때 유용합니다. (이 외에도 `'normal'`, `'light'` 등의 값을 사용할 수 있습니다.)

---

### 3. 📤 반환값/할당 변수
*   **반환값 없음 (None)**
    *   이 함수는 별도의 데이터를 반환(return)하지 않고, 현재 활성화된 그래프의 x축 레이블 설정을 곧바로 변경(수정)합니다. 따라서 `x = plt.xlabel(...)`처럼 변수에 결과를 담아 사용할 일은 거의 없습니다.

---

### 4. 🎁 요약 및 실행 예시
백문이 불여일견! 아래의 아주 간단한 코드를 복사해서 직접 실행해 보세요. x축에 굵은 글씨로 'Predicted'가 나타나는 것을 확인할 수 있습니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 간단한 빈 그래프 생성 (데이터는 임의로 설정)
plt.plot([1, 2, 3], [4, 5, 6])

# 2. x축 이름 지정 및 굵기 설정 (오늘 배운 함수!)
plt.xlabel('Predicted', fontweight='bold')

# 3. y축 이름도 세트로 지정해보기
plt.ylabel('Actual', fontweight='bold')

# 4. 그래프 화면에 띄우기
plt.show()
```

**[예상 결과]**
*   화면에 선 그래프가 나타납니다.
*   **x축 아래쪽**에는 **굵은 글씨**로 **`Predicted`** 라는 글자가 적힙니다.
*   **y축 왼쪽**에는 **굵은 글씨**로 **`Actual`** 이라는 글자가 적힙니다.

이제 `plt.xlabel`이 어떤 일을 하는지 완벽하게 이해하셨죠? 앞으로 그래프를 그리실 때 축 이름을 예쁘게 꾸미는 데 적극적으로 활용해 보세요!

# plt.title - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 22:29:44

---

파이썬의 대표적인 데이터 시각화 라이브러리인 **Matplotlib**(`matplotlib.pyplot`)에서 사용된 `plt.title()` 함수에 대한 상세 해설입니다.

---

### 1. 📌 함수 개요
`plt.title()`은 현재 생성된 그래프의 **상단 중앙에 제목(Title)을 추가해 주는 함수**입니다. 그래프가 무엇을 나타내는지 보는 사람이 직관적으로 이해할 수 있도록 이름을 붙여줄 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
코드에 사용된 4개의 인자가 각각 어떤 역할을 하는지 하나씩 살펴볼까요?

* **`'CatBoost - Mean Absolute SHAP Values'` (위치 인자)**
  * **역할:** 그래프에 표시될 실제 텍스트 내용입니다.
  * **의미:** 이 그래프가 "CatBoost 모델의 평균 절대 SHAP 값(변수 중요도)"을 보여준다는 것을 명확하게 설명하고 있습니다.
* **`fontsize=14`**
  * **역할:** 제목 글자의 크기(Font Size)를 조절합니다.
  * **의미:** 기본값보다 약간 크게(14 포인트) 설정하여, 그래프 전체에서 제목이 눈에 잘 띄도록 만들었습니다.
* **`fontweight='bold'`**
  * **역할:** 글자의 두께(Font Weight)를 조절합니다.
  * **의미:** `'bold'`를 지정하여 제목 글자를 **굵게** 표시함으로써 강조 효과를 줍니다.
* **`pad=20`**
  * **역할:** 패딩(Padding), 즉 제목과 그래프 상단 영역 사이의 간격을 조절합니다.
  * **의미:** 숫자를 20으로 주어, 그래프 그림과 제목이 너무 붙어답답해 보이지 않도록 적당한 여백(간격)을 띄워주었습니다.

---

### 3. 📤 반환값/할당 변수
* **반환값:** `plt.title()` 함수는 내부적으로 생성된 텍스트 객체(`matplotlib.text.Text`)를 반환합니다.
* **할당 변수:** 위 코드에서는 반환값을 별도의 변수(`=` 기호 왼쪽)에 저장하지 않고 함수만 실행했습니다. 파이썬에서는 제목을 화면에 띄우기만 할 때 변수에 담지 않고 이렇게 단독으로 자주 사용합니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 주피터 노트북이나 파이썬 파일에서 복사해서 실행해 볼 수 있는 가장 간단한 예시 코드입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 간단한 막대그래프 데이터 준비
categories = ['A', 'B', 'C']
values = [10, 25, 15]

# 2. 그래프 그리기
plt.bar(categories, values)

# 3. 해설한 title 함수 적용하기
plt.title('CatBoost - Mean Absolute SHAP Values', fontsize=14, fontweight='bold', pad=20)

# 4. 그래프 화면에 출력
plt.show()
```

**[예상 결과]**
* 화면에 간단한 막대그래프가 나타납니다.
* 그래프 바로 위쪽 중앙에 **"CatBoost - Mean Absolute SHAP Values"**라는 굵고(bold) 크기 14짜리 제목이 그래프와 살짝 간격(pad=20)을 두고 예쁘게 출력됩니다.

# feature_names.index - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 22:37:15

---

파이썬 코드에서 사용된 `feature_names.index(feature1)`에 대해 초보자의 눈높이에 맞춰 쉽고 명쾌하게 해설해 드리겠습니다.

---

### 1. 📌 함수 개요
`.index()`는 파이썬의 기본 자료형인 **리스트(List)에서 특정 값의 위치(몇 번째 칸에 있는지)를 찾아주는 함수**입니다. 우리가 일상에서 명명록이나 사전에서 특정 단어를 찾아 몇 번째 페이지에 있는지 확인하는 것과 같습니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
이 코드에서 사용된 인자는 괄호 안에 들어있는 **`feature1`** 하나입니다.

*   **`feature1` (찾고 싶은 값):**
    *   **역할:** `feature_names` 리스트 안에서 위치를 찾아내고 싶은 특정 특성(Feature)의 이름입니다.
    *   **설정된 값의 의미:** 예를 들어 데이터셋에 `['나이', '소득', '직업']` 이라는 특성 이름들이 있을 때, `feature1`에 `'소득'`이라는 문자열이 들어있다면 리스트 안에서 `'소득'`이 정확히 어디에 위치하는지 찾게 됩니다.
    *   *주의점:* 만약 `feature_names` 리스트 안에 `feature1`에 해당하는 값이 존재하지 않다면, 파이썬은 프로그램을 멈추고 `ValueError` 에러를 발생시킵니다.

---

### 3. 📤 반환값/할당 변수
함수의 실행 결과는 등호(=) 왼쪽의 **`feature1_idx`** 변수에 저장됩니다.

*   **`feature1_idx` (정수형, Integer):**
    *   **반환값의 의미:** 리스트에서 해당 값이 발견된 **인덱스 번호(몇 번째 위치인지)**를 숫자로 돌려줍니다.
    *   **파이썬의 특징:** 파이썬은 숫자를 **0부터 세기 시작(0-based indexing)**합니다. 
        *   리스트의 첫 번째에 있으면 `0`
        *   두 번째에 있으면 `1`
        *   세 번째에 있으면 `2`가 반환됩니다.
    *   **할당 이유:** 머신러닝 모델이나 배열(Array)은 이름(문자열) 대신 **숫자 번호(인덱스)**로 데이터를 처리하는 경우가 많기 때문에, 특성의 이름을 위치 번호로 바꾸어 저장해두고 나중에 쓰기 위해서입니다.

---

### 4. 🎁 요약 및 실행 예시

백문이 불여일견! 아래의 간단한 코드를 직접 실행해 보면 한눈에 이해할 수 있습니다.

**[실행 코드]**
```python
# 1. 특성 이름들이 들어있는 리스트 준비
feature_names = ['age', 'income', 'score', 'height']

# 2. 찾고 싶은 특성 이름
feature1 = 'score'

# 3. index() 함수를 사용해 위치(인덱스) 찾기
feature1_idx = feature_names.index(feature1)

# 4. 결과 출력
print(f"찾을 특성 이름: {feature1}")
print(f"특성이 위치한 인덱스 번호: {feature1_idx}")
```

**[예상 결과]**
```text
찾을 특성 이름: score
특성이 위치한 인덱스 번호: 2
```
> **설명:** `'score'`는 `feature_names` 리스트에서 0부터 세었을 때 세 번째(`age`=0, `income`=1, `score`=2)에 위치하므로, `2`라는 숫자가 `feature1_idx`에 쏙 들어가게 됩니다!

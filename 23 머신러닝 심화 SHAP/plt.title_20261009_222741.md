# plt.title - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 22:27:41

---

파이썬의 대표적인 시각화 라이브러리인 **Matplotlib(`plt`)**을 사용할 때 가장 자주 쓰는 함수 중 하나인 `plt.title()`에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 하나씩 쉽고 명쾌하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`plt.title()`은 현재 그려지고 있는 그래프의 **상단 중앙에 제목(Title)을 추가하는 함수**입니다. 그래프가 무엇을 나타내는지 보는 사람이 직관적으로 이해할 수 있도록 설명이나 이름을 붙여줄 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드에는 총 4개의 인자가 사용되었습니다. 하나씩 뜯어볼까요?

*   **`'XGBoost - SHAP Summary Plot (Feature Importance)'` (위치 인자)**
    *   **역할:** 그래프에 표시할 **실제 텍스트 내용**입니다.
    *   **의미:** 이 그래프가 "XGBoost 모델의 SHAP 요약 플롯이며, 변수 중요도(Feature Importance)를 보여준다"는 것을 명확하게 설명하고 있습니다.
*   **`fontsize=14`**
    *   **역할:** 글자의 **크기(Font Size)**를 조절합니다.
    *   **의미:** 숫자가 클수록 글자가 커집니다. `14`는 기본 크기보다 살짝 커서 눈에 잘 띄면서도 너무 부담스럽지 않은 적당한 크기입니다.
*   **`fontweight='bold'`**
    *   **역할:** 글자의 **두께(Font Weight)**를 설정합니다.
    *   **의미:** `'bold'`는 **굵게**를 의미합니다. 제목이 시각적으로 강조되어 그래프의 전체적인 주목도를 높여줍니다.
*   **`pad=20`**
    *   **역할:** 제목과 그래프 상단 테두리(혹은 축) 사이의 **간격(Padding)**을 조절합니다.
    *   **의미:** 단위는 픽셀( 정확히는 포인트 단위)이며, `20`만큼의 여백을 주어 제목이 그래프 본문과 너무 붙어 답답해 보이지 않도록 시각적 여유를 줍니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값 없음 (None)**
    *   `plt.title()` 함수는 화면의 그래프 객체에 직접 제목을 그려 넣는 역할을 하기 때문에, 별도의 데이터를 반환(`return`)하지 않습니다. 따라서 변수에 따로 값을 할당할 필요 없이 단독으로 호출하여 사용합니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 복사해서 실행해 볼 수 있는 가장 간단한 예제 코드입니다.

```python
import matplotlib.pyplot as plt

# 1. 간단한 더미 데이터로 그래프 생성
x = [1, 2, 3, 4]
y = [10, 20, 25, 30]

plt.plot(x, y)

# 2. 오늘 배운 plt.title() 적용하기
plt.title(
    "XGBoost - SHAP Summary Plot (Feature Importance)",
    fontsize=14,
    fontweight="bold",
    pad=20,
)

# 3. 그래프 화면에 출력
plt.show()
```

**💡 예상 결과:**
화면에 꺾은선 그래프가 나타나고, **그래프 바로 위 중앙**에 굵고 큼직한 글씨로 `"XGBoost - SHAP Summary Plot (Feature Importance)"`라는 제목이 그래프와 살짝 간격을 둔 채 예쁘게 표시됩니다.

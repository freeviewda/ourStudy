파이썬으로 데이터 시각화를 할 때 가장 널리 쓰이는 라이브러리인 **Matplotlib**의 `plt.title` 함수에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 친절하고 명쾌하게 정리해 드릴게요!

---

### 1. 📌 함수 개요
`plt.title()`은 **현재 생성된 그래프의 상단 중앙에 제목(Title)을 추가해 주는 함수**입니다. 그래프가 무엇을 나타내는지 시각적으로 쉽게 설명하고 싶을 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `plt.title('XGBoost - Confusion Matrix', fontsize=14, fontweight='bold')`에 사용된 3가지 인자의 역할은 다음과 같습니다.

*   **`'XGBoost - Confusion Matrix'` (위치 인자)**
    *   **역할:** 그래프에 표시할 텍스트(제목 내용)를 지정합니다.
    *   **의미:** 이 그래프가 "XGBoost 모델의 오행렬(Confusion Matrix) 결과를 보여주고 있다"는 것을 나타냅니다.
*   **`fontsize=14` (키워드 인자)**
    *   **역할:** 그래프 제목 글자의 크기를 조절합니다.
    *   **의미:** 기본 크기보다 조금 더 크게(14 포인트) 설정하여, 독자의 눈에 잘 띄도록 강조했습니다.
*   **`fontweight='bold'` (키워드 인자)**
    *   **역할:** 글자의 굵기(Weight)를 설정합니다.
    *   **의미:** `'bold'`는 **진하게(볼드체)**를 의미하며, 제목이 그래프의 핵심 설명으로서 확실히 주목받도록 만듭니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값:** `plt.title()` 함수는 제목에 해당하는 `matplotlib.text.Text` 객체를 반환합니다.
*   **할당 변수:** 제시된 코드에서는 이 반환값을 별도의 변수(예: `title_obj = ...`)에 저장하지 않고 **그냥 함수만 실행**했습니다. 파이썬에서는 반환값을 꼭 변수에 담지 않아도 화면(그래프)에 정상적으로 적용되므로, 제목만 띄우고 끝낼 때는 이렇게 단독으로 자주 사용합니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 주피터 노트북이나 파이썬 파일에서 실행해 볼 수 있는 가장 간단한 예시 코드입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 간단한 빈 그래프 생성
plt.plot([1, 2, 3], [4, 5, 6])

# 2. 오늘 배운 plt.title 함수 적용!
plt.title('XGBoost - Confusion Matrix', fontsize=14, fontweight='bold')

# 3. 화면에 그래프 출력
plt.show()
```

**[예상 결과]**
*   화면에 꺾은선 그래프가 나타나며, **그래프 바로 위 정중앙**에 **"XGBoost - Confusion Matrix"** 라는 문구가 **크고 두꺼운 글씨체**로 깔끔하게 띄워지게 됩니다!

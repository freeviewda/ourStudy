---

### 1. 📌 함수 개요
`plt.ylabel`은 파이썬의 시각화 라이브러리인 맷플롯립(Matplotlib)에서 **그래프의 Y축(세로축) 이름(라벨)을 지정**하는 함수입니다. 그래프가 무엇을 나타내는지 보는 사람이 직관적으로 이해할 수 있도록 세로축의 제목을 달아주는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `plt.ylabel('Actual', fontweight='bold')`에 사용된 두 가지 인자의 역할은 다음과 같습니다.

*   **첫 번째 인자: `'Actual'` (위치 인자)**
    *   **역할:** Y축에 표시할 텍스트(이름)를 지정합니다.
    *   **의미:** 여기서는 `'Actual'`(실제값)이라는 문자열을 전달하여, 이 세로축이 나타내는 데이터가 '실제값'임을 명시하고 있습니다. (예: 머신러닝 혼동 행렬(Confusion Matrix) 등에서 실제 정답 값을 나타낼 때 자주 사용됩니다.)
*   **`fontweight='bold'` (키워드 인자)**
    *   **역할:** 텍스트의 두께(폰트 웨이트)를 조절합니다.
    *   **의미:** `'bold'`로 설정했기 때문에 Y축 글씨가 **굵은 글씨**로 강조되어 출력됩니다. (그래프의 가독성을 높일 때 유용합니다.)

---

### 3. 📤 반환값/할당 변수
*   **반환값:** `plt.ylabel()` 함수는 내부적으로 생성된 텍스트 객체(`matplotlib.text.Text`)를 반환합니다.
*   **할당 변수:** 제시해주신 코드에서는 반환값을 별도의 변수에 담지 않고(`variable = ...` 형태 없이) 함수만 단독으로 호출했습니다. 이처럼 파이썬 시각화에서는 반환값을 꼭 변수에 저장하지 않고, 화면에 바로 적용하는 용도로 가볍게 사용하는 경우가 많습니다.

---

### 4. 🎁 요약 및 실행 예시
백문이 불여일견! 아래의 아주 간단한 코드를 복사해서 직접 실행해 보세요. `plt.ylabel`이 그래프에 어떻게 적용되는지 한눈에 확인할 수 있습니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 간단한 데이터 준비
x = [1, 2, 3, 4]
y = [10, 20, 25, 30]

# 선 그래프 그리기
plt.plot(x, y)

# X축, Y축 이름(라벨) 달기
plt.xlabel("X Axis (Time)", fontweight="bold")
plt.ylabel("Actual", fontweight="bold")  # 👈 우리가 살펴본 함수!

# 그래프 화면에 띄우기
plt.show()
```

**[예상 결과]**
*   창이 뜨면서 선 그래프가 나타납니다.
*   가로축 아래에는 `X Axis (Time)`이, **세로축 왼쪽에는 굵은 글씨로 `Actual`** 이라는 이름이 예쁘게 표시된 것을 확인할 수 있습니다.

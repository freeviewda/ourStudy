### 1. 📌 함수 개요
`plt.title()` 함수는 **현재 그려지고 있는 그래프의 상단에 제목(Title)을 추가해 주는 함수**입니다. 그래프가 무엇을 나타내는지 보는 사람이 직관적으로 알 수 있도록 설명 문구를 붙일 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드에는 총 4개의 인자가 전달되었습니다. 각각 어떤 역할을 하는지 살펴볼까요?

*   **`'LightGBM - SHAP Summary Plot (Feature Importance)'` (위치 인자)**
    *   **역할:** 그래프에 표시할 **실제 제목 텍스트**입니다.
    *   **의미:** 이 그래프가 "LightGBM 모델의 SHAP 요약 그래프이며, 특성 중요도(Feature Importance)를 보여준다"는 내용을 사용자에게 알려줍니다.
*   **`fontsize=14`**
    *   **역할:** 글자 크기(Font Size)를 조절합니다.
    *   **의미:** 기본 크기보다 조금 더 크게(14 포인트) 설정하여 제목이 눈에 잘 띄도록 만들었습니다.
*   **`fontweight='bold'`**
    *   **역할:** 글자의 굵기(Font Weight)를 조절합니다.
    *   **의미:** `'bold'`를 지정하여 제목 글씨를 **두껍게** 만들어 강조했습니다.
*   **`pad=20`**
    *   **역할:** 그래프 상단 끝과 제목 사이의 간격(Padding)을 조절합니다.
    *   **의미:** 기본 간격보다 살짝 여유를 두어(20 픽셀 만큼 띄움), 제목이 그래프 그림과 너무 붙어답답해 보이는 것을 방지합니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값 없음 (없거나 내부 객체 반환)**
    *   `plt.title()` 함수는 별도의 데이터를 반환하여 변수에 저장(할당)하고 언패킹하는 등의 작업을 하지 않습니다.
    *   대신, 내부적으로 현재 생성된 그래프(Axes 객체)에 제목이라는 시각적 요소를 **직접 그려 넣는(수정하는) 역할**만 수행합니다. 따라서 코드를 작성할 때 대입 연산자(`=`)를 써서 변수에 담을 필요가 없습니다.

---

### 4. 🎁 요약 및 실행 예시
백문이 불여일견! 초보자분들도 주피터 노트북이나 파이썬 환경에서 복사해서 바로 실행해 볼 수 있는 가장 간단한 예시 코드를 준비했습니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 간단한 선 그래프 데이터 준비
x = [1, 2, 3, 4]
y = [10, 20, 25, 30]

# 2. 그래프 그리기
plt.plot(x, y)

# 3. plt.title 함수 적용 (오늘 배운 내용!)
plt.title(
    "My First Graph", fontsize=16, fontweight="bold", pad=15
)

# 4. 화면에 그래프 출력하기
plt.show()
```

**[예상 결과]**
*   화면에 꺾은선 그래프가 나타납니다.
*   그래프 바로 위 중앙에 **"My First Graph"** 라는 제목이 **두껍고 큰 글씨**로, 그래프와 살짝 간격을 두고 깔끔하게 표시됩니다.

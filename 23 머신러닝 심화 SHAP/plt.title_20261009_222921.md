파이썬 데이터 분석 및 시각화에서 가장 많이 쓰이는 라이브러리인 **Matplotlib**의 `plt.title` 함수에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 하나씩 친절하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`plt.title()` 함수는 **현재 그려지고 있는 그래프의 상단에 제목(Title)을 추가해 주는 함수**입니다. 그래프가 무엇을 나타내는지 보는 사람이 직관적으로 알 수 있도록 설명 문구를 띄울 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드에는 총 4개의 인자가 전달되었습니다. 각각 어떤 역할을 하는지 살펴볼까요?

* **`'CatBoost - SHAP Summary Plot (Feature Importance)'` (위치 인자)**
  * **역할:** 그래프 위에 표시될 실제 텍스트 내용입니다.
  * **의미:** 이 그래프가 "CatBoost 모델의 SHAP(특성 중요도) 요약 그래프"라는 것을 명확하게 설명하고 있습니다.
* **`fontsize=14`**
  * **역할:** 제목 폰트의 크기를 설정합니다.
  * **의미:** 기본 크기보다 조금 더 크게(14 포인트) 설정하여, 그래프를 볼 때 제목이 눈에 잘 띄도록 강조했습니다.
* **`fontweight='bold'`**
  * **역할:** 폰트의 두께(굵기)를 설정합니다.
  * **의미:** `'bold'`를 지정하여 글자를 **굵게** 만들었습니다. 중요한 그래프 제목일수록 굵게 표현하여 시인성을 높입니다.
* **`pad=20`**
  * **역할:** 그래프 상단과 제목 텍스트 사이의 간격(Padding)을 설정합니다.
  * **의미:** 픽셀 단위(정확히는 포인트 단위)로 간격을 띄워주어, 제목이 그래프의 실제 그림(또는 축 레이블)과 너무 붙어 답답해 보이지 않도록 여유 공간을 줍니다.

---

### 3. 📤 반환값/할당 변수
* **반환값 없음 (또는 Text 객체 반환)**
  * 이 함수는 별도의 변수에 값을 할당(`title = plt.title(...)`)하지 않고 단독으로 호출되었습니다. 
  * 내부적으로는 생성된 텍스트 객체(Text object)를 반환하지만, 단순 시각화 과정에서는 변수에 담아두지 않고 화면에 바로 제목을 띄우는 용도로 끝나는 경우가 대부분입니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 주피터 노트북이나 파이썬 파일에서 직접 복사해서 실행해 볼 수 있는 가장 간단한 예시 코드입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 간단한 데이터를 준비합니다 (x축: [1, 2, 3], y축: [2, 4, 6])
plt.plot([1, 2, 3], [2, 4, 6])

# 2. 오늘 배운 plt.title 함수를 적용합니다!
plt.title(
    "My First Graph", fontsize=16, fontweight="bold", pad=15
)  # 제목, 글자크기, 굵기, 간격 설정

# 3. 그래프를 화면에 보여줍니다.
plt.show()
```

**[예상 결과]**
* 화면에 꺾은선 그래프가 나타나며, **그래프 바로 위 중앙**에 **"My First Graph"** 라는 굵고 큼직한 제목이 살짝 위로 간격을 두고 예쁘게 출력됩니다.

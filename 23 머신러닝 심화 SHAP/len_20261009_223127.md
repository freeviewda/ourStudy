# len - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 22:31:27

---

파이썬에서 자주 사용되는 내장 함수 **`len()`**에 대해 초보자의 눈높이에 맞춰 쉽고 명쾌하게 해설해 드리겠습니다.

제시해주신 코드 문맥(`x = np.arange(len(feature_names))`)을 바탕으로 설명할게요!

---

### 1. 📌 함수 개요
`len()`은 파이썬의 **기본 내장 함수(Built-in Function)**로, 리스트, 문자열, 튜플 등 **데이터(객체)의 길이나 요소의 개수를 세어주는 역할**을 합니다. 
여기서는 머신러닝 등에서 특성(Feature) 이름들이 담겨 있는 `feature_names`의 개수가 몇 개인지를 파악하기 위해 사용되었습니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
이 코드에서 `len()` 함수에 전달된 인자는 하나입니다.

*   **`feature_names` (입력된 데이터)**
    *   **역할:** 길이를 측정할 대상입니다. 보통 데이터 분석에서 사용되는 특성(변수)들의 이름이 들어 있는 리스트(List)나 배열(Array) 형태의 데이터입니다.
    *   **의미:** "이 리스트 안에 데이터(항목)가 총 몇 개 들어있니?"라고 `len()` 함수에게 물어보는 대상이라고 생각하시면 됩니다.

---

### 3. 📤 반환값/할당 변수
`len()` 함수가 실행되면 그 결과는 어떻게 처리되고 어디에 담길까요?

*   **반환값 (정수, Integer):** 
    *   `len(feature_names)`는 `feature_names`에 들어있는 항목의 개수를 **정수(숫자)**로 반환합니다. (예: 특성이 5개라면 `5`를 반환)
*   **할당 변수 (`x = ...`):**
    *   반환된 숫자(개수)는 NumPy의 `np.arange()` 함수로 들어가게 됩니다.
    *   예를 들어 개수가 5개라면 `np.arange(5)`가 되어 `[0, 1, 2, 3, 4]`라는 배열이 만들어지고, 최종적으로 변수 **`x`**에 저장됩니다. 
    *   이 `x`는 주로 그래프를 그릴 때 X축의 눈금(위치)을 지정하는 용도로 아주 유용하게 쓰입니다.

---

### 4. 🎁 요약 및 실행 예시
백문이 불여일견! 직접 코드를 실행해 보며 이해해 볼까요? 아래 코드를 파이썬 환경에서 그대로 복사해서 실행해 보세요.

**[실행 코드]**
```python
import numpy as np

# 1. 특성 이름 리스트 정의 (총 4개)
feature_names = ['나이', '소득', '직업', '학력']

# 2. len()을 이용해 개수를 구하고, np.arange()로 X축 위치 생성
x = np.arange(len(feature_names))

print("특성 개수 (len의 결과):", len(feature_names))
print("만들어진 x의 값:", x)
```

**[예상 결과]**
```text
특성 개수 (len의 결과): 4
만들어진 x의 값: [0 1 2 3]
```

**💡 한 줄 요약:** 
`len(feature_names)`는 **"특성 이름이 몇 개인지 세어주는 똑똑한 계보기"**이며, 이 숫자를 이용해 그래프의 칸(위치)을 자동으로 만들어주는 기초 작업입니다!

# plt.title - AI 파이썬 학습 노트

---

파이썬의 대표적인 시각화 라이브러리인 **Matplotlib**에서 사용된 `plt.title` 함수에 대한 상세 해설입니다. 초보자도 쉽게 이해할 수 있도록 항목별로 친절하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`plt.title()`은 **현재 생성된 그래프의 상단 중앙에 제목(Title)을 추가해 주는 함수**입니다. 그래프가 무엇을 나타내는지 보는 사람이 한눈에 파악할 수 있도록 설명이나 이름을 붙일 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드에서 사용된 3개의 인자가 각각 어떤 역할을 하는지 살펴볼까요?

*   **`'Decision Plot - Positive vs Negative Samples'` (위치 인자)**
    *   **역할:** 그래프에 표시될 텍스트(제목 내용)를 지정합니다.
    *   **의미:** 이 그래프가 "양성(Positive) 샘플과 음성(Negative) 샘플을 비교하는 결정 경계(Decision)를 보여주는 그래프"라는 것을 명시하고 있습니다.
*   **`fontsize=14` (키워드 인자)**
    *   **역할:** 그래프 제목 글자의 크기(Font Size)를 조절합니다.
    *   **의미:** 기본 크기보다 조금 더 크게 설정(`14`)하여, 그래프를 보는 사람이 제목을 가장 먼저 눈치챌 수 있도록 시인성을 높였습니다.
*   **`fontweight='bold'` (키워드 인자)**
    *   **역할:** 글자의 굵기(Font Weight)를 조절합니다.
    *   **의미:** `'bold'`를 지정하여 글자를 **굵게** 만들었습니다. 제목을 강조하여 일반 텍스트나 축 이름과 확실히 구분되게 만듭니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값:** `plt.title()` 함수는 제목에 해당하는 텍스트 객체(`matplotlib.text.Text`)를 반환합니다.
*   **할당 변수:** 제시해주신 코드에는 따로 변수에 저장(`title = plt.title(...)`)하지 않고 함수만 단독으로 호출했습니다. 이 경우, 파이썬은 내부적으로 제목을 화면에 그린 뒤 반환값을 조용히 버리게 됩니다. (제목 객체를 나중에 수정할 일이 없다면 이렇게 변수 없이 바로 호출해도 전혀 문제없습니다.)

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 주피터 노트북이나 파이썬 파일에서 직접 복사해서 실행해 볼 수 있는 가장 간단한 전체 코드 예시입니다.

```python
import matplotlib.pyplot as plt

# 1. 간단한 더미 데이터 생성
x = [1, 2, 3, 4, 5]
y = [2, 4, 6, 8, 10]

# 2. 그래프 그리기
plt.plot(x, y)

# 3. 해설한 plt.title 함수 적용하기
plt.title(
    'Decision Plot - Positive vs Negative Samples',
    fontsize=14,
    fontweight='bold',
)

# 4. 그래프 화면에 출력
plt.show()
```

**💡 예상 결과:**
화면에 꺾은선 그래프가 나타나며, **그래프 바로 위 중앙**에 **굵은 글씨체(14 크기)**로 `Decision Plot - Positive vs Negative Samples`라는 제목이 깔끔하게 표시됩니다!

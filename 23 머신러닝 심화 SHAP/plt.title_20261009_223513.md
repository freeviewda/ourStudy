파이썬의 대표적인 시각화 라이브러리인 **Matplotlib**에서 사용된 `plt.title` 함수에 대한 상세 해설입니다. 초보자분들도 쉽게 이해하실 수 있도록 항목별로 나누어 설명해 드릴게요!

---

### 1. 📌 함수 개요
`plt.title()` 함수는 현재 생성된 그래프의 **상단 중앙에 제목(Title)을 달아주는 역할**을 합니다. 그래프가 어떤 내용을 담고 있는지 한눈에 파악할 수 있도록 설명 문구를 추가할 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드에서는 크게 두 가지 종류의 인자가 사용되었습니다. 하나씩 뜯어볼까요?

*   **첫 번째 위치 인자 (제목 텍스트):** `f'XGBoost Force Plot - Sample {sample_idx} (Negative Prediction)'`
    *   **역할:** 그래프 상단에 표시될 실제 텍스트 내용입니다.
    *   **설정된 값의 의미:** 파이썬의 f-string(문자열 포맷팅) 기술을 사용해 동적으로 생성되었습니다. `sample_idx`라는 변수 안에 들어있는 숫자(예: 5번 샘플이라면 5)가 문자열 안에 쏙 들어가서, *"XGBoost Force Plot - Sample 5 (Negative Prediction)"*과 같이 **몇 번째 샘플에 대한 그래프인지 정확히 알려주는 맞춤형 제목**을 만들어 줍니다.
    *   *(참고: Negative Prediction은 모델이 해당 샘플을 '아니오(0)' 또는 '음성'으로 예측했음을 의미합니다.)*

*   **두 번째 키워드 인자 (`fontsize`):** `fontsize=12`
    *   **역할:** 제목 글자의 크기(Font Size)를 조절합니다.
    *   **설정된 값의 의미:** 12포인트 크기로 설정하여, 너무 크지도 작지도 않게 그래프와 잘 어우러지도록 적당한 가독성을 제공합니다.

*   **세 번째 키워드 인자 (`fontweight`):** `fontweight='bold'`
    *   **역할:** 글자의 굵기(Font Weight)를 조절합니다.
    *   **설정된 값의 의미:** `'bold'`로 설정하여 제목 글자를 **진하게** 만듭니다. 이를 통해 그래프의 다른 일반 텍스트와 확실히 구분되어 눈에 잘 띌 수 있게 강조해 줍니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값 없음 (None)**
    *   이 함수는 변수에 따로 값을 할당(`result = plt.title(...)`)하여 사용하지 않고, 그저 그림(Plot) 객체 자체에 제목이라는 속성을 '그려 넣는' 명령형 함수입니다. 따라서 별도로 반환되어 언패킹되는 변수는 없습니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 코랩(Colab)이나 주피터 노트북에서 실행해 볼 수 있는 가장 간단한 예시 코드입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 예시로 사용할 샘플 번호 변수 선언
sample_idx = 42

# 2. 간단한 선 그래프 그리기
plt.plot([1, 2, 3], [4, 5, 6])

# 3. 해설한 plt.title 함수 적용하기
plt.title(f'XGBoost Force Plot - Sample {sample_idx} (Negative Prediction)',
          fontsize=12, fontweight='bold')

# 4. 그래프 화면에 출력하기
plt.show()
```

**[예상 결과]**
*   화면에 파란색 선이 그려진 그래프가 나타납니다.
*   그래프의 맨 위쪽 정중앙에 **굵은 글씨체(Bold)**로 **"XGBoost Force Plot - Sample 42 (Negative Prediction)"** 라는 제목이 깔끔하게 표시됩니다.

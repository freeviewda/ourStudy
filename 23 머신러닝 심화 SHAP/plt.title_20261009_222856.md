파이썬의 데이터 시각화 라이브러리인 `matplotlib`에서 사용되는 `plt.title()` 함수에 대한 상세 해설입니다. 초보자도 쉽게 이해할 수 있도록 항목별로 친절하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`plt.title()`은 **현재 생성된 그래프의 상단에 제목(Title)을 추가해 주는 함수**입니다. 그래프가 무엇을 나타내는지 보는 사람이 한눈에 알아볼 수 있도록 이름을 붙여줄 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
코드에 사용된 4개의 인자가 각각 어떤 역할을 하고 왜 저런 값으로 설정되었는지 살펴볼까요?

*   **`'LightGBM - Mean Absolute SHAP Values'` (위치 인자)**
    *   **역할:** 그래프에 표시될 **제목의 텍스트**를 지정합니다.
    *   **의미:** 이 그래프가 'LightGBM' 모델의 '평균 절대 SHAP 값(변수 중요도)'을 보여주는 그래프라는 것을 명확하게 설명하고 있습니다.
*   **`fontsize=14`**
    *   **역할:** 글자의 **크기(Font Size)**를 조절합니다.
    *   **의미:** 기본값보다 살짝 크게(14 포인트) 설정하여, 그래프 제목이 눈에 잘 띄도록 만들었습니다.
*   **`fontweight='bold'`**
    *   **역할:** 글자의 **두께(Font Weight)**를 조절합니다.
    *   **의미:** `'bold'`를 지정하여 글자를 **굵게** 만들었습니다. 중요도를 강조하는 효과가 있습니다.
*   **`pad=20`**
    *   **역할:** 그래프 상단 테두리(또는 축)와 제목 텍스트 사이의 **간격(Padding)**을 조절합니다.
    *   **의미:** 제목이 그래프 그림과 너무 딱 붙어 있으면 답답해 보일 수 있으므로, 위쪽으로 20픽셀 만큼의 여백을 주어 시각적으로 깔끔하게 배치했습니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값:** `plt.title()` 함수는 제목에 해당하는 텍스트 객체(`matplotlib.text.Text`)를 반환합니다.
*   **할당 변수:** 위 코드에서는 별도의 변수에 저장(`title_obj = plt.title(...)`)하지 않고 **함수만 단독으로 호출**하여 바로 화면에 반영되도록 했습니다. (필요에 따라 반환된 객체를 이용해 나중에 제목 속성을 수정할 수도 있습니다.)

---

### 4. 🎁 요약 및 실행 예시
백문이 불여일견! 아래의 아주 간단한 코드를 직접 복사해서 실행해 보세요. `plt.title()`이 어떻게 동작하는지 1분 만에 이해할 수 있습니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 간단한 막대그래프 데이터 준비
x = ['A', 'B', 'C']
y = [10, 25, 15]

# 2. 그래프 그리기
plt.bar(x, y)

# 3. plt.title() 적용하기 (해설한 코드 적용!)
plt.title(
    'LightGBM - Mean Absolute SHAP Values',
    fontsize=14,
    fontweight='bold',
    pad=20,
)

# 4. 그래프 화면에 출력
plt.show()
```

**[예상 결과]**
*   화면에 A, B, C를 나타내는 막대그래프가 나타납니다.
*   그래프 맨 위 중앙에 **굵은 글씨체(bold)**로 **크기 14**의 **'LightGBM - Mean Absolute SHAP Values'**라는 제목이 그래프와 살짝 떨어져서(pad=20) 깔끔하게 출력됩니다.

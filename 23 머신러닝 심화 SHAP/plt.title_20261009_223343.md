# plt.title - AI 파이썬 학습 노트

---

파이썬으로 데이터 시각화(특히 Matplotlib 라이브러리)를 할 때 가장 많이 쓰는 함수 중 하나인 `plt.title`에 대한 상세 해설입니다. 초보자분들이 쉽게 이해하실 수 있도록 항목별로 친절하게 풀어드릴게요!

---

### 1. 📌 함수 개요
`plt.title()`은 **그래프의 상단 중앙에 제목(Title)을 달아주는 함수**입니다. 그래프가 무엇을 나타내는지 보는 사람이 한눈에 알아볼 수 있도록 설명이나 이름을 붙여줄 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드에서는 제목의 **내용**과 글자의 **크기 및 굵기**를 설정하고 있습니다. 전달된 인자들을 하나씩 뜯어볼까요?

*   **첫 번째 위치 인자 (제목 문자열):**
    *   `f'XGBoost Force Plot - Sample {sample_idx} (Positive Prediction)'`
    *   **의미:** 파이썬의 f-string(포맷 문자열)을 사용하여, 현재 시각화하고 있는 데이터의 번호(`sample_idx` 변수 값)가 제목에 자동으로 쏙 들어가도록 만들었습니다. 
    *   예를 들어 `sample_idx`가 5였다면, 화면에는 **"XGBoost Force Plot - Sample 5 (Positive Prediction)"**이라고 제목이 찍힙니다.
*   **`fontsize=12`**
    *   **의미:** 글자 크기(Font Size)를 12포인트로 설정합니다. 숫자가 클수록 글자가 커지며, 보통 그래프 제목은 12~16 사이의 값을 보기 좋게 자주 사용합니다.
*   **`fontweight='bold'`**
    *   **의미:** 글자의 굵기(Font Weight)를 '굵게(Bold)' 설정합니다. 제목이 선명하게 강조되어 눈에 잘 띄게 만드는 효과가 있습니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값 없음 (없음 / None)**
*   **해설:** `plt.title()` 함수는 화면에 직접 제목을 그려주는 역할만 수행하고, 별도의 데이터를 반환(return)하지 않습니다. 따라서 변수에 따로 값을 대입(`변수 = plt.title(...)`)해서 받을 필요 없이, 그냥 함수만 단독으로 호출해서 사용합니다.

---

### 4. 🎁 요약 및 실행 예시
백문이 불여일견! 초보자분들도 복사해서 바로 실행해 볼 수 있는 가장 간단한 실습 코드를 준비했습니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 시뮬레이션을 위한 샘플 번호 변수 선언
sample_idx = 42

# 2. 간단한 빈 그래프 그리기 (도화지 준비)
plt.plot([1, 2, 3], [4, 5, 6])

# 3. 질문하신 plt.title 함수 사용!
plt.title(f'XGBoost Force Plot - Sample {sample_idx} (Positive Prediction)',
          fontsize=12, fontweight='bold')

# 4. 화면에 그래프 띄우기
plt.show()
```

**[예상 결과]**
*   화면에 꺾은선 그래프가 나타납니다.
*   그래프 **바로 윗부분 중앙**에 **"XGBoost Force Plot - Sample 42 (Positive Prediction)"**라는 문구가 **굵고(Bold) 12포인트 크기**로 깔끔하게 출력됩니다.

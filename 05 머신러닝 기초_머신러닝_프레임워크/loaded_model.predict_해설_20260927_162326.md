# 🤖 AI 파이썬 학습 노트: loaded_model.predict

- **기록 일시**: 2026-09-27 16:23:26
- **대상 코드/함수**: `loaded_model.predict`

---

파이썬 머신러닝 코드에서 사용된 `loaded_model.predict(X_test)` 문맥에 대해 초보자의 눈높이에 맞춰 쉽고 명쾌하게 해설해 드릴게요!

---

### 1. 📌 함수 개요
`loaded_model.predict()`는 **이미 학습(훈련)이 끝난 머신러닝 모델에 새로운 질문(데이터)을 던져서 정답을 맞히게 하는(예측) 핵심 함수**입니다. 
마치 공부를 마친 학생에게 모의고사 시험지를 주고 풀게 하는 것과 같습니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
이 코드에서 괄호 안에는 하나의 인자가 전달되었습니다.

* **`X_test` (테스트용 문제 데이터)**
  * **역할:** 모델이 한 번도 보지 못한 미지의 데이터(특징, Feature)들의 모음입니다. 
  * **설정된 값의 의미:** 보통 전체 데이터를 쪼갤 때 모델 학습용(`X_train`)과 시험용(`X_test`)으로 나누는데, 여기서 `X_test`는 **"진짜 실력(예측력)을 테스트하기 위해 남겨둔 시험지"**를 의미합니다. 정답(`y_test`)은 떼고 문제만 담겨 있습니다.

---

### 3. 📤 반환값/할당 변수
함수가 실행된 결과는 등호(`=`) 왼쪽의 변수에 저장됩니다.

* **`loaded_model_pred` (모델의 예측 결과)**
  * **역할:** `X_test`(시험지)를 받아 모델이 최종적으로 예측해 낸 **'답안지'**입니다.
  * **데이터 형태:** 
    * 만약 **분류(Classification) 문제**였다면 (예: 스팸 메일 판별, 고양이/강아지 분류), 모델이 예측한 **클래스 레이블(예: `[0, 1, 1, 0...]`)**이 담깁니다.
    * 만약 **회귀(Regression) 문제**였다면 (예: 집값 예측, 온도 예측), 모델이 예측한 **연속적인 숫자 값(예: `[3억 5천, 4억 2천...]`)**이 담깁니다.

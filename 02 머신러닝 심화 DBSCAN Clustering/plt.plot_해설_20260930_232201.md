# 🤖 AI 파이썬 학습 노트: plt.plot

- **기록 일시**: 2026-09-30 23:22:01
- **대상 코드/함수**: `plt.plot`

---

파이썬으로 데이터를 시각화할 때 가장 많이 사용하는 `matplotlib.pyplot` 라이브러리의 `plt.plot(distances)` 코드에 대한 상세 해설입니다. 초보자분들도 쉽게 이해하실 수 있도록 항목별로 친절하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`plt.plot()`은 전달받은 데이터들을 **선 그래프(Line Plot)로 그려주는 가장 기초적이고 강력한 시각화 함수**입니다. 데이터의 흐름이나 추세, 변화 과정을 한눈에 파악할 수 있도록 꺾은선 그래프로 화면에 띄워줍니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
현재 코드에서는 하나의 인자만 전달되었습니다.

* **`distances`**
  * **역할:** 그래프를 그릴 때 사용할 **Y축의 값들(숫자 데이터 리스트 또는 배열)**입니다.
  * **설정된 값의 의미:** 예를 들어 `[10, 15, 7, 22]`와 같은 거리(distance) 데이터가 들어있다면, 이 숫자들의 크기 변화를 선으로 연결하여 보여줍니다.
  * **💡 참고 (X축은 어떻게 되나요?):** X축에 대한 별도의 값을 지정해주지 않으면, 파이썬은 자동으로 데이터의 순서(인덱스: `0, 1, 2, 3...`)를 X축으로 사용합니다. 즉, 첫 번째 값은 X=0, 두 번째 값은 X=1 위치에 찍히게 됩니다.

---

### 3. 📤 반환값/할당 변수
`plt.plot()` 함수는 그래프를 직접 화면에 그려주는 **시각화 작업**을 수행합니다. 

* **반환값:** 이 함수는 화면에 그림(Plot)을 띄우는 것이 주 목적이기 때문에, 파이썬 코드에서 따로 변수에 값을 할당해 받아오는 경우가 드뭅니다. (보통 함수 실행 후 추가로 `plt.show()`를 호출해 화면에 최종 출력합니다.)
* **할당된 변수 없음:** 위 코드 (`plt.plot(distances)`)에서는 별도의 변수에 결과값을 저장하지 않고 곧바로 그래프 객체를 생성하는 용도로만 사용되었습니다.

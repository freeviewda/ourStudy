# 🤖 AI 파이썬 학습 노트: np.unique

- **기록 일시**: 2026-09-30 23:23:14
- **대상 코드/함수**: `np.unique`

---

파이썬 코드에서 사용된 **`np.unique(clusters)`**에 대해 초보자분들도 한눈에 이해하기 쉽도록 항목별로 친절하고 명쾌하게 해설해 드리겠습니다.

---

### 1. 📌 함수 개요
`np.unique`는 파이썬의 대표적인 수치 계산 라이브러리인 **NumPy**의 함수로, **입력된 데이터에서 중복을 제거하고 고유한(unique) 값들만 남겨서 오름차순으로 정렬해 주는 함수**입니다. 머신러닝이나 데이터 분석에서 데이터에 어떤 그룹(클래스나 군집)이 몇 개나 존재하는지 확인할 때 아주 자주 사용됩니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시된 코드에서는 하나의 인자가 전달되었습니다.

*   **`clusters`**
    *   **역할:** 중복을 제거하고 고유값을 찾고자 하는 대상 데이터(보통 NumPy 배열이나 파이썬 리스트)입니다.
    *   **설정된 값의 의미:** 머신러닝의 군집화(Clustering) 알고리즘(예: K-Means 등)을 거친 결과로 나온 **각 데이터 포인트들의 소속 군집 번호(레이블)들이 담긴 1차원 배열(또는 리스트)**을 의미합니다. (예: `[0, 1, 0, 2, 1, 0]` 형태의 데이터)

---

### 3. 📤 반환값/할당 변수
`np.unique` 함수가 실행된 후 결과가 저장되는 변수와 그 값의 의미입니다.

*   **`unique_labels`**
    *   **어떤 데이터인가:** `clusters` 배열 안에 들어있던 **중복을 제거한 고유한 군집 번호들의 목록**입니다.
    *   **예시:** 만약 `clusters`에 `[0, 1, 0, 2, 1, 0, 2]`가 들어있었다면, 중복을 제거하고 정렬된 **`[0, 1, 2]`**라는 1차원 NumPy 배열이 반환되어 `unique_labels`에 저장됩니다.
    *   **활용 의미:** 이를 통해 전체 데이터가 **총 몇 개의 군집(클러스터)으로 나누어졌는지**(`len(unique_labels)`를 통해 개수 파악 가능) 쉽게 알 수 있습니다.

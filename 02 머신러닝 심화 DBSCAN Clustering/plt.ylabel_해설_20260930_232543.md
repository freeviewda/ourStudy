# 🤖 AI 파이썬 학습 노트: plt.ylabel

- **기록 일시**: 2026-09-30 23:25:43
- **대상 코드/함수**: `plt.ylabel`

---

파이썬 데이터 시각화에서 가장 많이 쓰이는 `matplotlib.pyplot` 라이브러리의 `plt.ylabel` 함수에 대해 초보자의 눈높이에 맞춰 친절하고 명쾌하게 해설해 드릴게요!

---

### 1. 📌 함수 개요
`plt.ylabel()`은 **그래프의 Y축(세로축)에 이름(제목)을 달아주는 함수**입니다. 그래프를 보는 사람이 세로축이 무엇을 나타내는지 직관적으로 알 수 있도록 설명해 주는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
코드 `plt.ylabel('Principal Component 2')`에 전달된 인자의 의미는 다음과 같습니다.

*   **`'Principal Component 2'` (문자열, string)**
    *   **역할:** Y축에 표시할 텍스트(이름)를 지정합니다.
    *   **설정된 값의 의미:** 주성분 분석(PCA)이라는 머신러닝 기법을 통해 2차원으로 압축된 데이터 중, **두 번째 주성분(Principal Component 2)**을 세로축에 표현하고 있음을 나타냅니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값 없음 (None)**
    *   `plt.ylabel()` 함수는 별도의 데이터를 반환하는 함수가 아닙니다. 
    *   변수에 값을 대입할 필요 없이(예: `a = plt.ylabel(...)`처럼 쓰지 않음), 그저 현재 활성화된 그래프의 Y축 레이아웃을 직접 수정(그리기)하고 끝나는 **시각화 설정 함수**입니다.

# 🤖 AI 파이썬 학습 노트: PCA

- **대상 코드/함수**: `PCA`

---

파이썬 머신러닝 코드에서 사용된 `PCA` 함수와 인자에 대해 초보자의 눈높이에 맞춰 쉽고 명쾌하게 설명해 드리겠습니다.

---

### 1. 📌 함수 개요
**PCA (Principal Component Analysis, 주성분 분석)**는 데이터의 **'차원(특성 수)을 줄여주는(압축하는) 대표적인 비지도 학습 알고리즘'**입니다. 쉽게 말해, 데이터의 전체적인 특징(정보)은 최대한 유지하면서 복잡한 데이터의 덩치를 줄여서, 데이터 분석이나 시각화를 더 쉽고 빠르게 할 수 있도록 도와주는 마법 같은 도구입니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제공해주신 코드 `PCA(n_components=2)`에서 사용된 인자의 역할과 의미는 다음과 같습니다.

*   **`n_components = 2`**
    *   **의미:** 원본 데이터의 특성을 압축해서 **최종적으로 남길 차원의 수(축의 개수)**를 2개로 지정하겠다는 뜻입니다.
    *   **설명:** 예를 들어 어떤 데이터에 키, 몸무게, 나이, 소득 등 10개의 정보(10차원)가 있다면, 이 인자를 통해 정보 손실을 최소화하면서 2개의 대표적인 정보(2차원)로 압축합니다. 특히 2차원으로 줄이게 되면 2차원 산점도(그래프)로 시각화하여 눈으로 확인하기 매우 좋아집니다.

---

### 3. 📤 반환값/할당 변수
코드에서 반환된 결과를 담고 있는 `pca` 변수가 무엇을 의미하는지 설명해 드릴게요.

*   **`pca` (PCA 객체)**
    *   **의미:** 위에서 설정한 규칙(`n_components=2`)을 가지고 **데이터를 변환할 준비를 마친 'PCA 도구(모델) 상자'**입니다.
    *   **설명:** 이 자체로는 바로 데이터가 변환되지 않으며, 이후에 `pca.fit_transform(데이터)`과 같은 코드를 통해 실제로 데이터를 2차원으로 쏙 압축하는 데 사용됩니다.

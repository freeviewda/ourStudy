# 🤖 AI 파이썬 학습 노트: set_title

- **기록 일시**: 2026-09-29 16:32:55
- **대상 코드/함수**: `set_title`

---

파이썬 데이터 시각화(주로 `matplotlib` 라이브러리)에서 사용되는 `set_title` 함수에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 쉽고 명쾌하게 정리해 드릴게요!

---

### 1. 📌 함수 개요
`set_title()`은 **그래프의 상단 중앙에 제목(Title)을 달아주는 함수**입니다. 여러 개의 그래프(Subplots)가 있을 때, 특정 그래프가 어떤 데이터를 보여주는지 이름을 붙여 구별하기 위해 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드에서는 제목을 동적으로 만들기 위해 **f-string(문자열 포맷팅)**을 사용해 인자로 전달했습니다.

*   **코드:** `f'True Labels ({len(np.unique(wine.target))} classes)'`
*   **전달되는 최종 문자열 예시:** `'True Labels (3 classes)'` (와인 데이터의 타겟 클래스 개수가 3개인 경우)

인자 내부의 구성 요소를 하나씩 쪼개어 보면 다음과 같습니다.

*   **`wine.target`**
    *   **역할:** 파이썬의 대표적인 머신러닝 데이터셋인 와인(Wine) 데이터에서 **정답(Label) 데이터**를 의미합니다. (예: 와인의 품종 0, 1, 2)
*   **`np.unique(...)`**
    *   **역할:** 넘파이(NumPy)의 함수로, **데이터에서 중복을 제거하고 고유한 값들만 남겨주는 역할**을 합니다.
    *   *의미:* `wine.target` 안에는 수많은 정답 데이터가 들어있는데, 이 중복을 제거하면 "우리 데이터에는 총 몇 가지의 품종(클래스)이 있는가?"를 알 수 있습니다.
*   **`len(...)`**
    *   **역할:** 파이썬 내장 함수로, **괄호 안의 데이터 개수(길이)를 세어줍니다.**
    *   *의미:* `np.unique`를 통해 나온 고유한 클래스들의 **개수(숫자)**를 구합니다. (와인 데이터의 경우 보통 3이 나옵니다.)
*   **`f'True Labels (... classes)'` (f-string)**
    *   **역할:** 문자열 안에 파이썬 변수나 계산식을 중괄호(`{}`)를 사용해 쏙 집어넣어 주는 편리한 기능입니다.
    *   *의미:* 고정된 글자인 `'True Labels ('`와 `') classes'` 사이에 방금 계산한 클래스 개수 숫자를 쏙 집어넣어 최종적으로 **"실제 레이블 (3 클래스)"**라는 완성된 제목 문자열을 만듭니다.

---

### 3. 📤 반환값/할당 변수
`set_title()` 함수는 화면에 그려진 그래프 객체의 제목 속성을 직접 변경(수정)하는 **명령형 함수**입니다.

*   **반환값:** **없음 (`None`)**
*   **설명:** 데이터를 새로 만들어내거나 변수에 담아주는 함수가 아닙니다. `axes[1]`(두 번째 그래프)의 제목표시판에 글씨를 , "이 그래프의 제목은 이거야!" 하고 쾅 도장을 찍어주는 역할을 끝으로 아무것도 반환하지 않습니다. 따라서 별도의 변수에 결과값을 담아둘 필요 없이, 그저 함수를 호출하는 것만으로 작업이 완료됩니다.

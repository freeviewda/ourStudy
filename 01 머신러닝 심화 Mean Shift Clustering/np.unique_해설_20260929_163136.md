# 🤖 AI 파이썬 학습 노트: np.unique

- **기록 일시**: 2026-09-29 16:31:36
- **대상 코드/함수**: `np.unique`

---

요청하신 파이썬 코드 중 외부 함수인 **`np.unique`**와 그 인자에 대해 초보자의 눈높이에 맞춰 친절하고 명쾌하게 해설해 드리겠습니다.

---

### 1. 📌 함수 개요
`np.unique`는 파이썬의 대표적인 수치 계산 라이브러리인 NumPy에서 제공하는 함수입니다. **전달된 데이터에서 중복된 값을 모두 제거하고, 오직 고유한(unique) 값들만 골라내어 정렬된 상태로 반환**해 주는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
코드 전체 문맥에서 `np.unique`가 사용된 부분은 `np.unique(wine.target)`입니다. 여기에 전달된 인자의 의미는 다음과 같습니다.

*   **`wine.target` (입력 데이터)**
    *   **역할:** 고유한 값들을 추출할 원본 데이터입니다.
    *   **설명:** 여기서 `wine`은 머신러닝에서 자주 쓰이는 '와인 데이터셋'을 의미하며, `.target`은 각 와인이 어떤 종류(클래스)인지 나타내는 정답 레이블(예: 0, 1, 2)이 들어있는 배열입니다.
    *   **설정값의 의미:** 예를 들어 와인 데이터셋에 총 178개의 데이터가 있고, 정답이 3가지 종류(0, 0, ..., 1, 1, ..., 2, 2)로 분류되어 있다면, `wine.target`은 이 178개의 숫자가 모두 들어있는 긴 배열이 됩니다. `np.unique`는 이 속에서 중복을 뺀 진짜 종류가 무엇인지 파악하기 위해 이 배열을 통째로 입력받습니다.

---

### 3. 📤 반환값/할당 변수
`np.unique(wine.target)`이 실행되면 어떤 결과가 반환되고 전체 코드에서 어떻게 쓰이는지 설명해 드릴게요.

*   **반환되는 값:** 
    *   중복이 제거되고 오름차순으로 정렬된 고유한 값들의 배열을 반환합니다.
    *   예를 들어 `wine.target`에 `[0, 1, 1, 2, 0, 2]`가 들어있었다면, `np.unique`는 **`[0, 1, 2]`**라는 배열을 돌려줍니다.
*   **전체 코드에서의 활용:**
    *   `len(np.unique(wine.target))` 부분은 반환된 고유값 배열의 길이(`len`), 즉 **와인 종류(클래스)의 총 개수**를 구하는 것입니다. (위 예시라면 `len([0, 1, 2])`가 되어 결과는 `3`이 됩니다.)
    *   최종적으로 이 숫자는 `np.linspace`로 들어가며, 와인 종류의 수(예: 3개)에 딱 맞춰 그래프 색상을 예쁘게 나누어(Set1) 지정하는 데 사용됩니다.

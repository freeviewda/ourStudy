# 🤖 AI 파이썬 학습 노트: np.unique

- **기록 일시**: 2026-09-29 16:25:06
- **대상 코드/함수**: `np.unique`

---

파이썬 코드에서 사용된 **`np.unique(labels)`**에 대해 초보자의 눈높이에 맞춰 쉽고 명쾌하게 해설해 드리겠습니다.

---

### 1. 📌 함수 개요
`np.unique()` 함수는 파이썬의 과학 계산 라이브러리인 NumPy에서 제공하는 함수로, **데이터 배열에서 중복된 값을 모두 제거하고 고유한 값(Unique values)들만 골라내는 역할**을 합니다. 머신러닝에서는 주로 군집화(Clustering) 결과로 나온 레이블(클러스터 번호)의 종류와 개수를 파악할 때 유용하게 쓰입니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
현재 코드에 전달된 인자는 `labels` 하나뿐입니다. 각 인자의 역할은 다음과 같습니다.

*   **`labels` (입력 데이터)**
    *   **역할:** 고유한 값들을 추출할 대상이 되는 1차원 배열(또는 리스트)입니다.
    *   **설명:** 머신러닝 모델(예: DBSCAN, KMeans 등)이 각 데이터 샘플에 부여한 군집 번호(레이블)들이 담겨 있습니다. 
    *   *예시:* 만약 `labels`가 `[0, 1, 0, 2, 1, -1, 0]` 이라면, 데이터 속에는 0번, 1번, 2번 클러스터와 노이즈를 뜻하는 -1번이 포함되어 있음을 알 수 있습니다.

---

### 3. 📤 반환값/할당 변수
`np.unique(labels)`는 기본적으로 입력된 배열에서 **중복을 제거한 고유한 값들을 오름차순으로 정렬한 1차원 NumPy 배열**을 반환합니다.

*   **반환되는 값:** 
    *   위의 예시(`labels = [0, 1, 0, 2, 1, -1, 0]`)를 넣었을 때, `np.unique(labels)`는 `[-1, 0, 1, 2]`라는 배열을 반환합니다.
*   **전체 코드에서의 활용 (`n_clusters_ = len(...)`):**
    *   `np.unique(labels)`가 반환한 고유 값들의 배열(`[-1, 0, 1, 2]`)에 **`len()`** 함수를 씌워 그 **길이(요소의 개수)**를 구합니다.
    *   즉, `len([-1, 0, 1, 2])`는 `4`가 되므로, 변수 `n_clusters_`에는 **총 몇 개의 클러스터(또는 그룹)가 생성되었는지** 그 개수가 최종 저장됩니다. 
    *   *(참고: 머신러닝 모델에 따라 노이즈(-1)도 개수에 포함될 수 있으므로, 실제 알고리즘에서는 노이즈를 제외하는 추가 처리를 하기도 합니다.)*

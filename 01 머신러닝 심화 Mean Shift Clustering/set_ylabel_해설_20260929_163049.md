# 🤖 AI 파이썬 학습 노트: set_ylabel

- **기록 일시**: 2026-09-29 16:30:49
- **대상 코드/함수**: `set_ylabel`

---

파이썬 데이터 분석 및 시각화 코드에서 자주 사용되는 `set_ylabel` 함수에 대한 상세 해설입니다. 초보자분들도 쉽게 이해하실 수 있도록 항목별로 친절하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`set_ylabel`은 파이썬의 대표적인 시각화 라이브러리인 **Matplotlib**에서 **그래프의 Y축 이름(라벨)을 설정**해 주는 함수입니다. 여러 개의 그래프(Subplots)가 있을 때, 특정 그래프의 세로축이 무엇을 나타내는지 이름을 붙여줄 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `axes[0].set_ylabel('PC2')`에서 사용된 인자의 역할은 다음과 같습니다.

*   **`'PC2'` (문자열, String)**
    *   **역할:** Y축에 표시할 텍스트(이름)를 지정합니다.
    *   **설정된 값의 의미:** 주성분 분석(PCA) 결과 중 두 번째 주성분(Principal Component 2)을 의미합니다. 즉, 이 그래프의 Y축 데이터가 'PC2' 값들을 나타내고 있음을 사용자에게 알려줍니다.

*(참고 앞부분의 `axes[0]`은 여러 개의 그래프 판(Axes 객체 배열) 중에서 **첫 번째 그래프**를 선택한다는 뜻입니다.)*

---

### 3. 📤 반환값 및 후속 효과
`set_ylabel` 함수는 별도의 데이터를 반환(Return)하여 변수에 할당하는 함수가 아닙니다. 

*   **동작 방식:** 그래프 객체에 직접 작용하여 **Y축의 이름을 화면에 그려주는(출력하는) 역할**을 합니다. 
*   **결과:** 코드가 실행되면 지정한 그래프의 Y축 왼쪽에 수직 방향으로 **'PC2'**라는 글자가 나타나게 됩니다.

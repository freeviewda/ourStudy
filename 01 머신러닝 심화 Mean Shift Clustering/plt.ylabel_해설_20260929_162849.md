# 🤖 AI 파이썬 학습 노트: plt.ylabel

- **기록 일시**: 2026-09-29 16:28:49
- **대상 코드/함수**: `plt.ylabel`

---

파이썬 데이터 시각화 라이브러리인 맷플롯립(Matplotlib)에서 사용되는 `plt.ylabel()` 함수에 대한 상세 해설입니다. 초보자분들도 쉽게 이해하실 수 있도록 요청하신 항목별로 친절하게 정리해 드리겠습니다.

---

### 1. 📌 함수 개요
`plt.ylabel()`은 **그래프의 Y축(세로축)에 이름을 붙여주는(라벨을 설정하는) 함수**입니다. 그래프가 무엇을 나타내는지 보는 사람이 직관적으로 이해할 수 있도록 세로축의 제목을 지정할 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
코드에서 전달된 인자와 그 의미는 다음과 같습니다.

*   **`'Principal Component 2'` (문자열, string)**
    *   **역할:** Y축에 표시될 텍스트(이름)를 지정합니다.
    *   **설정된 값의 의미:** 
        *   'Principal Component 2'는 우리말로 **'주성분 2'**를 뜻합니다. 
        *   데이터 분석 기법 중 하나인 **PCA(주성분 분석)**를 수행할 때, 여러 개의 복잡한 변수들을 압축해서 만든 새로운 축(2번째 축)을 Y축에 배치했음을 의미합니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값 없음 (`None`)**
    *   이 함수는 데이터를 계산하거나 변환해서 새로운 값을 돌려주는(return) 함수가 아닙니다.
    *   단지 현재 활성화된 그래프의 Y축에 글자를 그려넣는(시각적 요소 추가) 역할만 수행하므로, 별도의 변수에 값을 할당(저장)할 필요 없이 `plt.ylabel('...')` 형태로 단독 호출하여 사용합니다.

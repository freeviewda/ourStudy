파이썬 데이터 시각화 라이브러리인 **Matplotlib**에서 사용된 `plt.title` 함수에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 하나씩 친절하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`plt.title()`은 현재 그려지고 있는 그래프의 **상단 중앙에 제목(Title)을 추가해 주는 함수**입니다. 그래프가 무엇을 나타내는지 한눈에 파악할 수 있도록 설명을 붙일 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
코드 안에서 괄호 `( )` 사이에 들어간 문자열 데이터가 바로 이 함수에 전달되는 입력 인자입니다.

*   **`f'Actual vs Predicted (R2={r2:.4f}, RMSE={rmse:.4f})'`**
    *   **f-string(포맷 문자열) 기법:** 문자열 앞에 붙은 `f`는 문자열 안에 파이썬 변수(`{r2}`, `{rmse}`)를 직접 쏙 집어넣어 사용할 수 있게 해주는 기능입니다.
    *   **`Actual vs Predicted`:** "실제값(Actual)과 예측값(Predicted)"을 비교하는 그래프라는 의미입니다.
    *   **`R2={r2:.4f}`:** 모델의 설명력을 나타내는 $R^2$ (결정계수) 값을 표시합니다. 뒤의 `:.4f`는 소수점 넷째 자리까지만 반올림하여 깔끔하게 보여달라는 뜻입니다. (예: `0.9521`)
    *   **`RMSE={rmse:.4f}`:** 모델의 예측 오차를 나타내는 RMSE(평균 제곱근 오차) 값을 표시합니다. 이 역시 소수점 넷째 자리까지 출력됩니다. (예: `1.2345`)

> **💡 최종 만들어지는 제목 예시:**
> `Actual vs Predicted (R2=0.9521, RMSE=1.2345)`

---

### 3. 📤 반환값/할당 변수
*   **반환값 없음 (`None`)**
*   `plt.title()` 함수는 화면(그래프 창)에 직접 제목을 텍스트로 그려주는 **시각적 작업**만 수행합니다. 따라서 별도의 데이터를 반환하거나 변수에 대입(`=`)하여 사용하지 않습니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 복사해서 실행해 볼 수 있는 가장 간단한 전체 코드입니다. 이 코드를 실행하면 그래프 위쪽에 방금 배운 제목이 예쁘게 나타납니다!

```python
import matplotlib.pyplot as plt

# 1. 예시를 위한 가상의 성능 점수 변수 선언
r2 = 0.891234
rmse = 1.456789

# 2. 간단한 선 그래프 그리기 (아무 데이터나 사용)
plt.plot([1, 2, 3], [1, 4, 9])

# 3. 배운 함수 사용: 그래프 제목 설정
plt.title(f'Actual vs Predicted (R2={r2:.4f}, RMSE={rmse:.4f})')

# 4. 그래프 화면에 출력하기
plt.show()
```

**🎯 실행 결과:**
그래프 상단에 다음과 같은 제목이 표시됩니다.
> **`Actual vs Predicted (R2=0.8912, RMSE=1.4568)`**

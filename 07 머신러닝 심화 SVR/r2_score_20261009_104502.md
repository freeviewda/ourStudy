---

### 1. 📌 함수 개요
`r2_score`는 머신러닝 회귀 모델(숫자를 예측하는 모델)이 **"데이터를 얼마나 잘 예측했는지" 성능을 평가**해 주는 함수입니다. 
* 쉽게 말해, **"우리 모델이 만든 예측이 실제 값과 얼마나 비슷하니?"**를 0과 1 사이의 점수(또는 음수)로 매겨주는 **성적표**라고 생각하시면 됩니다. (1점에 가까울수록 완벽한 예측입니다!)

---

### 2. 🔍 입력 인자(매개변수) 분석
코드 `r2_score(y_test, y_pred_all)`에서 사용된 두 개의 인자를 차근차근 살펴볼까요?

* **첫 번째 인자: `y_test` (정답)**
  * **역할:** 모델이 맞혀야 하는 **실제 진짜 값(Ground Truth)**입니다.
  * **의미:** 테스트 데이터셋에 해당하는 실제 정답 레이블들이 들어있는 리스트나 배열입니다. (예: 실제 집 가격들)

* **두 번째 인자: `y_pred_all` (모델의 예측값)**
  * **역할:** 우리 모델이 **예측해 낸 값(Prediction)**입니다.
  * **의미:** 모델이 `y_test`를 보고 "이 정도 가격일 거야!"라고 추정하여 뱉어낸 결과값들입니다.

> **💡 핵심 요약:** `y_test`(실제 정답)와 `y_pred_all`(내 모델의 답안)을 서로 비교해서 점수를 매기기 위해 이 두 인자를 순서대로 넣은 것입니다.

---

### 3. 📤 반환값/할당 변수
* **할당 변수: `r2_all`**
  * **역할:** `r2_score` 함수가 계산을 끝내고 돌려준 **최종 성적표(점수)**를 저장하는 상자(변수)입니다.
  * **데이터 종류:** 보통 **실수(Float)** 소수점 형태로 나옵니다. (예: `0.92`, `0.75` 등)
  * **해석 방법:**
    * **`1.0`**: 완벽하게 다 맞춤 (오차 0)
    * **`0.0`**: 그냥 평균치만 구한 것보다 못함 (의미 없는 모델)
    * **음수(예: `-0.5` 등)**: 모델이 엉터리로 예측함 (평균보다도 못 맞추는 심각한 상태)

---

### 4. 🎁 요약 및 실행 예시
백문이 불여일견! 초보자분들이 직접 파이썬에서 실행해 볼 수 있는 가장 간단한 예시 코드를 준비했습니다.

**[실행 코드]**
```python
# 1. 사이킷런(Scikit-learn) 라이브러리에서 r2_score 가져오기
from sklearn.metrics import r2_score

# 2. 실제 정답 (y_test) 과 모델이 예측한 값 (y_pred_all) 준비
y_test = [100, 150, 200, 250]      # 실제 집 값 (단위: 만 원)
y_pred_all = [110, 140, 190, 260]  # 우리 모델이 예측한 집 값

# 3. r2_score 함수 호출하여 점수 계산하기
r2_all = r2_score(y_test, y_pred_all)

# 4. 결과 출력
print(f"R2 Score 성적표: {r2_all}")
```

**[예상 결과]**
```text
R2 Score 성적표: 0.974...
```
* **해석:** 실제 값과 모델의 예측값이 아주 비슷하므로, 1에 가까운 매우 높은 점수(`0.97`)가 나온 것을 확인할 수 있습니다! 이처럼 내 모델이 우수한지 판단하고 싶을 때 `r2_score`를 사용하시면 됩니다.

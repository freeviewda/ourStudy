# len - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 10:45:08

---

파이썬 코드에서 사용된 `len()` 함수와 해당 문맥에 대한 상세 해설입니다. 초보자분들도 쉽게 이해하실 수 있도록 요청하신 4가지 항목으로 나누어 설명해 드릴게요!

---

### 1. 📌 함수 개요
`len()`은 파이썬의 **내장 함수(Built-in Function)**로, 리스트, 문자열, 튜플 등 **여러 개의 데이터를 담고 있는 객체의 길이(아이템의 개수)**를 세어 숫자로 알려주는 역할을 합니다. 
* 위 코드에서는 당뇨병(diabetes) 데이터셋의 피처(특성) 이름들이 몇 개 들어있는지 그 **개수**를 구하기 위해 사용되었습니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
코드 내에서 `len()` 함수의 괄호 안에는 다음과 같은 인자가 전달되었습니다.

* **전달된 인자:** `diabetes.feature_names`
* **상세 설명:**
  * **`diabetes`**: 사이킷런(Scikit-learn) 라이브러리에서 제공하는 '당뇨병 환자 데이터셋'을 담고 있는 변수입니다.
  * **`.feature_names`**: `diabetes` 데이터가 가지고 있는 **피처(컬럼)들의 이름 목록(리스트)**을 불러오는 속성(Attribute)입니다. 예를 들어 나이, 성별, BMI, 혈압 등 예측에 사용되는 10가지 데이터의 이름들이 문자열 형태로 들어있습니다.
  * **종합:** 즉, `len()` 함수는 10개의 피처 이름이 들어있는 리스트를 통째로 넘겨받아 그 리스트 안에 **아이템이 총 몇 개 들어있는지** 계산하게 됩니다. (이 데이터셋의 경우 결과는 `10`이 됩니다.)

---

### 3. 📤 반환값/할당 변수
`len()` 함수가 실행되면 그 결과는 다음과 같이 처리됩니다.

* **반환값:** 전달된 리스트의 길이를 나타내는 **정수(Integer)** 값입니다. (예: `10`)
* **코드 내 활용 (`f-string` 내부):**
  * 파이썬의 f-string(문자열 포맷팅 방식) 기법을 사용하여, 문자열 안에 중괄호 `{ }`를 열고 그 안에 `len(...)` 코드를 넣었습니다.
  * 이렇게 하면 함수가 실행되면서 반환된 숫자(`10`)가 문자열의 해당 위치에 쏙 들어가게 됩니다.
  * 최종 출력 예시: `"모든 피처 (10개):"`

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 파이썬 환경에서 `len()` 함수와 데이터셋의 구조를 테스트해 볼 수 있는 간단한 코드입니다.

**💻 실습 코드:**
```python
# 사이킷런에서 당뇨병 데이터셋 가져오기
from sklearn.datasets import load_diabetes

diabetes = load_diabetes()

# 1. 피처 이름들이 무엇이 있는지 확인해보기
print("피처 이름 리스트:", diabetes.feature_names)

# 2. len() 함수를 사용하여 피처의 개수 구하기
feature_count = len(diabetes.feature_names)
print(f"모든 피처 ({feature_count}개):")
```

**📺 예상 출력 결과:**
```text
피처 이름 리스트: ['age', 'sex', 'bmi', 'bp', 's1', 's2', 's3', 's4', 's5', 's6']
모든 피처 (10개):
```

> **💡 핵심 팁:** `len()`은 프로그래밍을 할 때 데이터의 개수를 동적으로 확인해야 할 때(예: 반복문을 돌리거나 데이터 크기를 체크할 때) 정말 자주 쓰이는 아주 기본적인 함수이 꼭 기억해 두세요!

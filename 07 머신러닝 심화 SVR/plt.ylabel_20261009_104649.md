파이썬의 데이터 시각화 라이브러리인 `matplotlib`에서 사용되는 `plt.ylabel` 함수에 대한 상세 해설입니다. 초보자분들이 쉽게 이해하실 수 있도록 항목별로 나누어 설명해 드릴게요!

---

### 1. 📌 함수 개요
`plt.ylabel()`은 **그림(Plot)의 Y축에 이름(라벨)을 달아주는 함수**입니다. 그래프를 보는 사람이 Y축이 무엇을 나타내는지(예: 가격, 점수, 온도 등) 직관적으로 알 수 있도록 설명 글귀를 적어주는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드에서 전달된 인자는 문자열 하나입니다.

* **`"Cross Validation Score (Negative MSE)"`**
  * **역할:** Y축에 표시될 텍스트(이름)를 지정합니다.
  * **설정된 값의 의미:** 
    * `Cross Validation Score`: 교차 검증(머신러닝 모델의 성능을 평가하는 방법)의 점수임을 나타냅니다.
    * `(Negative MSE)`: 평균 제곱 오차(MSE, Mean Squared Error)에 음수(-)를 취한 값을 사용한다는 뜻입니다. (MSE는 원래 값이 작을수록 좋은데, 머신러닝 라이브러리 중에는 '점수가 높을수록 좋다'는 규칙을 따르기 위해 오차에 마이너스를 붙여 점수처럼 다루는 경우가 많습니다.)

---

### 3. 📤 반환값/할당 변수
* **반환값:** 이 함수는 Y축 텍스트를 담당하는 `Text` 객체를 반환합니다.
* **할당 변수:** 제시해주신 코드(`plt.ylabel(...)`)에서는 반환값을 별도의 변수에 저장하지 않고 곧바로 화면에 반영되도록 사용했습니다. (보통은 변수에 담아두지 않고 이 형태로 끝냅니다.)

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 복잡한 설정 없이 직접 실행해 볼 수 있는 가장 간단한 전체 코드 예시입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 간단한 데이터 준비 (X축: 회차, Y축: 점수)
x = [1, 2, 3, 4, 5]
y = [-10, -8, -5, -3, -2]

# 2. 선 그래프 그리기
plt.plot(x, y)

# 3. X축과 Y축에 이름표 붙이기
plt.xlabel("Iteration (회차)")
plt.ylabel("Cross Validation Score (Negative MSE)")  # 👈 우리가 살펴본 함수!

# 4. 그래프 화면에 띄우기
plt.show()
```

**[예상 결과]**
* 창이 하나 뜨면서 꺾은선 그래프가 나타납니다.
* **Y축 왼쪽에 세로로** `"Cross Validation Score (Negative MSE)"`라는 글자가 예쁘게 적혀 있는 것을 확인할 수 있습니다.

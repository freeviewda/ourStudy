파이썬의 데이터 시각화 라이브러리인 **Matplotlib**에서 가장 자주 쓰이는 `plt.figure` 함수에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 하나씩 친절하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`plt.figure()`는 새로운 도화지(캔버스)를 생성하는 함수입니다. 파이썬에서 그림을 그리기 전에 "여기에 새로운 그림을 그릴 준비를 해라"라고 지시하는 역할을 합니다. 이 함수를 호출해야 비로소 그래프를 그릴 수 있는 빈 화면이 만들어집니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `plt.figure(figsize=(10, 6))`에서 사용된 인자의 역할은 다음과 같습니다.

*   **`figsize` (도화지 크기 설정)**
    *   **전달된 값:** `(10, 6)`
    *   **상세 의미:** 생성할 그래프(도화지)의 가로와 세로 크기를 인치(inch) 단위로 설정합니다. 
        *   앞의 숫자 `10`은 **가로 길이(10인치)**, 뒤의 숫자 `6`은 **세로 길이(6인치)**를 의미합니다.
        *   이 값을 조절하면 정사각형 모양, 직사각형 모양 등 원하는 비율의 넓고 시원한 그래프를 만들 수 있습니다. (기본값보다 보통 더 크고 보기 좋은 그래프를 만들 때 `(10, 6)`이나 `(12, 6)`을 자주 씁니다.)

---

### 3. 📤 반환값/할당 변수
질문하신 코드 `plt.figure(figsize=(10, 6))`는 반환값을 별도의 변수(예: `fig = plt.figure(...)`)에 저장하지 않고 바로 실행했습니다.

*   **반환값:** 이 함수는 생성된 **Figure(도화지) 객체**를 반환합니다.
*   **변수에 할당하지 않은 이유:** 변수에 담지 않고 바로 써도, Matplotlib이 "가장 최근에 만들어진 도화지"로 인식하여 이후에 작성하는 그래프 명령(`plt.plot()`, `plt.bar()` 등)을 이 도화지 위에 자동으로 그려주기 때문입니다.
*   *참고:* 나중에 도화지를 이미지 파일로 저장(`fig.savefig()`)하거나 세부 설정을 제어하고 싶다면 `fig = plt.figure(figsize=(10, 6))` 형태로 변수에 담아 사용하기도 합니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분이 직접 복사해서 실행해 볼 수 있는 가장 간단한 전체 코드입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 크기가 가로 10인치, 세로 6인치인 도화지 생성
plt.figure(figsize=(10, 6))

# 2. 간단한 데이터로 선 그래프 그리기
x = [1, 2, 3, 4, 5]
y = [2, 4, 6, 8, 10]
plt.plot(x, y, marker='o', color='blue', linewidth=2)

# 3. 그래프 제목과 축 이름 지정
plt.title("My First Plot with figsize", fontsize=14)
plt.xlabel("X Axis")
plt.ylabel("Y Axis")

# 4. 화면에 출력하기
plt.show()
```

**[예상 결과]**
*   모니터 화면에 가로로 조금 넓고 큼직한(10x6 비율) 직사각형 창이 뜨고, 그 안에 파란색 선과 동그란 마커가 찍힌 깔끔한 그래프가 나타납니다. 
*   `figsize=(10, 6)`를 지우고 `plt.figure()`만 실행해 보면, 기본 크기의 조금 더 정사각형에 가까운 작은 도화지가 생성되는 것을 비교하며 체감하실 수 있습니다!

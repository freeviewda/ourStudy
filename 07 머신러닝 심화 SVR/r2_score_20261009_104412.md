---

### 1. 📌 함수 개요
`r2_score`는 회귀 모델(숫자 값을 예측하는 모델)의 성능이 얼마나 뛰어난지 평가해 주는 **결정 계수(R-squared)**를 구하는 함수입니다. 
쉽게 말해, **"우리가 만든 인공지능이 실제 데이터를 얼마나 정확하게 맞혔는지(설명해 주는지)"**를 0과 1 사이의 점수로 나타내 주는 채점관 역할입니다. (1에 가까울수록 완벽한 예측입니다.)

---

### 2. 🔍 입력 인자(매개변수) 분석
제공해주신 코드 `r2_score(y_test, y_pred)`에서 사용된 두 가지 입력 인자의 역할은 다음과 같습니다.

*   **첫 번째 인자: `y_test` (정답 / 실제 값)**
    *   **역할:** 모델이 맞혀야 하는 **실제 데이터(Ground Truth)**입니다. 
    *   **의미:** 테스트 데이터셋의 실제 정답 값들이 들어있는 리스트나 배열입니다. 채점으로 치면 '정답지'에 해당합니다.
*   **두 번째 인자: `y_pred` (예측 값)**
    *   **역할:** 머신러닝 모델이 `y_test`를 보고 **예측해 낸 값(Predicted Value)**입니다.
    *   **의미:** 우리 모델이 실제로 예측한 결과들이 들어있는 리스트나 배열입니다. 채점으로 치면 학생이 작성한 '답안지'에 해당합니다.

---

### 3. 📤 반환값/할당 변수
`r2 = r2_score(y_test, y_pred)` 코드에서 반환된 값이 변수에 어떻게 저장되는지 살펴봅니다.

*   **할당받는 변수: `r2`**
    *   **데이터 종류:** 실수(Float, 소수점 형태의 숫자)
    *   **의미:** 계산된 **R² 점수(결정 계수)**가 이 변수에 저장됩니다.
    *   **점수 해석 팁:**
        *   `1.0`: 완벽하게 예측 성공!
        *   `0.0`: 모델이 데이터를 전혀 설명하지 못함 (그냥 평균값으로 찍는 것과 비슷한 수준)
        *   음수(`-값`): 모델이 평균값으로 예측하는 것보다도 더 못함 (성능이 매우 나쁨)

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 코드를 실행해 보며 감을 잡을 수 있도록 아주 간단한 예시 코드를 준비했습니다.

**[실행 코드]**
```python
# 1. 사이킷런(scikit-learn) 라이브러리에서 r2_score 함수 가져오기
from sklearn.metrics import r2_score

# 2. 실제 정답값(y_test)과 모델이 예측한 값(y_pred) 준비
y_test = [3.0, -0.5, 2.0, 7.0]
y_pred = [2.5, 0.0, 2.0, 8.0]

# 3. r2_score 함수를 이용해 성능 채점하기
r2 = r2_score(y_test, y_pred)

# 4. 결과 출력하기
print(f"R2 Score: {r2}")
```

**[예상 결과]**
```text
R2 Score: 0.9486...
```
*   **해설:** 실제 값과 예측 값이 매우 유사하기 때문에 1에 아주 가까운 `0.94`라는 높은 점수가 `r2` 변수에 저장되어 출력됩니다!

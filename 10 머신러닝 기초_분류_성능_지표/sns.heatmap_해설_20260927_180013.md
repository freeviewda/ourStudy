# 🤖 AI 파이썬 학습 노트: sns.heatmap

- **기록 일시**: 2026-09-27 18:00:13
- **대상 코드/함수**: `sns.heatmap`

---

파이썬 코드에서 사용된 `sns.heatmap` 함수와 전달된 인자들에 대해 초보자의 눈높이에 맞춰 쉽고 명쾌하게 해설해 드리겠습니다.

---

### 1. 📌 함수 개요
`sns.heatmap`은 파이썬의 데이터 시각화 라이브러리인 **Seaborn**에서 제공하는 함수로, **행렬 형태의 숫자 데이터를 색상의 강도로 표현하여 2차원 히트맵(Heatmap) 그래프로 그려주는 역할**을 합니다. 주로 머신러닝의 성능을 평가할 때 사용하는 **혼동 행렬(Confusion Matrix)**을 시각화할 때 가장 많이 쓰입니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
코드에 전달된 6개의 인자가 각각 어떤 의미를 가지고 있는지 하나씩 살펴보겠습니다.

*   **`cm` (첫 번째 위치 인자)**
    *   **역할:** 시각화할 원본 데이터입니다.
    *   **의미:** 보통 2차원 배열 형태의 **혼동 행렬(Confusion Matrix)** 데이터가 들어갑니다. 모델이 예측한 결과와 실제 정답을 비교한 숫자 데이터가 이 행렬에 담겨 있습니다.
*   **`annot=True`**
    *   **역할:** 각 칸(셀) 안에 실제 숫자(데이터 값)를 표시할지 여부입니다.
    *   **의미:** `True`로 설정했기 때문에, 색상만 채워지는 것이 아니라 **각 칸마다 정확한 숫자 값(예: 50, 10 등)이 텍스트로 함께 출력**됩니다. 숫자가 같이 보여야 직관적으로 분석하기 좋습니다.
*   **`fmt='d'`**
    *   **역할:** 셀에 표시되는 숫자의 형식(Format)을 지정합니다.
    *   **의미:** `'d'`는 **정수(Integer)**를 의미합니다. 혼동 행렬의 데이터는 개수(몇 개 맞췄는지 등)를 세는 것이므로 소수점 없이 깔끔한 정수로 표시하겠다는 뜻입니다.
*   **`cmap='Blues'`**
    *   **역할:** 히트맵의 색상 팔레트(Colormap)를 지정합니다.
    *   **의미:** `'Blues'`는 파란색 계열을 의미합니다. **숫자가 클수록(데이터가 많을수록) 더 진한 파란색**으로 칠해져서 한눈에 어떤 결과가 많은지 쉽게 알아볼 수 있습니다.
*   **`cbar=False`**
    *   **역할:** 오른쪽에 색상의 의미를 알려주는 막대(Colorbar)를 표시할지 여부입니다.
    *   **의미:** `False`로 설정하여 **색상 막대를 숨겼습니다.** 혼동 행렬의 경우 굳이 컬러바가 없어도 직관적으로 이해할 수 있기 때문에 깔끔한 출력을 위해주로 숨깁니다.
*   **`xticklabels=['Predicted Negative (0)', 'Predicted Positive (1)']`**
    *   **역할:** X축(가로축) 눈금의 이름(라벨)을 직접 지정합니다.
    *   **의미:** 모델이 **예측한(Predicted)** 값의 이름을 설정한 것으로, 왼쪽은 '예측 부정(0)', 오른쪽은 '예측 긍정(1)'으로 축의 이름을 보기 쉽게 바꿔줍니다.
*   **`yticklabels=['Actual Negative (0)', 'Actual Positive (1)']`**
    *   **역할:** Y축(세로축) 눈금의 이름(라벨)을 직접 지정합니다.
    *   **의미:** 데이터의 **실제(Actual)** 정답 값을 의미하며, 위쪽은 '실제 부정(0)', 아래쪽은 '실제 긍정(1)'으로 축의 이름을 보기 쉽게 설정합니다.

### 3. 📤 반환값/할당 변수
> 💡 **참고:** 질문하신 내용 중 `train_test_split`의 반환값에 대한 언급이 있으셨으나, **현재 보여주신 `sns.heatmap` 코드에는 변수에 결과를 할당하는 부분이 없습니다.** 

`sns.heatmap` 함수는 데이터를 별도의 변수로 쪼개어 반환(Unpacking)하는 함수가 아니라, **그림(Axes 객체)을 그려서 화면에 띄워주는 시각화 함수**입니다. 

따라서 이 코드가 실행되면 별도의 변수가 생성되는 대신, **Jupyter Notebook이나 파이썬 실행 창에 예측 결과와 실제 정답을 비교하는 멋지고 직관적인 파란색 격자 모양의 표(혼동 행렬 시각화 그래프)가 즉시 출력**되게 됩니다.

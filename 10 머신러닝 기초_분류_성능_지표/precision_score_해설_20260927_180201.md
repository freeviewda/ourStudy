# 🤖 AI 파이썬 학습 노트: precision_score

- **기록 일시**: 2026-09-27 18:02:01
- **대상 코드/함수**: `precision_score`

---

파이썬의 머신러닝 라이브러리인 `scikit-learn(sklearn)`에서 사용되는 `precision_score` 함수에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 친절하고 명쾌하게 정리해 드릴게요!

---

### 1. 📌 함수 개요
`precision_score`는 머신러닝 분류 모델의 성능을 평가하기 위해 사용하는 **'정밀도(Precision)'** 계산 함수입니다. 
모델이 **'정답(Positive)'이라고 예측한 것들 중에서 실제로 정답이 맞았던 비율**을 계산해 줍니다. (즉, 모델의 예측이 얼마나 믿을 만한지 측정하는 지표입니다.)

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `precision_score(y_test, y_pred)`에 사용된 두 개의 인자를 하나씩 살펴보겠습니다.

* **첫 번째 인자: `y_test` (실제값)**
  * **역할:** 테스트 데이터의 **실제 정답(Ground Truth)** 레이블입니다.
  * **의미:** 모델이 맞혀야 하는 진짜 판정 결과들이 들어있는 리스트나 배열입니다. (예: `[0, 1, 1, 0, 1]` 등)

* **두 번째 인자: `y_pred` (예측값)**
  * **역할:** 머신러닝 모델이 테스트 데이터를 보고 **예측한 결과(Prediction)** 레이블입니다.
  * **의미:** 모델이 "이건 정답이야!"라고 판단하여 뱉어낸 결과들이 들어있는 리스트나 배열입니다. (예: `[0, 1, 0, 0, 1]` 등)

> **💡 요약하자면:** `y_test`(실제 시험지 답안)와 `y_pred`(학생이 적어낸 답안)를 비교하여, 학생이 "맞다"고 쓴 것 중 실제로 맞은 게 몇 개나 되는지 채점하는 재료로 쓰입니다.

---

### 3. 📤 반환값/할당 변수
함수가 실행된 후 결과값이 어떤 변수에 담기는지 설명해 드릴게요.

* **할당 변수: `precision`**
  * **역할:** `precision_score` 함수가 계산을 끝내고 돌려준 **정밀도 점수(실수형 데이터, Float)**를 저장하는 변수입니다.
  * **의미:** 0.0에서 1.0 사이의 값(또는 백분율 형태)으로 반환됩니다. 
    * 예시로 값이 `0.85`가 나왔다면, 모델이 "정답"이라고 예측한 것 중 **85%만 실제로 맞았고, 15%는 틀렸다(오탐지)**는 것을 의미합니다.

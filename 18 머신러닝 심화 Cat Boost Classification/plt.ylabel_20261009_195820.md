파이썬의 데이터 시각화 라이브러리인 맷플롯립(Matplotlib)에서 사용되는 `plt.ylabel` 함수에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 친절하고 명쾌하게 정리해 드립니다!

---

### 1. 📌 함수 개요
`plt.ylabel()`은 **그려진 그래프의 세로축(Y축)에 이름(라벨)을 달아주는 함수**입니다. 그래프를 보는 사람이 Y축이 무엇을 나타내는지 직관적으로 이해할 수 있도록 도와줍니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `plt.ylabel("Features")`에서 전달된 인자의 의미는 다음과 같습니다.

*   **`"Features"` (문자열, string)**
    *   **역할:** Y축에 표시될 텍스트(이름)를 지정합니다.
    *   **설정된 값의 의미:** 굳이 번역하자면 "특징들" 또는 "특성들"이라는 뜻으로, 머신러닝이나 데이터 분석에서 데이터의 열(Column) 이름을 Y축에 나타낼 때 주로 사용됩니다.
    *   *참고:* 이 위치에 원하는 텍스트("Price", "Age", "Score" 등)를 큰따옴표나 작은따옴표로 감싸서 넣으면 그대로 Y축 이름으로 출력됩니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값 없음 (None 또는 Text 객체 반환)**
    *   이 함수는 화면에 Y축 글자를 띄워주는 역할을 메인으로 하기 때문에, 별도의 변수에 값을 대입(`result = plt.ylabel(...)`)하여 사용하는 경우는 초보자 단계에서는 거의 없습니다. 
    *   내부적으로는 생성된 텍스트 객체를 반환하지만, 보통은 함수를 단독으로 호출하여 사용합니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 파이썬 환경(Jupyter Notebook 등)에서 직접 복사해서 실행해 볼 수 있는 가장 간단한 전체 코드 예시입니다.

```python
import matplotlib.pyplot as plt

# 1. 간단한 데이터 준비
x_values = [1, 2, 3, 4]
y_values = [10, 20, 25, 30]

# 2. 그래프 그리기
plt.plot(x_values, y_values)

# 3. X축과 Y축에 이름(라벨) 붙이기
plt.xlabel("Index")       # X축 이름 설정
plt.ylabel("Features")    # Y축 이름 설정 (오늘 배운 함수!)

# 4. 그래프 화면에 출력하기
plt.show()
```

**💡 예상 결과:**
창이 뜨면서 꺾은선 그래프가 나타나고, **가로축(X축) 아래에는 "Index"**라는 글자가, **세로축(Y축) 왼쪽에는 "Features"**라는 글자가 예쁘게 표시됩니다.

# classification_report - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 19:53:24

---

머신러닝 분류(Classification) 모델의 성능을 한눈에 평가할 때 가장 널리 쓰이는 **`classification_report`** 함수에 대한 상세 해설입니다.

---

### 1. 📌 함수 개요
**`classification_report`**는 분류 모델의 예측 결과가 실제 정답과 얼마나 일치하는지를 정밀도(Precision), 재현율(Recall), F1-점수(F1-score) 등 **핵심 평가지표로 종합 정리해 표(텍스트) 형태로 출력해 주는 함수**입니다.  
단순한 '정확도(Accuracy)' 하나만으로는 놓치기 쉬운 클래스별 세부 성능을 한눈에 파악할 수 있게 돕습니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `classification_report(y_test, y_pred)`에 전달된 인자들의 의미는 다음과 같습니다.

* **`y_test` (첫 번째 인자, 실제 매개변수명: `y_true`)**
  * **의미:** 모델 평가를 위해 따로 빼둔 **'실제 정답 데이터(Ground Truth)'**입니다.
  * **역할:** 모델이 맞혀야 하는 기준(시험지의 정답지) 역할을 합니다.
* **`y_pred` (두 번째 인자, 실제 매개변수명: `y_pred`)**
  * **의미:** 머신러닝 모델이 테스트 데이터(X_test)를 보고 **'예측해 낸 값'**입니다.
  * **역할:** 학생이 시험지에 적어낸 답안지 역할을 하며, `y_test`와 1:1로 비교됩니다.

> 💡 **참고 (자주 함께 쓰이는 유용한 추가 인자):**
> * `target_names`: 숫자(0, 1) 대신 `['스팸 아님', '스팸']`처럼 클래스 이름을 보기 좋게 표시하고 싶을 때 사용합니다.
> * `output_dict=True`: 결과를 텍스트가 아닌 파이썬 **딕셔너리(dict)** 형태로 받아 프로그램 내부에서 수치 데이터를 활용하고 싶을 때 사용합니다.

---

### 3. 📤 반환값/할당 변수
코드에서는 반환값을 별도 변수에 담지 않고 `f-string`을 통해 `print()` 함수로 바로 출력하고 있습니다. 반환되는 기본 데이터는 **문자열(String)** 형태의 성능 요약 리포트입니다.

리포트에 포함된 각 열(Column)의 의미는 다음과 같습니다:

1. **Precision (정밀도):** 모델이 "이거 맞아(예: 스팸)"라고 예측한 것 중에서 **진짜 맞은 비율** (예측의 정확성)
2. **Recall (재현율):** 실제로 "맞는 데이터"들 중에서 **모델이 놓치지 않고 찾아낸 비율** (적중률)
3. **F1-score:** 정밀도와 재현율의 균형을 보는 지표 (둘의 조화평균값, 1에 가까울수록 우수)
4. **Support:** 각 클래스(정답 범주)에 속한 **실제 데이터의 개수**
5. **Accuracy / Macro avg / Weighted avg:** 전체 정확도 및 클래스별 점수들의 단순 평균 / 데이터 수(Support)를 고려한 가중 평균

---

### 4. 🎁 요약 및 실행 예시

초보자도 바로 복사해서 실행해 볼 수 있는 미니 예제 코드입니다.

#### [실행 코드]
```python
from sklearn.metrics import classification_report

# 1. 가상의 실제 정답(y_test)과 모델의 예측값(y_pred) 준비
# (0: 정상 메일, 1: 스팸 메일)
y_test = [0, 0, 0, 0, 1, 1, 1, 1]
y_pred = [0, 0, 0, 1, 1, 1, 1, 0]  # 모델이 3번 인덱스와 7번 인덱스를 틀림

# 2. 리포트 출력 (클래스 이름 지정)
report = classification_report(y_test, y_pred, target_names=["정상 메일", "스팸 메일"])

print(f"\n분류 리포트:\n{report}")
```

#### [예상 출력 결과]
```text
분류 리포트:
              precision    recall  f1-score   support

       정상 메일       0.75      0.75      0.75         4
       스팸 메일       0.75      0.75      0.75         4

    accuracy                           0.75         8
   macro avg       0.75      0.75      0.75         8
weighted avg       0.75      0.75      0.75         8
```
> **한 줄 요약:**  
> 모델이 잘 맞혔는지 채점할 때 `정답(y_test)`과 `답안(y_pred)`을 넘겨주면, **정밀도·재현율·F1점수를 일목요연한 성적표로 뽑아주는 함수**입니다!

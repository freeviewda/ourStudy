# ax.set_ylabel - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 19:55:58

---

파이썬의 데이터 시각화 라이브러리인 맷플롯립(Matplotlib)에서 사용되는 `ax.set_ylabel` 함수에 대한 상세 해설입니다.

---

### 1. 📌 함수 개요
`ax.set_ylabel`은 그래프의 **Y축(세로축)에 이름(라벨)을 지정**해 주는 함수입니다. 그래프를 보는 사람이 세로축이 무엇을 나타내는지(예: 정답률, 가격, 온도 등) 쉽게 이해할 수 있도록 설명글을 달아주는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시된 코드 `ax.set_ylabel('Accuracy')`에서 사용된 인자의 역할과 의미는 다음과 같습니다.

*   **`'Accuracy'` (문자열, Positional Argument)**
    *   **역할**: Y축에 표시할 텍스트(이름)를 지정합니다.
    *   **의미**: 여기서는 'Accuracy(정확도)'라는 문자열을 전달하여, 이 세로축이 모델의 예측 정확도를 나타냄을 시각적으로 알려줍니다.
    *   *참고:* 이 외에도 글자 크기를 바꾸는 `fontsize`, 글자 색상을 바꾸는 `color` 등 다양한 추가 인자(Keyword Argument)를 함께 사용할 수 있습니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값 없음 (None)**
    *   이 함수는 Y축의 설정값만 바꾸고, 별도의 데이터를 반환하지 않습니다. (파이썬 내부적으로는 `None`을 반환합니다.)
    *   따라서 별도의 변수에 값을 할당(`result = ax.set_ylabel(...)`)할 필요 없이, 단독으로 호출하여 사용합니다.

---

### 4. 🎁 요약 및 실행 예시
초보자도 주피터 노트북이나 파이썬 환경에서 복사해서 바로 실행해 볼 수 있는 가장 간단한 예시 코드입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 도화지(Figure)와 축(Axes) 객체 생성
fig, ax = plt.subplots()

# 2. 간단한 데이터로 선 그래프 그리기
x = [1, 2, 3, 4]
y = [0.5, 0.7, 0.85, 0.95]
ax.plot(x, y)

# 3. Y축 이름 설정 (★ 핵심 함수 사용)
ax.set_ylabel('Accuracy')

# 4. X축 이름도 세트로 자주 사용됩니다
ax.set_xlabel('Epoch')

# 5. 그래프 화면에 띄우기
plt.show()
```

**[예상 결과]**
*   가로축(X축)에는 'Epoch', **세로축(Y축)에는 'Accuracy'**라는 글자가 예쁘게 적혀 있는 선 그래프가 화면에 팝업 창으로 나타납니다.

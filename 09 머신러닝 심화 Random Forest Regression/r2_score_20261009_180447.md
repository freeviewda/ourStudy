# r2_score - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 18:04:47

---

파이썬 머신러닝에서 자주 쓰이는 `r2_score` 함수에 대해 초보자의 눈높이에 맞춰 쉽고 명쾌하게 해설해 드리겠습니다.

---

### 1. 📌 함수 개요
`r2_score`는 머신러닝 회귀 모델(숫자를 예측하는 모델)이 **"데이터를 얼마나 잘 예측했는지" 성능을 평가**해 주는 함수입니다. 
* **결정 계수(R-squared)**라는 지표를 계산하며, 쉽게 말해 **"우리가 만든 모델이 정답을 평균치보다 얼마나 더 잘 맞히는지"**를 0과 1 사이의 점수(때로는 음수)로 나타내 줍니다.

---

### 2. 🔍 입력 인자(매개변수) 분석

제시해주신 코드 `r2_score(y_test, y_pred_default)`에는 총 2개의 입력 인자가 순서대로 전달되었습니다.

* **첫 번째 인자: `y_test` (실제 정답)**
  * **역할:** 모델이 맞혀야 하는 **진짜 정답 데이터**입니다. (테스트용 데이터셋의 실제값)
  * **의미:** 평가의 기준이 되는 데이터로, "원래 이 값이어야 한다"는 절대적인 기준점 역할을 합니다.

* **두 번째 인자: `y_pred_default` (모델의 예측값)**
  * **역할:** 기본 설정(Default)으로 학습된 머신러닝 모델이 **예측해 낸 값**입니다.
  * **의미:** "우리 모델이 이렇게 예측했다"는 결과물로, 첫 번째 인자(`y_test`)와 비교당할 대상입니다.

> 💡 **핵심 요약:** "실제 정답(`y_test`)과 모델이 예측한 값(`y_pred_default`)을 서로 비교해서 점수를 매겨줘!" 라는 의미입니다.

---

### 3. 📤 반환값/할당 변수

* **할당 변수: `r2_default`**
  * **역할:** `r2_score` 함수가 계산을 끝내고 돌려주는 **최종 성능 점수**를 저장하는 변수입니다.
  * **데이터 종류:** 실수(Float, 소수점 형태의 숫자)
  * **점수 읽는 법:**
    * **`1.0`에 가까울수록:** 모델이 예측을 완벽하게 잘한 것입니다. (정답과 예측이 거의 일치)
    * **`0.0` 부근일 경우:** 모델이 데이터를 전혀 학습하지 못하고 단순히 평균값 정도로만 맞히는 수준입니다.
    * **음수(`-` 값)일 경우:** 모델이 평균값으로 예측하는 것보다도 못할 정도로 엉터리로 예측했다는 뜻입니다.

---

### 4. 🎁 요약 및 실행 예시

초보자분들이 직접 코드를 실행해 보며 감을 잡을 수 있도록 아주 간단한 예시 코드를 준비했습니다.

**[간단한 실습 코드]**
```python
from sklearn.metrics import r2_score

# 1. 실제 정답 (예: 집값, 단위: 천만원)
y_test = [3억, 5억, 4억, 6억] -> 코드로 쓰면 [30, 50, 40, 60]
y_test = [30, 50, 40, 60]

# 2. 모델이 예측한 값
y_pred_default = [32, 48, 41, 58]

# 3. R2 점수 계산하기
r2_default = r2_score(y_test, y_pred_default)

# 4. 결과 출력
print(f"R2 점수: {r2_default}")
```

**[예상 결과]**
```text
R2 점수: 0.95...
```
*(해설: 점수가 0.95로 1에 아주 가깝게 나왔으므로, 이 모델은 집값을 굉장히 정확하게 잘 맞히는 훌륭한 모델이라고 평가할 수 있습니다!)*

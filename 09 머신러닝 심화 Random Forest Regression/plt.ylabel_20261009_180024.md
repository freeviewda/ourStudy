---

파이썬 데이터 시각화에서 가장 많이 쓰이는 `matplotlib.pyplot` 라이브러리의 `plt.ylabel` 함수에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 쉽고 명쾌하게 정리해 드릴게요!

---

### 1. 📌 함수 개요
`plt.ylabel()`은 **그려진 그래프의 세로축(Y축)에 이름(라벨)을 달아주는 함수**입니다. 그래프를 보는 사람이 "이 세로축이 무엇을 나타내는 값인지" 직관적으로 이해할 수 있도록 도와줍니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시된 코드 `plt.ylabel('Predicted Values')`에서 전달된 인자의 의미는 다음과 같습니다.

*   **`'Predicted Values'` (위치 인자 / 문자열)**
    *   **역할:** Y축에 표시될 텍스트(이름)를 지정합니다.
    *   **설정값 의미:** 영문 그대로 **'예측된 값들'**이라는 뜻입니다. 머신러닝 모델이 예측한 결과값을 시각화할 때, Y축이 무엇을 의미하는지 알려주기 위해 이와 같이 설정했습니다.
    *   *참고:* 이외에도 글자 크기를 바꾸는 `fontsize`, 글자 색상을 바꾸는 `color` 등 다양한 추가 인자(옵션)를 함께 사용할 수 있습니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값:** `plt.ylabel()` 함수는 텍스트가 그려진 위치와 속성을 담은 **`Text` 객체(오브젝트)**를 반환합니다.
*   **할당 변수:** 제시된 코드에서는 반환값을 별도의 변수에 저장하지 않고(`Text` 객체를 받지 않고) 함수만 단독으로 실행했습니다. 파이썬에서는 단순히 화면에 글자를 띄우기만 할 때 이처럼 변수 할당 없이 사용해도 무방합니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 주피터 노트북이나 파이썬 파일에서 복사해서 바로 실행해 볼 수 있는 가장 간단한 예시 코드입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 간단한 데이터 준비 (X축: 공부 시간, Y축: 예측 점수)
x = [1, 2, 3, 4, 5]
y = [50, 60, 70, 80, 90]

# 2. 산점도(점 그래프) 그리기
plt.plot(x, y, marker='o')

# 3. 그래프 제목과 축 이름 달기
plt.title('Study Time vs Score')
plt.xlabel('Study Hours')
plt.ylabel('Predicted Values')  # 👈 오늘의 핵심 함수! (Y축 이름을 'Predicted Values'로 지정)

# 4. 그래프 화면에 출력하기
plt.show()
```

**[예상 결과]**
*   창이 뜨면서 선 그래프가 나타납니다.
*   그래프의 **세로축(Y축) 왼쪽**에 **`Predicted Values`**라는 글자가 예쁘게 적혀 있는 것을 확인할 수 있습니다.

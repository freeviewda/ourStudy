---

### 1. 📌 함수 개요
`plt.title()`은 **그려진 그래프의 맨 위에 제목(Title)을 달아주는 함수**입니다. 
보고 있는 그래프가 어떤 데이터를 다루고 있는지 누구나 한눈에 알아볼 수 있도록 이름을 붙여주는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `plt.title("Feature Importances (LightGBM)")`에서 괄호 안에 들어간 값은 제목으로 사용할 **문자열(String)**입니다.

* **`"Feature Importances (LightGBM)"`**
  * **역할:** 그래프 상단에 표시될 텍스트를 지정합니다.
  * **설정된 값의 의미:** 
    * `Feature Importances`: 머신러닝 모델(여기서는 LightGBM)이 예측을 할 때 **어떤 특성(Feature, 열 데이터)이 가장 중요한 역할을 했는지** 그 중요도를 나타내는 그래프임을 뜻합니다.
    * `(LightGBM)`: 이 중요도를 계산해낸 머신러닝 알고리즘의 이름이 **LightGBM**임을 명시해 줍니다.

*(참고로 이 함수는 글자 크기(`fontsize`), 글자 색상(`color`), 위치(`loc`) 등 다양한 추가 인자를 받을 수 있지만, 현재 코드에서는 가장 기본이 되는 제목 텍스트만 전달되었습니다.)*

---

### 3. 📤 반환값/할당 변수
* **반환값:** 이 함수는 제목을 텍스트 객체(`matplotlib.text.Text`)로 반환합니다.
* **할당 변수:** 현재 코드에서는 `=` 기호나 변수 할당 없이 `plt.title(...)` 형태로만 단독 사용되었습니다. 이 경우, 파이썬은 반환값을 따로 저장하지 않고 **화면(그래프)에 제목을 바로 띄우는 역할만 수행**하게 됩니다. (보통 제목을 변수에 담아두고 나중에 수정할 일이 거의 없기 때문에 이렇게 단독으로 많이 씁니다.)

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 복사해서 실행해 볼 수 있는 가장 간단한 전체 코드 예시입니다. 라이브러리를 임포트하고 그래프를 그린 뒤, `plt.title()`을 어떻게 호출하는지 확인해 보세요!

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 간단한 막대 그래프 데이터 준비
features = ['Age', 'Income', 'Score']
importance = [0.5, 0.3, 0.2]

# 2. 그래프 그리기
plt.bar(features, importance)

# 3. 그래프 제목 달기 (오늘 배운 함수!)
plt.title("Feature Importances (LightGBM)")

# 4. 화면에 그래프 보여주기
plt.show()
```

**[예상 결과]**
* 화면에 3개의 막대 그래프가 나타나며, **그래프 바로 위 중앙**에 깔끔하게 **`Feature Importances (LightGBM)`** 라는 제목이 인쇄되어 나타납니다.

# GridSearchCV - AI 파이썬 학습 노트

- 생성 일시: 2026-10-12 03:19:48

---

파이썬 머신러닝 라이브러리인 Scikit-Learn(사이킷런)에서 제공하는 `GridSearchCV` 함수에 대해 초보자의 눈높이에 맞춰 아주 쉽고 명쾌하게 설명해 드리겠습니다!

---

### 1. 📌 함수 개요
`GridSearchCV`는 머신러닝 모델의 성능을 가장 높여주는 **최적의 하이퍼파라미터(사람이 직접 설정해야 하는 설정값)를 찾아주는 도구**입니다. 
우리가 일일이 값을 바꿔가며 실험해 볼 필요 없이, 지정해둔 여러 후보 값들을 **모두 조합**해 보면서 가장 성능이 좋은 조합을 자동으로 찾아줍니다. (Grid = 격자/바둑판, Search = 탐색, CV = 교차 검증)

---

### 2. 🔍 입력 인자(매개변수) 분석

제시해주신 코드에서 사용된 6가지 인자의 역할과 설정된 값의 의미는 다음과 같습니다.

*   **`lgbm_clf` (첫 번째 위치 인자)**
    *   **역할:** 최적화를 수행할 기본 머신러닝 모델(여기서는 LightGBM 분류 모델)입니다.
    *   **의미:** "이 모델을 가지고 가장 좋은 성능을 내는 설정을 찾아줘!"라고 지시하는 것입니다.
*   **`param_grid`**
    *   **역할:** 테스트해 볼 하이퍼파라미터들의 후보를 담은 딕셔너리(Dictionary)입니다.
    *   **의미:** 예를 들어 `{'max_depth': [3, 5], 'learning_rate': [0.1, 0.01]}`과 같이 설정했다면, 이 모델이 가질 수 있는 모든 조합(총 4가지 경우의 수)을 전부 테스트해 보게 됩니다.
*   **`cv=StratifiedKFold(5)`**
    *   **역할:** 데이터를 몇 개의 조각으로 나누어 교차 검증(Cross Validation)을 진행할지 결정합니다.
    *   **의미:** 데이터를 5개로 쪼개서(5-Fold), 4개는 공부(훈련)용으로 쓰고 나머지 1개는 시험(검증)용으로 쓰는 과정을 5번 반복합니다. 특히 `Stratified`가 붙어 있어서 정답(클래스)의 비율이 한쪽으로 치우치지 않게 골고루 잘 섞어서 나눠줍니다.
*   **`scoring='accuracy'`**
    *   **역할:** 모델의 성능을 평가하는 기준(지표)을 무엇으로 할지 정합니다.
    *   **의미:** 여기서는 '정확도(Accuracy)'를 기준으로 삼아, 가장 정확도가 높게 나온 하이퍼파라미터 조합을 '최고의 설정'으로 뽑겠다는 뜻입니다.
*   **`n_jobs=-1`**
    *   **역할:** 컴퓨터의 CPU를 몇 개나 사용할지 지정합니다.
    *   **의미:** `-1`은 **"내 컴퓨터에 있는 모든 CPU 코어를 다 동원해서 빠르게 계산해라!"**라는 뜻입니다. 모델 탐색 시간이 단축됩니다.
*   **`verbose=1`**
    *   **역할:** 학습(탐색) 진행 상황을 화면에 얼마나 자세히 출력할지 정합니다.
    *   **의미:** `0`이면 아무것도 출력하지 않고 조용히 일하고, `1` 이상이면 "지금 몇 번째 조합을 테스트 중인지" 진행 상황을 로그로 보여줍니다.

---

### 3. 📤 반환값/할당 변수

*   **`grid_clf` (할당된 변수)**
    *   **설명:** `GridSearchCV` 객체 자체가 반환되어 `grid_clf`에 저장됩니다. 
    *   이 변수(`grid_clf`)는 아직 그냥 도구일 뿐이며, 뒤에 `.fit(X_train, y_train)`을 붙여서 실제로 데이터를 넣고 학습을 시켜야 비로소 작동합니다.
    *   학습이 끝난 후에는 `grid_clf.best_params_`로 **가장 좋았던 설정값**을 확인할 수 있고, `grid_clf.best_estimator_`로 **가장 성능이 좋은 모델**을 꺼내 쓸 수 있습니다.

---

### 4. 🎁 요약 및 실행 예시

전체 흐름을 한눈에 볼 수 있는 간단한 실습 코드입니다.

```python
from lightgbm import LGBMClassifier
from sklearn.model_selection import GridSearchCV, StratifiedKFold
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

# 1. 데이터 불러오기
iris = load_iris()
X_train, X_test, y_train, y_test = train_test_split(iris.data, iris.target, random_state=42)

# 2. 모델 준비
lgbm_clf = LGBMClassifier(random_state=42)

# 3. 탐색할 파라미터 후보 설정
param_grid = {
    'max_depth': [3, 5],
    'learning_rate': [0.1, 0.05]
}

# 4. GridSearchCV 설정 (질문하신 코드!)
grid_clf = GridSearchCV(
    lgbm_clf,
    param_grid,
    cv=StratifiedKFold(5),
    scoring='accuracy',
    n_jobs=-1,
    verbose=1
)

# 5. 실제로 학습 시작 (이때 모든 조합을 테스트하며 최적의 값을 찾습니다)
grid_clf.fit(X_train, y_train)

# 6. 결과 확인
print("가장 좋은 설정값:", grid_clf.best_params_)
print("가장 높은 정확도:", grid_clf.best_score_)
```

**💡 한 줄 요약:** 
`GridSearchCV`는 **"내가 지정한 여러 옵션 조합 중, 5겹 교차 검증을 통해 정확도가 가장 높게 나오는 꿀조합을 모든 CPU를 동원해 찾아줘!"** 라고 컴퓨터에게 명령하는 똑똑한 탐색 로봇입니다.

# 🤖 AI 파이썬 학습 노트: plt.tight_layout

- **기록 일시**: 2026-09-21 22:01:09
- **대상 코드/함수**: `plt.tight_layout`

---

plt.tight_layout()은 마치 좁은 방에 여러 가구를 들여놓았을 때, 서로 부딪히지 않게 깔끔하게 자리 배치와 간격을 알아서 싹 정리해 주는 똑똑한 가구 배치사와 같아요. 

그래프를 그리다 보면 제목, 축 이름, 눈금 숫자끼리 서로 겹치거나 잘려서 답답해 보일 때가 많은데, 이 함수 한 줄만 톡 적어주면 모든 요소들이 알맞은 자리를 찾아가서 아주 보기 좋고 깔끔하게 정돈된답니다.

# 🤖 AI 파이썬 학습 노트: classification_report

- **기록 일시**: 2026-09-23 05:18:03
- **대상 코드/함수**: `classification_report`

---

파이썬 머신러닝에서 모델의 성능을 평가할 때 가장 자주 쓰이는 `classification_report` 함수에 대해 초보자의 눈높이에 맞춰 알기 쉽게 정리해 드릴게요!

---

### 1. 📌 함수 개요
`classification_report`는 머신러닝 분류(Classification) 모델이 예측한 결과가 **실제 정답과 얼마나 잘 맞았는지 한눈에 보여주는 '성적표'를 만들어주는 함수**입니다. 정밀도(Precision), 재현율(Recall), F1-점수(F1-score) 등 모델의 성능을 종합적으로 평가할 수 있는 핵심 지표들을 텍스트 형태로 예쁘게 출력해 줍니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제공해주신 코드 안에서 `classification_report`에 전달된 3가지 인자의 역할은 다음과 같습니다.

*   **`y_test` (첫 번째 인자)**
    *   **역할:** 테스트 데이터의 **실제 정답(True Labels)**입니다.
    *   **의미:** 모델이 맞혀야 하는 진짜 0과 1의 값들이 들어있는 모음입니다.
*   **`y_pred` (두 번째 인자)**
    *   **역할:** 머신러닝 모델이 예측한 **예측값(Predicted Labels)**입니다.
    *   **의미:** 모델이 "이 데이터는 0이야, 저 데이터는 1이야"라고 판단한 결과들의 모음입니다. (이 `y_pred`와 위의 `y_test`를 비교해서 성적표가 만들어집니다.)
*   **`target_names=['No Diabetes (0)', 'Diabetes (1)']`**
    *   **역할:** 컴퓨터가 이해하는 숫자(0과 1) 레이블에 **사람이 읽기 쉬운 이름(이름표)을 붙여주는 인자**입니다.
    *   **의미:** 기본적으로는 성적표에 `0`, `1`이라는 숫자만 덜렁 표시되지만, 이 인자를 통해 `0`은 '당뇨가 아님(No Diabetes)', `1`은 '당뇨(Diabetes)'라는 것을 명시하여 **성적표를 훨씬 보기 편하게 만들어 줍니다.**

---

### 3. 📤 반환값/할당 변수
질문에서 언급해주신 `X_train, X_test...` 같은 데이터 분할 변수들과는 달리, `classification_report`는 변수에 따로 값을 쪼개어 담는(언패킹하는) 구조가 아닙니다. 

이 함수는 보통 다음과 같이 사용됩니다:
```python
print(classification_report(y_test, y_pred, target_names=['No Diabetes (0)', 'Diabetes (1)']))
```

*   **반환되는 형태:** 함수가 실행되면 변수에 저장되는 대신, **문자열(String) 형태의 성적표 문서 자체**를 반환합니다.
*   **출력 결과의 의미:** `print()` 함수와 함께 사용되었기 때문에, 모니터 화면에 다음과 비슷한 형태로 표가 즉시 출력됩니다.
    *   **Precision (정밀도):** 모델이 '당뇨(1)'라고 예측한 것 중에서 **실제로 당뇨였던 사람의 비율**
    *   **Recall (재현율):** 실제 '당뇨(1)'인 환자들 중에서 **모델이 당뇨라고 맞힌 사람의 비율**
    *   **F1-score (F1 점수):** 정밀도와 재현율의 조화 평균 (모델의 전체적인 균형 잡힌 성능을 나타냄)
    *   **Support:** 각 그룹에 속한 실제 데이터의 개수

# 🤖 AI 파이썬 학습 노트: value_counts

- **기록 일시**: 2026-09-27 17:43:26
- **대상 코드/함수**: `value_counts`

---

파이썬 데이터 분석에서 가장 많이 쓰이는 필수 함수 중 하나인 `value_counts()`에 대해 초보자의 눈높이에 맞춰 친절하고 명쾌하게 설명해 드리겠습니다.

---

### 1. 📌 함수 개요
`value_counts()`는 판다스(Pandas) 데이터프레임의 특정 열(Column)에 들어있는 **데이터의 종류별 개수(빈도수)를 세어주는 함수**입니다. 데이터에 어떤 값들이 몇 번씩 등장하는지 빠르게 파악하여, 데이터의 분포나 불균형 상태를 확인할 때 매우 유용하게 사용됩니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `df['outcome'].value_counts()`를 보면, 괄호 `()` 안에 **아무런 인자(값)도 전달되지 않았습니다.** 

이렇게 괄호를 비워둘 경우, 파이썬은 다음과 같이 **기본값(Default)**으로 동작합니다.
* **전달된 인자:** 없음
* **설정된 의미:** 
  * 기본적으로 **내림차순(큰 것에서 작은 순서)**으로 정렬하여 결과를 보여줍니다. 즉, 가장 많이 등장한 데이터가 맨 위에 나타납니다.
  * 결측치(NaN, 비어있는 값)는 기본적으로 개수 세기에서 제외됩니다.

> **💡 참고 (자주 함께 쓰이는 주요 인자들):**
> 만약 괄호 안에 설정을 추가하고 싶다면 아래와 같은 인자들을 넣을 수 있습니다.
> * `dropna=False`: 결측치(`NaN`)의 개수도 함께 세고 싶을 때 사용합니다.
> * `normalize=True`: 개수 대신 전체 데이터 중 해당 값이 차지하는 **비율(백분율 형태)**로 보고 싶을 때 사용합니다.
> * `ascending=True`: 오름차순(작은 것에서 큰 순서)으로 정렬하고 싶을 때 사용합니다.

---

### 3. 📤 반환값/할당 변수
이 코드는 별도의 변수에 값을 저장하지 않고 바로 `print()` 함수로 출력하고 있습니다. 함수가 실행되어 화면에 나타나는 결과(반환값)의 구조는 다음과 같습니다.

* **반환되는 데이터 형태:** 판다스 **시리즈(Series)** 객체
* **구조 설명:**
  * **인덱스(Index):** `outcome` 열에 존재하던 **고유한 데이터 값들** (예: '성공', '실패' 또는 `0`, `1`)이 행 이름(인덱스)으로 지정됩니다.
  * **값(Values):** 각 데이터 값이 **등장한 횟수(개수)**가 숫자로 표시됩니다.

**예시 화면:**
```text
0    300
1    100
Name: outcome, dtype: int64
```
* **해석:** `outcome` 열에는 `0`이라는 데이터가 300번, `1`이라는 데이터가 100번 들어있음을 한눈에 알 수 있습니다.

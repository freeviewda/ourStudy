# 🤖 AI 파이썬 학습 노트: accuracy_score

- **기록 일시**: 2026-09-27 17:46:34
- **대상 코드/함수**: `accuracy_score`

---

파이썬 머신러닝에서 자주 사용되는 `accuracy_score` 함수에 대해 초보자의 눈높이에 맞춰 쉽고 명쾌하게 설명해 드리겠습니다.

---

### 1. 📌 함수 개요
`accuracy_score`는 머신러닝 모델이 예측한 결과가 실제 정답과 얼마나 일치하는지, 즉 **'정확도(Accuracy)'를 계산해 주는 평가 함수**입니다. 전체 예측 데이터 중 모델이 맞춘 데이터의 비율을 0과 1 사이의 값(또는 0% ~ 100%)으로 반환합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제공해주신 코드 `accuracy_score(y_test, y_pred)`에서 사용된 두 개의 입력 인자는 다음과 같습니다.

*   **첫 번째 인자: `y_test` (실제 정답)**
    *   **역할:** 모델이 학습에 전혀 사용하지 않고 남겨둔 **테스트 데이터의 실제 정답(Label)**입니다.
    *   **의미:** "이 데이터가 진짜 참이야"라고 알려주는 기준점 역할을 합니다.
*   **두 번째 인자: `y_pred` (모델의 예측값)**
    *   **역할:** 머신러닝 모델(`y_test`에 대응하는 테스트 피처를 넣어 얻은 결과)이 **"이럴 것이다"라고 예측한 값**입니다.
    *   **의미:** 모델의 성적을 매기기 위해 제출한 답안지라고 생각하시면 됩니다.

> 💡 **동작 원리:** 함수는 `y_test`(실제 답)와 `y_pred`(모델의 답)를 일대일로 비교하여 몇 개나 맞았는지 세어본 뒤, 전체 개수로 나누어 정확도를 계산합니다.

---

### 3. 📤 반환값/할당 변수
함수 실행 결과가 저장되는 변수 `accuracy`에 대한 설명입니다.

*   **할당 변수: `accuracy`**
    *   **데이터 종류:** `float`(실수형) 타입의 숫자입니다.
    *   **의미:** 모델의 예측 정확도를 나타냅니다.
        *   예를 들어 이 변수에 `0.85`가 들어있다면, 모델이 전체 테스트 데이터 중 **85%를 맞췄다**는 뜻입니다. (최소 0.0 [0%]부터 최대 1.0 [100%]까지의 값을 가집니다.)

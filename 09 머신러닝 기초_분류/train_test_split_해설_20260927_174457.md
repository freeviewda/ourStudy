# 🤖 AI 파이썬 학습 노트: train_test_split

- **기록 일시**: 2026-09-27 17:44:57
- **대상 코드/함수**: `train_test_split`

---

파이썬 머신러닝에서 가장 많이 쓰이는 필수 함수 중 하나인 `train_test_split`에 대한 상세 해설입니다. 초보자분의 눈높이에 맞춰 하나씩 알기 쉽게 풀어드릴게요!

---

### 1. 📌 함수 개요
`train_test_split`은 머신러닝 모델을 학습시키기 위해 **전체 데이터를 '학습용(Train)'과 '테스트용(Test)'으로 무작위로 나누어 주는 함수**입니다. 
마치 학생이 시험을 보기 전에 **교과서(학습용 데이터)**로 공부를 하고, 실력 테스트를 위해 **모의고사(테스트용 데이터)**를 따로 남겨두는 것과 같은 원리입니다.

---

### 2. 🔍 입력 인자(매개변수) 분석

코비드에 사용된 5가지 인자가 각각 어떤 일을 하는지 살펴볼까요?

*   **`X`**: **문제(특징, Feature)** 데이터입니다. 집 예측이라면 방 개수, 위치, 평수 등의 정보가 들어있는 테이블(또는 배열)입니다.
*   **`y`**: **정답(레이블, Label)** 데이터입니다. 집 예측이라면 실제 '집 가격'이 들어있는 1차원 배열입니다.
*   **`test_size=0.2`**: **테스트용 데이터의 비율**을 전체의 20%(0.2)로 지정한다는 뜻입니다. 자연스럽게 나머지 80%는 학습용 데이터로 사용됩니다. (보통 0.2나 0.25를 많이 씁니다.)
*   **`random_state=42`**: 데이터를 섞을 때 **기준이 되는 번호표(시드, Seed)**입니다. 
    *   컴퓨터는 데이터를 무작위로 섞을 때 저마다 다르게 섞습니다. 이 숫자를 지정해 주면, 코드를 언제 다시 실행해도 **항상 똑같은 방식으로 데이터가 섞이도록 고정**해 줍니다. (다른 사람과 결과를 똑같이 맞추거나 디버깅할 때 아주 유용합니다. 숫자 42는 관습적으로 자주 쓰이는 행운의 숫자 같은 것입니다.)
*   **`stratify=y`**: **계층적 샘플링(Stratified Sampling)**을 하라는 뜻입니다. 
    *   예를 들어 정답(`y`)에 합격자가 10명, 불합격자가 90명 있다면, 그냥 무작위로 나눴을 때 테스트용에 합격자가 한 명도 안 들어가는 대참사가 발생할 수 있습니다. 
    *   `stratify=y`를 쓰면 **원본 데이터의 정답 비율(합격 10%, 불합격 90%)을 학습용과 테스트용 모두 똑같이 유지**하면서 쪼개 줍니다. 데이터가 불균형할 때 필수적인 옵션입니다.

---

### 3. 📤 반환값 및 변수 할당

함수가 실행되면 총 4개의 덩어리로 데이터를 쪼개어 반환하며, 이를 파이썬의 **언패킹(Unpacking)** 기능을 통해 4개의 변수에 착착 나누어 담게 됩니다.

*   **`X_train`**: **학습용 문제지** (전체 문제 `X`의 80%)
    *   모델이 공부할 때 사용하는 입력 데이터입니다.
*   **`X_test`**: **테스트용 문제지** (전체 문제 `X`의 20%)
    *   모델이 공부를 다 마친 후, 실력 검증을 위해 풀게 될 숨겨진 문제 데이터입니다.
*   **`y_train`**: **학습용 정답지** (전체 정답 `y`의 80%)
    *   `X_train`에 대응하는 진짜 정답들입니다. 모델이 "이 문제의 답은 이거야!" 하고 공부할 때 쓰입니다.
*   **`y_test`**: **테스트용 정답지** (전체 정답 `y`의 20%)
    *   `X_test`에 대응하는 진짜 정답들입니다. 모델이 시험을 본 뒤, 채점관이 채점할 때 몰래(?) 사용하는 정답지입니다.

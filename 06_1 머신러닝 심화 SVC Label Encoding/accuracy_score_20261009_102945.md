# accuracy_score - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 10:29:45

---

파이썬으로 머신러닝 모델을 만들 때 가장 자주 쓰이는 평가 지표 중 하나인 `accuracy_score` 함수에 대해 초보자의 눈높이에 맞춰 쉽고 명쾌하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`accuracy_score`는 머신러닝 모델이 예측한 결과가 **실제 정답과 얼마나 일치하는지(정확도)**를 계산해 주는 함수입니다. 
전체 예측 데이터 중 모델이 **정답을 맞힌 비율**을 0.0(0%)부터 1.0(100%) 사이의 소수로 알려줍니다. (예: 0.85 = 85% 정확도)

* 이 함수를 사용하려면 먼저 라이브러리를 임포트해야 합니다:
  `from sklearn.metrics import accuracy_score`

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `accuracy_score(y_test, y_pred)`에서 사용된 두 개의 인자는 다음과 같습니다.

* **첫 번째 인자: `y_test` (실제 정답)**
  * **역할:** 모델이 맞혀야 하는 **진짜 정답 데이터**입니다.
  * **의미:** 테스트용 데이터셋(`X_test`)에 대응하는 실제 레이블(Label/Target) 값들이 들어있는 리스트나 판다스 시리즈(Series)/넘파이 배열(Array)입니다.

* **두 번째 인자: `y_pred` (모델의 예측값)**
  * **역할:** 훈련된 머신러닝 모델이 `y_test`를보고 **'이럴 것이다'라고 예측한 값**입니다.
  * **의미:** 모델(`model.predict(X_test)`)이 뱉어낸 결과물들이 담긴 데이터입니다.

> 💡 **비유하자면:** `y_test`는 시험지의 '정답지'이고, `y_pred`는 학생이 적어낸 '답안지'입니다. `accuracy_score`는 이 둘을 채점하여 점수를 매기는 선생님 역할을 합니다!

---

### 3. 📤 반환값/할당 변수
* **반환되는 값:** 0과 1 사이의 **실수(Float) 형태의 정확도 점수**가 반환됩니다.
  * 예시: `0.925` (이는 모델이 100문제 중 92.5문제를 맞혔다는 뜻입니다.)
* **할당받는 변수 (`accuracy`):** 
  * 함수가 계산해 준 위 정확도 숫자를 그대로 받아 저장하는 그릇(변수명)입니다. 나중에 `print(accuracy)`를 통해 화면에 점수를 출력할 때 사용됩니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분이 직접 복사해서 실행해 볼 수 있는 가장 간단한 전체 코드 예시입니다.

```python
from sklearn.metrics import accuracy_score

# 1. 실제 정답 (시험지)
y_test = [0, 1, 1, 0, 1]

# 2. 모델이 예측한 값 (학생의 답안지)
# (5개 중 4개를 맞힌 상황: 0번째만 틀림)
y_pred = [1, 1, 1, 0, 1] 

# 3. accuracy_score 함수 호출 및 결과 저장
accuracy = accuracy_score(y_test, y_pred)

# 4. 결과 출력
print(f"모델의 정확도: {accuracy}")
```

**[예상 결과]**
```text
모델의 정확도: 0.8
```
* **해설:** 5문제 중 4개를 맞혔으므로 $4 / 5 = 0.8$ (즉, 80%의 정확도)이 출력됩니다!

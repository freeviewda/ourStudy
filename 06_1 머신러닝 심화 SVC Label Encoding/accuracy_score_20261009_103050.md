# accuracy_score - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 10:30:50

---

파이썬 머신러닝에서 가장 많이 쓰이는 평가 지표 중 하나인 `accuracy_score` 함수에 대해 초보자의 눈높이에 맞춰 쉽고 명쾌하게 설명해 드리겠습니다.

---

### 1. 📌 함수 개요
`accuracy_score`는 머신러닝 모델이 예측한 결과가 실제 정답과 얼마나 일치하는지, 즉 **정확도(Accuracy)**를 계산해 주는 함수입니다. 
전체 예측 데이터 중에서 모델이 맞춘 데이터의 비율(0.0 ~ 1.0 사이의 값, 또는 0% ~ 100%)을 구해줍니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `accuracy_score(y_test, y_pred_linear)`에서 사용된 두 개의 인자는 다음과 같습니다.

*   **첫 번째 인자: `y_test` (실제 정답)**
    *   **역할:** 테스트 데이터셋에 해당하는 **실제 진짜 정답 값**들의 모음입니다.
    *   **의미:** 모델이 평가받을 때 기준이 되는 '절대적인 정답지'라고 생각하시면 됩니다. (예: `[0, 1, 1, 0, 1]` 등)
*   **두 번째 인자: `y_pred_linear` (모델의 예측값)**
    *   **역할:** 선형 모델(Linear Model)이 문제를 풀고 **예측해 낸 결과 값**들의 모음입니다.
    *   **의미:** 학생들이 시험을 보고 적어낸 '답안지'와 같습니다. 이 답안지가 실제 정답(`y_test`)과 얼마나 똑같은지 비교하게 됩니다. (예: `[0, 1, 0, 0, 1]` 등)

---

### 3. 📤 반환값/할당 변수
*   **할당 변수: `accuracy_linear`**
    *   **데이터 종류:** `float` (실수형 숫자)
    *   **설명:** 함수가 계산을 끝낸 후 돌려주는 **정확도 점수**가 이 변수에 저장됩니다. 
    *   예를 들어, 값이 `0.85`로 나왔다면 모델이 전체 테스트 데이터 중 **85%를 맞췄다**는 뜻입니다. (최소 0.0에서 최대 1.0 사이의 값을 가집니다.)

---

### 4. 🎁 요약 및 실행 예시
이해를 돕기 위해 아주 간단한 코드로 직접 실행해 보겠습니다.

```python
from sklearn.metrics import accuracy_score

# 1. 실제 정답 (y_test)
y_test = [0, 1, 1, 0, 1]

# 2. 모델이 예측한 값 (y_pred_linear)
# (5개 중 4개를 맞추고, 3번째 값 1을 0으로 틀렸다고 가정)
y_pred_linear = [0, 1, 0, 0, 1] 

# 3. 정확도 계산 함수 호출
accuracy_linear = accuracy_score(y_test, y_pred_linear)

# 4. 결과 출력
print(f"모델의 정확도: {accuracy_linear}")
```

**[예상 결과]**
```text
모델의 정확도: 0.8
```
* **해설:** 5개의 문제 중 4개를 맞췄으므로, $4 / 5 = 0.8$ (즉, 80%의 정확도)이라는 결과가 `accuracy_linear` 변수에 담겨 출력됩니다!

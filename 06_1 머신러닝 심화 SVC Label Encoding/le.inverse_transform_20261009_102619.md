# le.inverse_transform - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 10:26:19

---

파이썬 머신러닝에서 자주 쓰이는 `le.inverse_transform([0, 1])` 코드에 대해 초보자 눈높이에 맞춰 아주 쉽고 친절하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`le.inverse_transform`은 **숫자로 바뀌어 있던 데이터를 원래의 문자열(카테고리) 값으로 되돌려주는(역변환하는) 함수**입니다. 
여기서 `le`는 보통 사이킷런(Scikit-Learn)의 `LabelEncoder` 객체를 의미하며, 컴퓨터가 이해할 수 있도록 0, 1, 2 등의 숫자로 바꾼 라벨을 다시 사람이 읽기 편한 원래 단어로 복원할 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
코드 안에서 함수에 전달된 인자는 `[0, 1]`입니다.

* **전달된 값:** `[0, 1]` (파이썬의 리스트 형태)
* **역할과 의미:** 
  * 모델(또는 이전 단계의 `LabelEncoder`)이 **"0번으로 기억하고 있던 원래 단어"**와 **"1번으로 기억하고 있던 원래 단어"**가 무엇이었는지 물어보는 것입니다.
  * 예를 들어, 과거에 '사과'를 `0`, '바나나'를 `1`로 변환해 두었다면, 이 함수는 `[0, 1]`을 입력받아 각각이 무엇이었는지 찾을 준비를 합니다.

---

### 3. 📤 반환값/할당 변수
이 코드는 별도의 변수에 값을 저장(할당)하지 않고, 바로 `print()` 함수 안에 쓰였습니다.

* **반환되는 데이터:** 원래 데이터의 형태(보통 NumPy 배열 형태)로 복원된 **문자열(또는 원래의 데이터 타입) 목록**이 반환됩니다.
* **출력 예시:** 만약 0이 'Cat', 1이 'Dog'였다면, 반환값은 `['Cat', 'Dog']`가 되며, `print()`에 의해 화면에는 아래처럼 출력됩니다.
  ```text
  ['Cat', 'Dog']
  ```

---

### 4. 🎁 요약 및 실행 예시
백문이 불여일견! 직접 코드를 실행해 보면 한 번에 이해할 수 있습니다. 아래 코드를 복사해서 파이썬 환경에서 실행해 보세요.

```python
from sklearn.preprocessing import LabelEncoder

# 1. LabelEncoder 객체 생성
le = LabelEncoder()

# 2. 문자열 데이터를 준비하고 숫자로 변환 (학습 시키기)
original_animals = ['고양이', '강아지', '고양이', '토끼']
le.fit(original_animals)

# (참고) 0, 1, 2가 각각 어떤 동물인지 확인
# 고양이=0, 강아지=1, 토끼=2 로 학습되었다고 가정해봅시다.

# 3. 오늘의 핵심 코드: 숫자를 다시 원래 문자열로 되돌리기!
predicted_numbers = [1, 0]  # 모델이 1과 0을 예측했다고 가정
original_names = le.inverse_transform(predicted_numbers)

print("변환된 원래 값:", original_names)
```

**💡 실행 결과:**
```text
변환된 원래 값: ['강아지' '고양이']
```
*(설명: 숫자 `1`은 '강아지'로, 숫자 `0`은 '고양이'로 완벽하게 되돌려진 것을 확인할 수 있습니다!)*

# plt.ylabel - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 17:44:53

---

파이썬 데이터 시각화 라이브러리인 맷플롯립(Matplotlib)에서 사용되는 `plt.ylabel('True Label')` 코드에 대한 상세 해설입니다.

---

### 1. 📌 함수 개요
`plt.ylabel()`은 **그림(Graph)의 Y축에 제목(이름)을 달아주는 함수**입니다. 그래프를 보는 사람이 Y축이 무엇을 나타내는지 명확하게 이해할 수 있도록 설명 글귀를 추가할 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제공해주신 코드 안에서 사용된 인자의 역할과 의미는 다음과 같습니다.

*   **`'True Label'` (문자열, String)**
    *   **역할:** Y축에 표시될 텍스트 내용입니다.
    *   **의미:** 머신러닝이나 통계 분석에서 이 모델이 맞추어야 하는 '실제 정답(True Label)' 데이터를 Y축의 지표로 사용하고 있음을 시각적으로 알려줍니다. (주로 분류 모델의 성능을 평가하는 혼동 행렬(Confusion Matrix) 등을 시각화할 때 자주 쓰입니다.)

---

### 3. 📤 반환값/할당 변수
*   **반환값:** 이 함수는 내부적으로 텍스트 객체(Text object)를 반환하지만, 보통은 별도의 변수에 할당하지 않고 그대로 실행하여 화면에 Y축 이름을 띄우는 용도로만 사용합니다.
*   **할당 변수:** 현재 코드에는 변수에 값을 담는(언패킹 등) 과정이 없습니다. 따라서 반환값은 화면에 시각적으로 반영된 후 조용히 사라집니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 복잡한 설정 없이 파이썬에서 바로 실행해 볼 수 있는 가장 간단한 예시 코드입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 간단한 데이터 준비
x = [1, 2, 3, 4]
y = [10, 20, 25, 30]

# 그래프 그리기
plt.plot(x, y)

# X축과 Y축에 이름표(Label) 달기
plt.xlabel('X Axis (Index)')
plt.ylabel('True Label')  # <-- 오늘의 핵심 함수!

# 그래프 화면에 보여주기
plt.show()
```

**[예상 결과]**
새로운 창(또는 주피터 노트북 화면)에 꺾은선 그래프가 나타나며, **왼쪽 세로축(Y축) 정중앙에 'True Label'이라는 글자가 예쁘게 적혀 있는 것**을 확인할 수 있습니다.

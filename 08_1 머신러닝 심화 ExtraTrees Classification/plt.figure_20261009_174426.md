파이썬 데이터 시각화의 대표 라이브러리인 **Matplotlib**에서 사용되는 `plt.figure` 함수에 대한 상세 해설입니다. 초보자분들이 쉽게 이해할 수 있도록 항목별로 친절하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`plt.figure()`는 새로운 도화지(캔버스)를 생성하는 함수입니다. 파이썬에서 그림을 그리기 전에 "여기에 새로운 그림을 그릴 거야!" 하고 작업 공간을 펴주는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
작성해주신 코드 `plt.figure(figsize=(4, 3))`에 사용된 인자의 역할은 다음과 같습니다.

*   **`figsize` (도화지 크기 설정)**
    *   **설정값:** `(4, 3)`
    *   **의미:** 생성할 도화지의 가로, 세로 크기를 인치(inch) 단위로 지정합니다. 
    *   앞의 `4`는 **가로 길이(4인치)**, 뒤의 `3`은 **세로 길이(3인치)**를 의미하며, 아담하고 비율 좋은 직사각형 모양의 그래프를 만들 때 주로 사용합니다.

---

### 3. 📤 반환값/할당 변수
현재 코드에는 변수에 결과를 담지 않고 `plt.figure(figsize=(4, 3))` 형태로 단독 사용되었습니다. 

*   이 경우, Matplotlib의 **현재 작업 공간(Current Figure)**으로 이 도화지가 지정되어 이후에 작성하는 그래프 명령(`plt.plot()`, `plt.scatter()` 등)이 모두 이 4x3 크기의 도화지 위에 그려지게 됩니다.
*   *(참고)* 만약 변수에 할당하고 싶다면 `fig = plt.figure(figsize=(4, 3))`과 같이 써서 도화지 자체를 객체로 제어할 수도 있습니다.

---

### 4. 🎁 요약 및 실행 예시
`plt.figure()`를 포함하여 초보자도 바로 실행해 볼 수 있는 가장 간단한 그래프 그리기 코드입니다.

**💻 파이썬 코드 예시:**
```python
import matplotlib.pyplot as plt

# 1. 4x3 크기의 새로운 도화지(캔버스) 생성
plt.figure(figsize=(4, 3))

# 2. 데이터 준비 및 그래프 그리기
x = [1, 2, 3, 4]
y = [10, 20, 25, 30]
plt.plot(x, y, marker='o') # 꺾은선 그래프 그리기

# 3. 제목 추가 및 화면에 출력
plt.title("My First Graph")
plt.show()
```

**🎯 실행 결과:**
*   가로 4인치, 세로 3인치 아담한 크기의 창(또는 노트북 화면)에 `(1,10)`, `(2,20)`, `(3,25)`, `(4,30)` 점들이 꺾은선으로 연결된 귀여운 그래프가 짠 하고 나타나게 됩니다!

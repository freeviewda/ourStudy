# X.shape - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 09:50:52

---

X.shape는 아주 쉽게 말해서 초콜릿 상자의 '가로 x 세로' 칸수를 확인하는 것과 같아요. 상자를 일일이 다 열어보지 않아도 "아, 이 상자는 3줄씩 4칸으로 되어 있구나!" 하고 상자의 모양과 크기를 한눈에 알 수 있게 해주는 기능이랍니다.

X.shape는 내가 가진 데이터가 몇 행, 몇 열로 이루어져 있는지 그 형태와 전체 크기를 알려주는 역할을 해요. 그래서 새로운 데이터를 처음 받았을 때 전체 양을 파악하거나, 인공지능 모델에 데이터를 넣기 전 모양이 예쁘게 잘 맞는지 확인할 때 가장 기본으로 사용된답니다.

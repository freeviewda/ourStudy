'StratifiedKFold'는 마치 과일 바구니를 똑같이 나누어 담는 현명한 주방장 같은 역할을 해요. 빨간 사과와 파란 사과가 섞인 바구니에서 맛을 골고루 보기 위해, 조각조각 나눌 때마다 각 색깔의 비율이 원본과 똑같이 들어가도록 배려해 주는 착한 도구랍니다. 

주로 머신러닝 모델을 훈련할 때, 전체 데이터 중에서 정답(라벨)의 비율이 한쪽으로 치우치지 않고 골고루 섞여서 공정하게 시험을 치를 수 있도록 데이터를 똑똑하게 쪼개고 싶을 때 사용해요.

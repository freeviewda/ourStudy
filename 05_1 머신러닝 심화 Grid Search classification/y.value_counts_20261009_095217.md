# y.value_counts - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 09:52:17

---

파이썬 머신러닝 코드에서 자주 사용되는 `y.value_counts()` 함수에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 친절하고 명쾌하게 정리해 드릴게요!

---

### 1. 📌 함수 개요
`y.value_counts()`는 판다스(Pandas) 라이브러리의 시리즈(Series) 객체에서 사용되는 함수로, **데이터프레임이나 리스트의 각 항목(클래스)이 각각 몇 번씩 나타났는지(빈도수)를 세어주는 함수**입니다. 머신러닝에서 데이터가 특정 클래스로 편중되어 있지는 않은지(데이터 불균형) 확인할 때 주로 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `y.value_counts()`를 보면, 괄호 안에 **아무런 인자(Argument)도 전달되지 않았습니다.** 

이렇게 괄호를 비워둘 경우, 함수는 기본값(Default)을 사용하여 다음과 같이 동작합니다.
* **기본 동작 방식:** 데이터에 등장하는 모든 고유한 값들의 개수를 센 후, **가장 많이 등장하는 값(내림차순)부터 차례대로 정렬**하여 보여줍니다.
* *(참고)* 만약 빈도수가 높은 순서가 아니라 데이터가 나타난 순서대로 보고 싶다면 `y.value_counts(sort=False)`처럼 옵션을 줄 수 있지만, 기본값은 `sort=True`입니다.

---

### 3. 📤 반환값/할당 변수
이 코드는 별도의 변수에 값을 저장하지 않고, `print()` 함수 내부에서 바로 문자열로 변환되어 출력됩니다.

* **반환되는 데이터 형태:** 판다스 **시리즈(Series)** 객체입니다.
* **구조:** 
  * **인덱스(Index):** 데이터 `y`에 들어있던 고유한 값들 (예: 머신러닝의 0, 1 또는 '합격', '불합격')
  * **값(Values):** 각 고유한 값이 데이터 내에서 몇 번 등장했는지 세어 숫자로 반환
* **출력 예시:**
  ```text
  클래스 분포:
  0    70
  1    30
  Name: count, dtype: int64
  ```
  *(해석: 0이라는 데이터가 70개, 1이라는 데이터가 30개 존재한다는 뜻)*

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 파이썬 환경에서 실행해 볼 수 있는 간단한 예제 코드입니다.

**[실습 코드]**
```python
import pandas as pd

# 1. 정답 데이터(y) 역할을 하는 판다스 시리즈 생성
# (예: 0은 고양이, 1은 강아지, 2는 새)
y = pd.Series([0, 1, 0, 2, 1, 0, 0, 1])

# 2. value_counts() 함수 사용해보기
print(f"클래스 분포:\n{y.value_counts()}")
```

**[예상 결과]**
```text
클래스 분포:
0    4
1    3
2    1
Name: count, dtype: int64
```
* **결과 해석:** 데이터 `y` 안에서 `0`은 총 4번, `1`은 3번, `2`는 1번 나타났음을 한눈에 파악할 수 있습니다!

# 🤖 AI 파이썬 학습 노트: scaler.transform

- **기록 일시**: 2026-09-22 14:58:25
- **대상 코드/함수**: `scaler.transform`

---

파이썬 머신러닝 코드에서 자주 사용되는 `scaler.transform(X_test)`에 대해 초보자의 눈높이에 맞춰 쉽고 명쾌하게 해설해 드리겠습니다.

---

### 1. 📌 함수 개요
`scaler.transform()`은 이미 학습된 기준(평균, 분산 등)을 바탕으로 **새로운 데이터의 범위를 일치시키는(스케일링) 변환 함수**입니다. 
주로 머신러닝 모델에 테스트 데이터를 넣기 전, 학습 데이터와 똑같은 기준으로 데이터의 단위를 맞추어 모델이 편향되지 않고 올바르게 예측할 수 있도록 돕는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
이 코드에서 괄호 안에는 하나의 인자가 전달되었습니다.

*   **`X_test` (테스트 데이터 셋)**
    *   **역할:** 모델을 최종 평가하기 위해 남겨둔 **테스트용 독립 변수(특성) 데이터**입니다. (예: 집값 예측이라면 평수, 방 개수 등이 담긴 표 형태의 데이터)
    *   **설정된 값의 의미:** 모델 학습 과정에서는 전혀 사용되지 않은, 완전히 새로운 데이터입니다. 이 데이터를 `scaler`에 넣어 학습 데이터(`X_train`)와 **동일한 기준(예: 평균 0, 분산 1)**으로 크기를 조정하게 됩니다.

> 💡 **초보자를 위한 핵심 꿀팁 (`fit_transform`과의 차이):**
> *   훈련 데이터에는 `fit_transform()`을 써서 '기준을 만들고 변환'하지만,
> *   테스트 데이터에는 절대 새로운 기준을 만들면 안 되므로 **오직 `transform()`만 사용**해야 합니다. 테스트 데이터의 기준으로 스케일링을 하면 데이터 누수(Data Leakage)가 발생하여 모델의 성능 평가가 부정확해집니다.

---

### 3. 📤 반환값/할당 변수
함수가 실행된 후 결과가 저장되는 변수에 대한 설명입니다.

*   **`X_test_scaled` (스케일링이 완료된 테스트 데이터)**
    *   **설명:** 기존 `X_test`의 데이터 값들이 머신러닝 알고리즘이 학습한 기준에 맞춰 **비율이나 범위가 재조정(변환)된 새로운 데이터**입니다.
    *   **형태:** 원본 `X_test`와 똑같은 행(Row)과 열(Column) 개수를 가지지만, 값들의 숫자 크기(단위)만 일치되어 있습니다. 
    *   **활용:** 이제 이 변수(`X_test_scaled`)를 이미 학습된 머신러닝 모델(`model.predict()`)에 넣어 최종 예측 성능을 평가하게 됩니다.

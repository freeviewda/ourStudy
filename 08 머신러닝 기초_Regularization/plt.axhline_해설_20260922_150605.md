# 🤖 AI 파이썬 학습 노트: plt.axhline

- **기록 일시**: 2026-09-22 15:06:05
- **대상 코드/함수**: `plt.axhline`

---

파이썬의 데이터 시각화 라이브러리인 **Matplotlib**에서 사용되는 `plt.axhline` 함수에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 알기 쉽게 정리해 드립니다!

---

### 1. 📌 함수 개요
`plt.axhline`은 그래프 화면의 **가로 방향으로 직선(Horizontal Line)을 그려주는 함수**입니다. 데이터 분석 시 기준선(예: 0점, 평균값, 임계값 등)을 시각적으로 강조하여 데이터의 흐름을 한눈에 파악할 수 있도록 돕는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `plt.axhline(0, color='black', linestyle='--', linewidth=0.8)`에 사용된 4가지 인자의 역할과 의미는 다음과 같습니다.

*   **`0` (첫 번째 위치 인자)**
    *   **역할:** 가로선을 **어느 Y축 위치에 그릴 것인지** 지정합니다.
    *   **의미:** 이 코드에서는 `0`을 전달했으므로, **Y축의 '0'을 지나가는 수평선**을 그리라는 뜻입니다. (주로 양수와 음수를 구분하는 기준선으로 자주 쓰입니다.)

*   **`color='black'`**
    *   **역할:** 선의 **색상(Color)**을 지정합니다.
    *   **의미:** 선의 색상을 **검은색(black)**으로 설정했습니다.

*   **`linestyle='--'`**
    *   **역할:** 선의 **모양/스타일(Line Style)**을 지정합니다.
    *   **의미:** `'--'`는 **점선(Dashed line)**을 의미합니다. 실선(`'-'`) 대신 눈에 덜 띄면서도 구분하기 좋은 점선으로 선을 그립니다.

*   **`linewidth=0.8`**
    *   **역할:** 선의 **두께(Line Width)**를 지정합니다.
    *   **의미:** 기본 두께보다 조금 얇은 **0.8 두께**로 설정하여, 그래프의 본래 데이터가 선 때문에 가려지지 않도록 은은하게 표현했습니다.

---

### 3. 📤 반환값/할당 변수
*   **해당 없음 (반환값을 변수에 저장하지 않음)**
    *   `plt.axhline` 함수는 주로 선을 그래프 위에 '그리는' 시각적 부수 효과(Side Effect)를 위해 사용됩니다. 
    *   별도의 데이터를 반환하여 변수에 담아두기보다는, 호출되는 순간 현재 활성화된 Matplotlib 그래프(Axes) 위에 곧바로 가로선을 렌더링합니다.

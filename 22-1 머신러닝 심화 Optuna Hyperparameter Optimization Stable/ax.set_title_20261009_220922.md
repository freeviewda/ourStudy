# ax.set_title - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 22:09:22

---

파이썬 데이터 시각화 라이브러리인 맷플롯립(Matplotlib)에서 사용되는 `ax.set_title` 코드에 대한 상세한 해설입니다. 초보자의 눈높이에 맞춰 하나씩 친절하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`ax.set_title`은 **그래프의 상단 중앙에 제목(Title)을 달아주는 함수**입니다. 어떤 데이터를 보여주는 그래프인지 보는 사람이 직관적으로 알 수 있도록 이름을 붙여줄 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드에는 총 3개의 인자가 전달되었습니다. 각각 어떤 역할을 하는지 살펴볼까요?

*   **`'CatBoost - Top 5 파라미터'` (첫 번째 위치 인자, 문자열)**
    *   **역할:** 그래프에 표시할 **실제 제목 텍스트**입니다.
    *   **의미:** 이 그래프가 "CatBoost 모델의 상위 5개 파라미터(매개변수)"를 나타내고 있음을 설명해 줍니다.
*   **`fontweight='bold'` (키워드 인자)**
    *   **역할:** 폰트의 **두께(weight)**를 설정합니다.
    *   **의미:** `'bold'`는 **굵게**를 의미하므로, 제목 글씨를 진하게 만들어 시인성을 높여줍니다.
*   **`fontsize=12` (키워드 인자)**
    *   **역할:** 폰트의 **크기(size)**를 설정합니다.
    *   **의미:** 글자 크기를 `12` 포인트로 지정하여, 그래프 전체 크기에 어울리도록 적당한 크기로 제목을 출력합니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값:** 이 함수는 내부적으로 제목 텍스트를 그린 객체(`matplotlib.text.Text`)를 반환합니다.
*   **할당 변수:** 제시해주신 코드에서는 `=` 기호로 변수에 값을 할당하는 부분이 없습니다. 즉, 반환된 객체를 따로 저장하지 않고 **"제목을 화면에 그려라"라는 명령만 수행**하고 끝난 형태입니다. (보통 제목을 그린 후 추가 수정할 일이 없다면 이렇게 변수 없이 바로 호출합니다.)

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 주피터 노트북이나 파이썬 파일에서 직접 실행해 볼 수 있는 가장 간단한 그래프 예시 코드입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 도화지(Figure)와 축(Axes) 객체 만들기
fig, ax = plt.subplots()

# 2. 간단한 선 그래프 그리기
ax.plot([1, 2, 3], [10, 20, 25])

# 3. 질문하신 함수 사용하기!
ax.set_title("CatBoost - Top 5 파라미터", fontweight="bold", fontsize=12)

# 4. 화면에 보여주기
plt.show()
```

**[예상 결과]**
*   화면에 간단한 꺾은선 그래프가 나타납니다.
*   그래프 맨 위 중앙에 **"CatBoost - Top 5 파라미터"** 라는 문구가 **굵은 글씨(bold)**와 **적당히 큰 크기(12)**로 깔끔하게 적혀 있는 것을 확인할 수 있습니다.

파이썬의 데이터 시각화 라이브러리인 **Matplotlib**에서 가장 많이 쓰이는 핵심 함수 중 하나인 `plt.subplots()`에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 친절하고 명쾌하게 정리해 드릴게요!

---

### 1. 📌 함수 개요
`plt.subplots()`는 **한 번에 여러 개의 그래프(서브플롯)를 그릴 수 있는 도화지(Figure)와 그 도화지 위 구역(Axes)들을 동시에 만들어주는 함수**입니다. 
데이터를 비교하거나 여러 관점을 한 화면에 보여주고 싶을 때 아주 유용하게 쓰입니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
작성해주신 코드 `plt.subplots(1, 3, figsize=(18, 6))`에 들어간 3가지 인자의 역할은 다음과 같습니다.

*   **첫 번째 인자 (`1`) : 행(Row)의 개수**
    *   생성할 그래프 구역을 **세로로 몇 줄**로 나눌지 정합니다. 여기서는 `1`이므로 그래프들이 위아래로 나뉘지 않고 한 줄로 배치됩니다.
*   **두 번째 인자 (`3`) : 열(Column)의 개수**
    *   생성할 그래프 구역을 **가로로 몇 칸**으로 나눌지 정합니다. 여기서는 `3`이므로 가로로 나란히 3개의 그래프 칸이 만들어집니다.
    *   *(결과적으로 `1행 3열`, 즉 나란히 옆으로 3개의 그래프가 들어갈 자리가 생깁니다.)*
*   **`figsize=(18, 6)` : 전체 도화지의 크기 (Figure Size)**
    *   만들어질 전체 그림의 가로, 세로 크기를 인치(inch) 단위로 설정합니다.
    *   `18`은 가로 길이, `6`은 세로 길이를 의미합니다. 그래프가 3개로 나란히 배치되기 때문에 가로를 넓게(18) 설정한 것입니다.

---

### 3. 📤 반환값/할당 변수
이 함수는 하나의 큰 묶음(튜플)으로 **두 가지 서로 다른 객체를 반환**합니다. 이를 파이썬의 **언패킹(Unpacking)** 기능을 이용해 `fig`와 `axes`라는 두 변수에 나누어 담는 것입니다.

*   **`fig` (Figure, 도화지)**
    *   그래프가 그려지는 **전체 도화지(캔버스)** 그 자체를 의미합니다.
    *   전체 제목(Title)을 넣거나, 그림의 전체 크기를 조절하거나, 그림을 파일로 저장(`fig.savefig()`)할 때 사용합니다.
*   **`axes` (Axes, 개별 그래프 구역)**
    *   도화지 위에 나누어진 **각각의 그래프 공간(알맹이)**들을 담고 있는 묶음(배열)입니다.
    *   위 코드에서는 3개의 칸을 만들었으므로 `axes`는 `[축1, 축2, 축3]` 형태의 리스트처럼 작동합니다. 
    *   `axes[0]`은 첫 번째 그래프, `axes[1]`은 두 번째 그래프, `axes[2]`는 세 번째 그래프를 조작(데이터 그리기, 이름 붙이기 등)할 때 사용합니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 복사해서 바로 실행해 볼 수 있는 가장 간단한 전체 코드 예시입니다.

```python
import matplotlib.pyplot as plt

# 1. 1행 3열의 도화지와 구역 만들기
fig, axes = plt.subplots(1, 3, figsize=(18, 6))

# 2. 각각의 구역(axes)에 데이터 그려보기
axes[0].plot([1, 2, 3], [1, 4, 9])  # 첫 번째 그래프: 선 그래프
axes[0].set_title("First Graph")

axes[1].bar(["A", "B", "C"], [3, 7, 5])  # 두 번째 그래프: 막대 그래프
axes[1].set_title("Second Graph")

axes[2].scatter([1, 2, 3], [3, 2, 1])  # 세 번째 그래프: 산점도
axes[2].set_title("Third Graph")

# 3. 화면에 출력하기
plt.show()
```

**💡 예상 결과:**
가로로 넓고 시원시원한 크기(`18x6`)의 화면에, 왼쪽부터 **선 그래프, 막대 그래프, 점 그래프**가 나란히 3개 그려진 멋진 결과물을 보실 수 있습니다!

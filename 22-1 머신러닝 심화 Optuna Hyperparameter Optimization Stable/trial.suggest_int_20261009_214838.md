### 1. 📌 함수 개요
`trial.suggest_int`는 **머신러닝 모델의 하이퍼파라미터(사람이 직접 설정해야 하는 값) 중 '정수(Integer)' 형태의 최적값을 자동으로 찾아내기 위해 범위를 지정하고 후보를 추천받는 함수**입니다. 
주로 LightGBM이나 XGBoost 같은 트리 기반 모델의 튜닝에서 나무의 잎사귀 개수(`num_leaves`) 등을 설정할 때 널리 사용됩니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `'num_leaves': trial.suggest_int('num_leaves', 20, 100)` 안에는 총 3개의 인자가 전달되고 있습니다. 하나씩 살펴볼까요?

* **첫 번째 인자 (`'num_leaves'`):** 
  * **역할:** 이 탐색(suggestion)에 붙일 **이름(고유 식별자)**입니다.
  * **의미:** Optuna가 기록을 남기거나 어떤 파라미터를 조절 중인지 구분할 때 사용하는 이름입니다. 보통 실제 파라미터 이름과 똑같이 맞추어 줍니다.
* **두 번째 인자 (`20`):** 
  * **역할:** 탐색할 정수 범위의 **최소값(Low)**입니다.
  * **의미:** `num_leaves`가 가질 수 있는 가장 작은 값을 20으로 제한합니다. 즉, 20보다 작은 값은 아예 시도조차 하지 않습니다.
* **세 번째 인자 (`100`):** 
  * **역할:** 탐색할 정수 범위의 **최대값(High)**입니다.
  * **의미:** `num_leaves`가 가질 수 있는 가장 큰 값을 100으로 제한합니다. 

> **💡 종합 의미:** 
> *"Optuna야! 20부터 100 사이의 정수 중에서 모델 성능이 가장 좋아질 것 같은 `num_leaves` 값을 하나 골라다오!"* 라는 뜻입니다.

---

### 3. 📤 반환값/할당 변수
* **반환값:** 지정한 범위(20~100) 안에서 Optuna가 **선택한 하나의 정수 값** (예: 34, 78, 45 등)을 반환합니다.
* **할당되는 곳:** 이 반환값은 딕셔너리의 키(`'num_leaves'`)의 **값(Value)**으로 곧바로 저장됩니다. 
* 결과적으로 반복문(Trial)이 돌 때마다 `num_leaves` 자리에 20~100 사이의 숫자가 무작위 또는 알고리즘에 의해 쏙쏙 들어가게 됩니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 전체 흐름을 이해할 수 있도록 Optuna를 사용하는 아주 간단한 예시 코드를 준비했습니다.

#### 📝 파이썬 실습 코드
```python
import optuna

# 1. 최적화를 수행할 목적 함수(Objective function) 정의
def objective(trial):
    # trial.suggest_int를 사용해 num_leaves 값을 20~100 사이에서 추천받음
    num_leaves = trial.suggest_int('num_leaves', 20, 100)
    
    # (참고) 추천받은 값이 어떻게 나오는지 출력해보기
    print(f"이번에 추천받은 num_leaves 값: {num_leaves}")
    
    # 임의의 성능 점수(Loss) 반환 (실제로는 모델 학습 후 점수가 들어감)
    dummy_score = (num_leaves - 50) ** 2  기본값 50에 가까울수록 점수가 좋다고 가정
    return dummy_score

# 2. Optunastudy 객체를 만들고 최적화 진행 (딱 3번만 실행해보기)
study = optuna.create_study(direction="minimize") # 점수를 최소화하는 방향
study.optimize(objective, n_trials=3)

# 3. 가장 좋은 결과를 낸 파라미터 확인
print("\n✨ 최적화 완료!")
print(f"가장 좋았던 설정: {study.best_params}")
```

파이썬 데이터 시각화 라이브러리인 Matplotlib에서 사용되는 `plt.suptitle` 함수에 대한 상세 해설입니다. 초보자분들도 쉽게 이해하실 수 있도록 항목별로 차근차근 설명해 드릴게요!

---

### 1. 📌 함수 개요
`plt.suptitle()`은 **여러 개의 그래프(Subplots)가 모여 있는 전체 화면(Figure)의 가장 상단에 전체 제목을 달아주는 함수**입니다. 
각각의 작은 그래프마다 제목을 붙이는 `plt.title()`과 달리, 전체 그래프를 아우르는 대제목이 필요할 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드에서 사용된 4개의 인자가 각각 어떤 역할을 하는지 살펴볼까요?

*   **`'XGBoost - 각 Run별 파라미터 Importance 비교'` (위치 인자)**
    *   **역할:** 전체 그래프의 상단에 표시될 **제목의 텍스트**입니다.
    *   **의미:** 이 그래프가 "XGBoost 모델의 여러 번의 실행(Run)별로 파라미터 중요도를 비교하는 것"임을 명확하게 설명해 줍니다.
*   **`fontsize=14`**
    *   **역할:** 글자 크기를 조절합니다.
    *   **의미:** 기본값보다 살짝 크게(14 포인트) 설정하여 전체 제목으로서 눈에 잘 띄도록 만들었습니다.
*   **`fontweight='bold'`**
    *   **역할:** 글자의 굵기를 조절합니다.
    *   **의미:** `'bold'`를 지정하여 글자를 **진하게** 만듦으로써 시각적인 강조 효과를 줍니다.
*   **`y=1.002`**
    *   **역할:** 전체 그림(Figure) 영역을 기준으로 제목의 **세로 위치(Y좌표)**를 미세 조정합니다.
    *   **의미:** 기본 위치보다 아주 살짝 위쪽(`1.002`)으로 밀어올렸습니다. 이렇게 하면 그래프 그림(Plot)과 대제목이 너무 붙어서 겹치는 현상을 방지하고 깔끔한 배치를 만들 수 있습니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값 없음 (None)**
*   이 코드에서는 함수가 실행되면서 별도의 변수(예: `title = plt.suptitle(...)`)에 값을 저장하지 않고 바로 화면에 적용(출력)하도록 사용되었습니다. 
*   내부적으로는 생성된 텍스트 객체(`matplotlib.text.Text`)를 반환하지만, 일반적인 시각화 코드에서는 위와 같이 단독으로 호출하여 화면을 꾸미는 용도로 주로 사용합니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 복사해서 실행해 볼 수 있는 가장 간단한 전체 코드 예시입니다.

```python
import matplotlib.pyplot as plt

# 1. 1행 2열의 서브플롯(전체 도화지) 생성
fig, axes = plt.subplots(1, 2, figsize=(10, 4))

# 2. 각각의 작은 그래프에 내용 채우기 (예시)
axes[0].plot([1, 2, 3], [4, 5, 6])
axes[0].set_title('Run 1')

axes[1].plot([1, 2, 3], [6, 5, 4])
axes[1].set_title('Run 2')

# 3. 전체 도화지의 대제목 달기 (해설한 함수 사용!)
plt.suptitle(
    'XGBoost - 각 Run별 파라미터 Importance 비교',
    fontsize=14,
    fontweight='bold',
    y=1.002,
)

# 4. 화면에 출력하기
plt.show()
```

**💡 예상 결과:**
두 개의 작은 그래프(Run 1, Run 2)가 나란히 그려지고, 그 **도화지 맨 꼭대기 중앙**에 진하고 굵은 14포인트 크기의 **"XGBoost - 각 Run별 파라미터 Importance 비교"** 라는 대제목이 깔끔하게 표시됩니다!

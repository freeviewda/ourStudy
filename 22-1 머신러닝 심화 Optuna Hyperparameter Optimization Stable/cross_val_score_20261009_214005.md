# cross_val_score - AI 파이썬 학습 노트

파이썬 머신러닝 라이브러리인 Scikit-Learn에서 제공하는 `cross_val_score` 함수에 대해 초보자의 눈높이에 맞춰 친절하고 명쾌하게 해설해 드릴게요!

---

### 1. 📌 함수 개요
`cross_val_score`는 머신러닝 모델의 성능을 더욱 객관적이고 신뢰성 있게 평가하기 위해 **'교차 검증(Cross-Validation)'**을 수행해 주는 함수입니다. 데이터를 여러 조각으로 나누어 돌아가면서 학습과 평가를 반복한 뒤, 모델의 평균적인 성능 점수를 계산해 줍니다.

---

### 2. 🔍 입력 인자(매개변수) 분석

코드에 전달된 6가지 인자가 각각 어떤 역할을 하는지 살펴볼까요?

*   **`model`**
    *   **역할:** 평가하고자 하는 머신러닝 모델 객체입니다.
    *   **의미:** (예: `RandomForestClassifier()`, `LogisticRegression()` 등) 우리가 성능을 테스트하고 싶은 알고리즘을 통째로 넣어줍니다.
*   **`X_train`**
    *   **역할:** 모델에 학습시킬 **독립 변수(문제지)** 데이터입니다.
    *   **의미:** 피처(Feature)들의 모음으로, 정답을 맞추기 위해 모델이 참고하는 데이터입니다.
*   **`y_train`**
    *   **역할:** 모델에 학습시킬 **종속 변수(정답)** 데이터입니다.
    *   **의미:** 레이블(Label) 또는 타겟(Target)이라고도 부르며, `X_train`에 대한 실제 정답 값입니다.
*   **`cv=5`**
    *   **역할:** 데이터를 몇 등분으로 쪼개서 검증할지 지정하는 **교차 검증 폴드 수(K-Fold)**입니다.
    *   **의미:** `5`로 설정했으므로, 전체 데이터를 5개의 조각으로 나누어 1개 조각은 테스트용, 나머지 4개 조각은 훈련용으로 사용하는 과정을 총 5번 반복합니다.
*   **`scoring='accuracy'`**
    *   **역할:** 모델의 성능을 평가할 **측정 지표(Metric)**를 지정합니다.
    *   **의미:** 분류(Classification) 문제에서 가장 흔하게 쓰이는 **'정확도(Accuracy)'**를 기준으로 모델의 점수를 매기겠다는 뜻입니다.
*   **`n_jobs=-1`**
    *   **역할:** 컴퓨터의 **CPU 코어**를 몇 개나 사용할지 지정합니다.
    *   **의미:** `-1`로 설정하면 **내 컴퓨터에 있는 모든 CPU 코어**를 동원해서 동시에 계산을 수행하므로, 코드가 훨씬 빠르게 실행됩니다.

---

### 3. 📤 반환값/할당 변수

코드의 실행 결과를 뜯어봅시다.

*   **`.mean()` 의 역할**: 
    *   `cross_val_score(...)`는 기본적으로 5번(cv=5이므로)의 테스트를 거쳐 **5개의 점수(배열, Array)**를 반환합니다. (예: `[0.91, 0.88, 0.93, 0.89, 0.90]`)
    *   여기에 **`.mean()`**을 붙였기 때문에, 이 5개 점수의 **평균값**(예: `0.902`)을 최종적으로 구해서 `cv_score` 변수에 저장하게 됩니다.
*   **`cv_score` 변수**: 
    *   최종적으로 계산된 **교차 검증 평균 정확도 점수**가 실수(Float) 형태로 담기게 됩니다.

---

### 4. 🎁 요약 및 실행 예시

초보자분들이 붓꽃(Iris) 데이터셋을 이용해 직접 실행해 볼 수 있는 간단한 전체 코드를 준비했습니다. 복사해서 바로 실행해 보세요!

```python
from sklearn.datasets import load_iris
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_score

# 1. 데이터 불러오기
iris = load_iris()
X_train, y_train = iris.data, iris.target

# 2. 모델 준비
model = RandomForestClassifier(random_state=42)

# 3. cross_val_score 사용하기
cv_scores = cross_val_score(
    model, X_train, y_train,
    cv=5, scoring='accuracy', n_jobs=-1
)

print("각 5번의 폴드별 정확도:", cv_scores)
print("최종 교차 검증 평균 정확도:", cv_scores.mean())
```

**💡 실행 결과 예시:**
```text
각 5번의 폴드별 정확도: [0.96666667 0.96666667 0.93333333 0.93333333 1.        ]
최종 교차 검증 평균 정확도: 0.96
```
이처럼 `cross_val_score`를 사용하면 **"우리 모델이 특정 데이터셋에만 운좋게 잘 맞는 게 아니라, 어떤 데이터를 넣어도 평균 96%의 정확도를 내는구나!"** 하고 객관적으로 믿을 수 있게 됩니다.

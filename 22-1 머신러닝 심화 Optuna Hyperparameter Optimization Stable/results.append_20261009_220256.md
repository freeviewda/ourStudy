# results.append - AI 파이썬 학습 노트

---

파이썬 코드에서 사용된 `results.append(...)` 부분에 대해 초보자분들도 쉽고 명쾌하게 이해하실 수 있도록 항목별로 차근차근 설명해 드릴게요!

---

### 1. 📌 함수 개요
`results.append()`는 **파이썬의 기본 리스트(List)에 새로운 데이터를 추가할 때 사용하는 함수**입니다. 
여기서는 머신러닝(XGBoost) 모델을 학습시킨 후, 그 모델의 성능 평가 결과들을 하나의 묶음(딕셔너리)으로 만들어 `results`라는 이름의 리스트에 차곡차곡 쌓아두기 위해 사용되었습니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
`append()` 괄호 안에는 추가할 데이터를 담은 **딕셔너리(Dictionary, `{}` 형태)**가 통째로 하나의 인자로 전달되었습니다. 딕셔너리는 `'이름': 값`의 쌍으로 이루어져 있습니다. 전달된 5개의 데이터가 각각 무엇을 의미하는지 자세히 볼까요?

*   **`'Model': 'XGBoost'`**
    *   **역할:** 어떤 머신러닝 모델을 사용했는지 기록합니다.
    *   **의미:** 이 결과가 'XGBoost'라는 알고리즘에서 나온 것임을 나타냅니다.
*   **`'Best Run': best_xgb_idx + 1`**
    *   **역할:** 하이퍼파라미터 튜닝(최적의 설정값을 찾는 과정)을 여러 번 시도했을 때, 가장 성능이 좋았던 '몇 번째 시도(Run)'였는지를 기록합니다.
    *   **의미:** 파이썬은 숫자를 0부터 세기 때문에(인덱스), 사람 보기 편하게 `+ 1`을 더해 "첫 번째, 두 번째..." 형태의 순번으로 변환해 저장했습니다.
*   **`'CV Score': best_xgb_study.best_value`**
    *   **역할:** 교차 검증(Cross-Validation) 과정에서 얻은 가장 높은 성능 점수를 기록합니다.
    *   **의미:** 모델을 학습할 때 내부적으로 평가했던 최고 점수입니다. (보통 Optuna 같은 라이브러리의 최적화 결과에서 가져옵니다.)
*   **`'Test Accuracy': accuracy_score(y_test, y_pred)`**
    *   **역할:** 한 번도 본 적 없는 테스트 데이터(`y_test`)를 가지고 모델이 예측한 값(`y_pred`)이 얼마나 맞았는지를 계산(정확도)하여 기록합니다.
    *   **의미:** 전체 데이터 중 모델이 정답을 맞춘 비율을 나타냅니다. (예: 0.95 = 95% 정답)
*   **`'Test F1': f1_score(y_test, y_pred, average='weighted')`**
    *   **역할:** 테스트 데이터에 대한 F1 점수(정밀도와 재현율의 조화 평균)를 기록합니다.
    *   **의미:** 데이터의 정답 클래스 비율이 불균형할 때 모델의 성능을 더 정확히 평가하기 위해 사용합니다. `average='weighted'`는 각 클래스의 데이터 양에 가중치를 주어 평균을 낸 것입니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값:** `append()` 함수 자체는 리스트에 요소를 추가하기만 하고, 별도의 특별한 값을 반환하지 않고 **`None`을 반환**합니다.
*   **어디에 저장되나요?:** 이 코드가 실행되면 리스트 자체(`results`)가 업데이트됩니다. 즉, 기존 `results` 리스트의 맨 마지막 자리에 방금 만든 딕셔너리 데이터가 쏙 들어가 추가됩니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 개념을 확실히 잡으실 수 있도록, 아주 간단한 미니 코드로 `append`의 동작을 시연해 드릴게요!

**[간단한 실행 예시 코드]**
```python
# 1. 결과를 담을 빈 리스트를 준비합니다.
results = []

# 가상의 모델 평가 결과 데이터라고 가정합시다.
model_name = 'XGBoost'
accuracy = 0.92

# 2. results.append()를 사용해 딕셔너리 형태의 데이터를 리스트에 추가합니다.
results.append({
    'Model': model_name,
    'Test Accuracy': accuracy
})

# 3. 결과가 잘 들어갔는지 확인해봅니다.
print(results)
```

**[예상 출력 결과]**
```text
[{'Model': 'XGBoost', 'Test Accuracy': 0.92}]
```

> **💡 한 줄 요약:** 
> `results.append({ ... })`는 **"내가 실험한 모델의 이름, 시도 횟수, 각종 점수들을 예쁘게 포장(딕셔너리)해서, 전체 결과 모음집(리스트)에 한 줄 추가해 줘!"**라는 뜻입니다. 나중에 여러 모델(XGBoost, Random Forest 등)의 결과를 한눈에 비교할 때 매우 유용하게 쓰입니다.

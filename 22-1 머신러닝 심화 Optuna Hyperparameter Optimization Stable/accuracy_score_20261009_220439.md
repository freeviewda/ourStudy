---

### 1. 📌 함수 개요
`accuracy_score`는 머신러닝 모델이 예측한 결과가 **실제 정답과 얼마나 일치하는지(정확도)**를 계산해 주는 함수입니다. 전체 예측 데이터 중에서 모델이 **정답을 맞힌 비율**을 0.0부터 1.0 사이의 소수(또는 0% ~ 100%)로 반환합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `'Test Accuracy': accuracy_score(y_test, y_pred)`에서 사용된 두 개의 인자를 차근차근 살펴보겠습니다.

*   **첫 번째 인자: `y_test` (실제 정답)**
    *   **역할:** 테스트 데이터의 **실제 진짜 정답(True Labels)** 값들이 담긴 리스트나 배열입니다.
    *   **의미:** 모델이 맞혀야 하는 '채점 기준표' 역할을 합니다.
*   **두 번째 인자: `y_pred` (모델의 예측값)**
    *   **역할:** 머신러닝 모델이 테스트 데이터를 보고 **예측한 결과(Predicted Labels)** 값들이 담긴 리스트나 배열입니다.
    *   **의미:** 학생들이 시험을 보고 적어낸 '답안지' 역할을 합니다.

> 💡 **비유하자면:** `y_test`는 시험의 '실제 정답지', `y_pred`는 학생이 적어낸 '제출 답안지'입니다. `accuracy_score`는 이 둘을 나란히 놓고 **"몇 개나 맞았는지"** 채점해 주는 채점관인 셈입니다.

---

### 3. 📤 반환값/할당 변수
이 함수는 채점이 끝난 결과를 하나의 **숫자(float 타입)**로 돌려줍니다.

*   **반환값의 형태:** `0.0` ~ `1.0` 사이의 실수
    *   예를 들어 결과로 `0.85`가 나왔다면, 전체 테스트 데이터 100개 중 85개를 맞췄다는 뜻이며 **정확도는 85%**가 됩니다.
*   **할당 코드 (`'Test Accuracy': ...`)의 의미:**
    *   이 코드는 파이썬의 **딕셔너리(Dictionary)** 구조 안에서 사용되고 있습니다. 
    *   `'Test Accuracy'`라는 이름(Key)표 아래에, `accuracy_score`가 계산해 낸 정확도 숫자(Value)를 저장하겠다는 뜻입니다.

---

### 4. 🎁 요약 및 실행 예시
백문이 불여일견! 실제로 코드를 돌려보며 어떻게 작동하는지 확인해 볼까요?

#### 💻 실습 코드
```python
from sklearn.metrics import accuracy_score

# 1. 실제 정답 (강아지=1, 고양이=0 이라고 가정)
y_test = [1, 0, 1, 1, 0]

# 2. 모델이 예측한 값
y_pred = [1, 0, 0, 1, 0]

# 3. 정확도 계산하기
score = accuracy_score(y_test, y_pred)

print(f"정답: {y_test}")
print(f"예측: {y_pred}")
print(f"Test Accuracy: {score}")
```

#### 📊 실행 결과
```text
정답: [1, 0, 1, 1, 0]
예측: [1, 0, 0, 1, 0]
Test Accuracy: 0.8
```

#### 🔍 결과 해석
*   총 5개의 데이터 중 **4개를 맞추고(인덱스 0, 1, 3, 4)**, **1개를 틀렸습니다(인덱스 2)**.
*   $4 \div 5 = 0.8$ 이므로, 정확도는 `0.8` (즉, 80%)이 출력됩니다!

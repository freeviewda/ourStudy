# defaultdict - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 21:58:22

---

파이썬 코드로 머신러닝이나 데이터를 다루다 보면 빈번하게 마주치는 `defaultdict`에 대해 초보자의 눈높이에 맞춰 쉽고 명쾌하게 해설해 드릴게요!

---

### 1. 📌 함수 개요
`defaultdict`는 파이썬 기본 내장 모듈인 `collections`에 속해 있는 특별한 딕셔너리(Dictionary)입니다. 일반 딕셔너리와 달리 **존재하지 않는 키(Key)에 접근해도 에러를 발생시키지 않고, 사전에 지정한 기본값(Default value)을 자동으로 생성**해 주는 아주 편리한 함수입니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `importance_by_param = defaultdict(list)`에서 괄호 안에 들어간 인자를 분석해 보겠습니다.

* **인자: `list`**
  * **역할:** 딕셔너리의 키에 해당하는 값이 없을 때, **어떤 기본값(데이터 타입)을 자동으로 만들어 채워넣을지**를 결정합니다.
  * **의미:** 여기서는 파이썬의 기본 리스트 생성 함수인 `list`가 전달되었습니다. 즉, **"앞으로 존재하지 않는 키에 접근하려고 하면, 에러를 내지 말고 빈 리스트(`[]`를 생성해서 기본값으로 넣어줘!"** 라는 뜻입니다.

---

### 3. 📤 반환값/할당 변수
* **할당 변수: `importance_by_param`**
  * **데이터 종류:** 비어 있는 특수 딕셔너리(`collections.defaultdict`) 객체가 반환되어 이 변수에 담깁니다.
  * **특징:** 이 변수는 앞으로 일반 딕셔너리처럼 사용할 수 있지만, **없는 키를 조회하거나 값을 추가할 때 `KeyError` 걱정을 전혀 할 필요가 없습니다.** (예: `importance_by_param['learning_rate'].append(0.05)`라고 바로 써도, 'learning_rate' 키가 없어도 에러 없이 빈 리스트가 먼저 만들어진 후 그 리스트에 `0.05`가 쏙 들어갑니다.)

---

### 4. 🎁 요약 및 실행 예시

초보자분들이 `defaultdict`의 위력을 한눈에 느낄 수 있도록 일반 딕셔너리와 비교하는 코드를 준비했습니다.

#### 💡 일반 딕셔너리를 썼을 때의 불편함
```python
# 일반 딕셔너리로 특정 파라미터의 중요도 점수들을 모으려 할 때
scores = {}
param = "max_depth"

# 키가 아직 없으므로 에러(KeyError) 방지를 위해 매번 체크해야 함!
if param not in scores:
    scores[param] = []

scores[param].append(0.85)
print(scores)  # 출력: {'max_depth': [0.85]}
```

#### ✨ `defaultdict(list)`를 썼을 때의 우아함
```python
from collections import defaultdict

# 1. defaultdict 선언 (값이 없을 때 빈 리스트 생성)
importance_by_param = defaultdict(list)
param = "max_depth"

# 2. 에러 체크 없이 곧바로 리스트 메서드(append) 사용 가능!
importance_by_param[param].append(0.85)
importance_by_param[param].append(0.92)

# 또 다른 파라미터도 바로 추가 가능
importance_by_param["learning_rate"].append(0.1)

print(importance_by_param)
# 출력: defaultdict(<class 'list'>, {'max_depth': [0.85, 0.92], 'learning_rate': [0.1]})
```

> **핵심 요약:** `defaultdict(list)`는 데이터를 그룹화하거나 여러 개의 값을 리스트로 차곡차곡 모을 때(예: 하이퍼파라미터별 성능 점수 수집 등), **"키가 있는지 매번 확인하는 귀찮은 작업(if-else)"을 없애주는 치트키 같은 함수**입니다!

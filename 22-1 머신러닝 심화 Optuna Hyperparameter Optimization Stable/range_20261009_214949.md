# range - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 21:49:49

---

파이썬 코드에서 사용된 `range` 함수와 인자에 대해 초보자의 눈높이에 맞춰 쉽고 친절하게 해설해 드릴게요!

---

### 1. 📌 함수 개요
`range()`는 파이썬의 **대표적인 내장 함수**로, **특정 횟수만큼 반복 작업을 하고 싶을 때** 주로 사용합니다. 
원하는 숫자 범위(시작점부터 끝점 전까지)의 숫자들을 순서대로 만들어 주는 마법 같은 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `range(N_RUNS)`에서 괄호 안에는 하나의 인자가 들어가 있습니다.

* **`N_RUNS`**:
  * **역할**: 반복을 총 몇 번 수행할 것인지를 결정하는 **'끝값(Stop)'**을 지정합니다.
  * **의미**: 만약 `N_RUNS`가 `5`라면, `range(5)`는 **0부터 시작해서 5 직전(즉, 4)까지**의 연속된 숫자를 만들어 냅니다. (컴퓨터는 숫자를 0부터 세는 것을 좋아한다는 점을 기억하세요!)

---

### 3. 📤 반환값/할당 변수
`for run in range(N_RUNS):` 문맥에서 반환되는 값과 변수는 다음과 같이 작동합니다.

* **반환값**: `range(N_RUNS)`는 0부터 `N_RUNS - 1`까지의 숫자 묶음(시퀀스)을 차례대로 하나씩 꺼내어 줍니다.
* **할당 변수 (`run`)**:
  * `range`가 건네주는 숫자를 **반복문이 돌 때마다 하나씩 받아적는 노트** 같은 변수입니다.
  * 첫 번째 바퀴에는 `0`, 두 번째 바퀴에는 `1`, 마지막 바퀴에는 `N_RUNS - 1`이 차례대로 `run`에 쏙쏙 담깁니다.

---

### 4. 🎁 요약 및 실행 예시
백문이 불여일견! 직접 코드를 실행해 보면 3초 만에 이해할 수 있습니다.

**[코드 예시]**
```python
N_RUNS = 3  # 총 3번 반복하고 싶어요!

for run in range(N_RUNS):
    print(f"현재 {run + 1}번째 실행 중입니다!")
```

**[예상 결과]**
```text
현재 1번째 실행 중입니다!
현재 2번째 실행 중입니다!
현재 3번째 실행 중입니다!
```
*(참고: `run`은 0부터 시작하므로, 사람이 읽기 편한 순번을 표현할 때는 `run + 1`을 자주 사용합니다.)*

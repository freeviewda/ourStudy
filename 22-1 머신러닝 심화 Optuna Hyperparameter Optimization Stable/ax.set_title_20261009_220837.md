# ax.set_title - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 22:08:37

---

파이썬 시각화 라이브러리인 맷플롯립(Matplotlib)에서 사용되는 `ax.set_title` 함수에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 쉽고 명쾌하게 정리해 드릴게요!

---

### 1. 📌 함수 개요
`ax.set_title()`은 **그래프의 상단 중앙에 제목(Title)을 설정해 주는 함수**입니다. 우리가 그린 그래프가 무엇을 나타내는지 한눈에 알 수 있도록 이름을 붙여주는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `ax.set_title('LightGBM - Top 5 파라미터', fontweight='bold', fontsize=12)`에 사용된 3가지 인자의 역할은 다음과 같습니다.

*   **`'LightGBM - Top 5 파라미터'` (첫 번째 위치 인자)**
    *   **역할:** 그래프에 표시할 실제 텍스트 내용입니다.
    *   **의미:** 이 그래프가 "LightGBM 모델의 상위 5개 파라미터"를 보여주고 있음을 설명하는 제목 문자열입니다.
*   **`fontweight='bold'` (키워드 인자)**
    *   **역할:** 글자의 굵기(Weight)를 설정합니다.
    *   **의미:** `'bold'`는 **굵게**를 의미합니다. 제목을 강조하고 싶을 때 사용합니다.
*   **`fontsize=12` (키워드 인자)**
    *   **역할:** 글자 크기(Font Size)를 설정합니다.
    *   **의미:** 글자 크기를 `12`포인트로 지정하여, 그래프 전체 크기에 어울리도록 적당한 가독성을 제공합니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값:** `ax.set_title()` 함수는 제목을 나타내는 `matplotlib.text.Text` 객체를 반환합니다.
*   **할당 변수:** 제시된 코드 단독으로는 반환값을 별도의 변수(예: `title_obj = ...`)에 저장하지 않고, **함수 실행 자체로 그래프에 제목을 바로 적용(그리기)**하는 용도로 사용되었습니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 주피터 노트북이나 파이썬 파일에서 직접 실행해 볼 수 있는 가장 간단한 전체 코드 예시입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 도화지(Figure)와 축(Axes) 객체 생성
fig, ax = plt.subplots()

# 2. 간단한 막대그래프 그리기 (예시 데이터)
ax.bar(['Param A', 'Param B', 'Param C'], [10, 25, 15])

# 3. ax.set_title 함수 사용 (오늘 배운 내용!)
ax.set_title('LightGBM - Top 5 파라미터', fontweight='bold', fontsize=12)

# 4. 그래프 화면에 출력
plt.show()
```

**[예상 결과]**
*   화면에 막대그래프가 나타나고, **그래프 바로 위 중앙**에 **굵은 글씨체(bold)**로 **'LightGBM - Top 5 파라미터'**라는 제목이 12포인트 크기로 깔끔하게 표시됩니다.

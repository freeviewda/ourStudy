# 🤖 AI 파이썬 학습 노트: X.head

- **기록 일시**: 2026-09-30 23:46:52
- **대상 코드/함수**: `X.head`

---

제시해주신 파이썬 코드 `print(X.head())`에서 호출된 함수와 인자에 대해 초보자의 눈높이에 맞춰 친절하고 명쾌하게 해설해 드리겠습니다.

---

### 1. 📌 함수 개요
`X.head()`는 파이썬의 데이터 분석 라이브러리인 **Pandas(판다스)**에서 제공하는 함수로, **데이터프레임의 가장 첫 행들(기본값 5개)을 화면에 출력**해 주는 역할을 합니다. 거대한 데이터셋을 다룰 때 데이터가 어떻게 생겼는지(컬럼명, 데이터 타입, 값의 형태 등) 빠르게 훑어볼 때 가장 유용하게 쓰이는 필수 함수입니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
현재 코드인 `X.head()` 안에는 아무런 값도 적혀 있지 않습니다(빈 괄호 상태).

* **전달된 인자:** 없음 (비어 있음)
* **설정된 값의 의미:** 
  * `head()` 함수는 괄호 안에 아무 숫도 넣지 않으면 **기본적으로 맨 위에서부터 5개의 행(Row)**을 보여주도록 설계되어 있습니다.
  * 만약 맨 앞의 10개를 보고 싶다면 `X.head(10)`, 3개만 보고 싶다면 `X.head(3)`처럼 숫자를 넣어 조절할 수 있습니다.

---

### 3. 📤 반환값/할당 변수
이 코드는 별도의 변수에 값을 저장(할당)하지 않고, 곧바로 `print()` 함수를 통해 화면에 출력하는 구조입니다.

* **반환값:** 데이터 `X`의 가장 위쪽 **상위 5개의 행 데이터** (Pandas DataFrame 형태)
* **동작 방식:** 
  1. `X.head()`가 실행되어 상위 5개 데이터 묶음을 반환합니다.
  2. 그 데이터 묶음이 `print()` 함수로 전달되어 모니터 화면에 예쁘게 표(Table) 형태로 출력됩니다.

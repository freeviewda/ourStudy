# 🤖 AI 파이썬 학습 노트: train_test_split

- **기록 일시**: 2026-09-30 23:47:24
- **대상 코드/함수**: `train_test_split`

---

파이썬 머신러닝에서 가장 많이 쓰이는 필수 함수 중 하나인 `train_test_split`에 대한 상세 해설입니다. 초보자분들의 눈높이에 맞춰 하나씩 알기 쉽게 풀어드릴게요!

---

### 1. 📌 함수 개요
`train_test_split`은 가지고 있는 전체 데이터(`X`, `y`)를 **머신러닝 모델을 학습시키기 위한 데이터(Train Set)**와 **성능을 평가하기 위한 테스트 데이터(Test Set)**로 무작위로 쪼개주는 함수입니다. (주로 파이썬의 대표적인 머신러닝 라이브러리인 `scikit-learn`에서 가져와서 사용합니다.)

---

### 2. 🔍 입력 인자(매개변수) 분석
코드에서 사용된 5개의 인자가 각각 어떤 일을 하는지 살펴볼까요?

*   **`X`**: 
    *   **역할**: 모델이 학습할 때 사용하는 **독립 변수(특징, Feature)** 데이터입니다. (예: 집의 크기, 방 개수, 위치 등의 정보)
*   **`y`**: 
    *   **역할**: 우리가 예측하고자 하는 **종속 변수(정답, Label)** 데이터입니다. (예: 실제 집 가격)
*   **`test_size=0.2`**: 
    *   **역할**: 전체 데이터를 학습용과 테스트용으로 나눌 때, **테스트 데이터에 몇 %의 비율을 할당할지** 정합니다.
    *   **의미**: `0.2`는 전체 데이터의 **20%**를 테스트용(`X_test`, `y_test`)으로 쓰겠다는 뜻입니다. 자연스럽게 나머지 80%는 학습용(`X_train`, `y_train`)으로 자동 배정됩니다.
*   **`random_state=42`**: 
    *   **역할**: 데이터를 무작위로 섞을 때 사용할 **'랜덤 시드(씨앗)'** 번호입니다. 컴퓨터는 진짜 무작위로 섞지 못하고 특정 알고리즘으로 섞기 때문에 시드 값이 필요합니다.
    *   **의미**: `42`라는 번호를 지정해 주면, **코드를 몇 번을 다시 실행해도 데이터가 똑같은 방식으로 섞입니다.** 다른 사람과 코드를 공유하거나 결과를 똑같이 재현해야 할 때 필수적인 설정입니다. (숫자 42는 관습적으로 자주 쓰이며, 다른 숫자로 바꿔도 무방합니다.)
*   **`stratify=y`**: 
    *   **역할**: 데이터를 나눌 때, **정답(`y`)의 비율을 유지**하면서 쪼개라는 뜻입니다(층화 추출).
    *   **의미**: 예를 들어 전체 데이터 중 '합격'이 80%, '불합격'이 20%라면, 학습용 데이터와 테스트용 데이터 모두 합격과 불합격이 정확히 8:2 비율을 유지하도록 배분해 줍니다. 특히 **분류(Classification) 문제에서 한쪽 데이터가 편향되는 것을 막아주는 매우 중요한 옵션**입니다.

---

### 3. 📤 반환값 / 할당 변수
이 함수를 실행하고 나면 총 4개의 묶음 데이터가 튀어나오며, 이를 좌변의 변수 4개에 순서대로 쏙쏙 나누어 담게 됩니다 (**파이썬의 '언패킹(Unpacking)' 기능**).

*   **`X_train` (학습용 특징)**: 전체 `X` 데이터의 80%. 모델에게 "이런 특징들을 보고 공부하렴" 하고 던져주는 문제집입니다.
*   **`X_test` (테스트용 특징)**: 전체 `X` 데이터의 20%. 모델에게 "이 특징만 보고 정답을 맞춰봐" 하고 시험을 볼 때 쓰는 시험문제입니다.
*   **`y_train` (학습용 정답)**: 전체 `y` 데이터의 80%. 모델이 공부할 때 참고할 수 있는 '모범 답안'입니다.
*   **`y_test` (테스트용 정답)**: 전체 `y` 데이터의 20%. 모델이 푼 시험 답안이 맞았는지 채점할 때 쓰는 '진짜 정답'입니다.

# 🤖 AI 파이썬 학습 노트: classification_report

- **기록 일시**: 2026-10-01 00:04:13
- **대상 코드/함수**: `classification_report`

---

파이썬 머신러닝에서 모델의 성능을 평가할 때 가장 자주 쓰는 핵심 함수 중 하나인 `classification_report`에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 쉽고 명쾌하게 정리해 드릴게요!

---

### 1. 📌 함수 개요
`classification_report`는 머신러닝 분류(Classification) 모델이 예측한 결과가 실제 데이터와 얼마나 일치하는지 종합적으로 평가하여 **텍스트 형식의 성능 지표 요약표를 만들어주는 함수**입니다. 정밀도(Precision), 재현율(Recall), F1-스코어 등 모델의 실력을 한눈에 파악할 수 있는 핵심 지표들을 깔끔하게 보여줍니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `print(classification_report(y_test, y_pred))`에서 사용된 두 가지 입력 인자의 역할은 다음과 같습니다.

*   **첫 번째 인자: `y_test` (정답 / 실제값)**
    *   **역할:** 테스트 데이터셋에 해당하는 **실제 정답 레이블(Label)**입니다.
    *   **의미:** "이 데이터의 진짜 원래 클래스는 이거야"라고 알려주는 기준점이 됩니다. 모델이 채점받을 때 보는 '답안지'와 같습니다.

*   **두 번째 인자: `y_pred` (모델의 예측값)**
    *   **역할:** 우리가 만든 머신러닝 모델이 `y_test`를 보고 **예측해 낸 결과값**입니다.
    *   **의미:** "모델 네가 이 데이터를 보고 이렇게 예측했지?" 하고 제출하는 '학생의 답안'과 같습니다.

> 💡 **요약하자면:** 진짜 정답(`y_test`)과 모델이 푼 답(`y_pred`)을 비교해서 채점표를 만들어 달라고 요청하는 것입니다.

---

### 3. 📤 반환값/할당 변수
*(※ 질문에서 언급해주신 `train_test_split` 관련 변수명인 X_train, y_test 등과 혼동되지 않도록 `classification_report`가 직접 반환하는 값에 대해 설명해 드릴게요!)*

`classification_report` 함수는 별도의 변수에 대입하지 않고 바로 `print()` 함수 안에 넣었기 때문에, 화면에 텍스트 형태의 성적표를 곧바로 출력하게 됩니다. 이 함수가 반환(출력)하는 텍스트 성적표에는 다음과 같은 항목들이 포함됩니다.

*   **클래스별 지표 (각 행):** 데이터의 카테고리(예: 0, 1 또는 양성, 음성)별로 모델이 얼마나 잘 맞췄는지 보여줍니다.
    *   **Precision (정밀도):** 모델이 '참(Positive)'이라고 예측한 것 중 **실제로 참인 것의 비율**입니다. (오인 낙찰을 줄이는 능력)
    *   **Recall (재현율):** 실제 '참(Positive)'인 것 중 **모델이 참이라고 맞춘 것의 비율**입니다. (놓치는 정답이 없도록 찾는 능력)
    *   **F1-score (F1 점수):** 정밀도와 재현율의 조화 평균으로, 두 지표가 어느 한쪽으로 치우치지 않고 균형을 이루는지 나타냅니다.
    *   **Support:** 테스트 데이터(`y_test`)에 실제로 존재하는 각 클래스의 개수입니다.

*   **전체 평균 지표 (하단 요약 행):**
    *   **Accuracy (정확도):** 전체 데이터 중 모델이 올바르게 맞춘 전체 비율입니다.
    *   **Macro average (매크로 평균):** 각 클래스의 성능을 단순 평균 낸 값입니다.
    *   **Weighted average (가중 평균):** 각 클래스에 속한 데이터의 개수(Support)를 고려하여 가중치를 주어 평균 낸 값입니다.

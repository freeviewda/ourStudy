# 🤖 AI 파이썬 학습 노트: plt.xlabel

- **기록 일시**: 2026-10-01 00:06:59
- **대상 코드/함수**: `plt.xlabel`

---

파이썬의 데이터 시각화 라이브러리인 `matplotlib.pyplot`에서 호출된 **`plt.xlabel`** 함수에 대해 초보자의 눈높이에 맞춰 알기 쉽게 정리해 드립니다.

---

### 1. 📌 함수 개요
`plt.xlabel()`은 생성된 그래프의 **X축(가로축)에 이름(라벨)을 달아주는 함수**입니다. 그래프를 보는 사람이 X축이 무엇을 나타내는지 직관적으로 이해할 수 있도록 도와줍니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
현재 코드에서 사용된 인자는 문자열 하나입니다.

*   **`"Number of Features Selected"`**
    *   **역할**: X축에 표시될 텍스트(이름)를 지정합니다.
    *   **설정된 값의 의미**: 직역하면 **"선택된 특성(변수)의 개수"**라는 뜻입니다. 기계학습(Machine Learning)에서 모델의 성능을 높이기 위해 여러 개의 데이터 특징(Feature) 중 몇 개를 골라 사용할 때, 그 개수를 X축에 나타내고 있음을 알려줍니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값 없음 (`None`)**
    *   `plt.xlabel()` 함수는 그래프의 X축에 글자를 그려주는 시각화 작업만 수행하고, 별도의 데이터를 반환하지 않습니다. 따라서 변수에 따로 값을 할당(저장)할 필요 없이 단독으로 호출하여 사용합니다.

# 🤖 AI 파이썬 학습 노트: PCA

- **기록 일시**: 2026-09-28 16:50:55
- **대상 코드/함수**: `PCA`

---

파이썬 머신러닝 코드에서 사용된 `PCA` 함수와 인자들에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 쉽고 명쾌하게 정리해 드릴게요!

---

### 1. 📌 함수 개요
`PCA`(Principal Component Analysis, 주성분 분석)는 **데이터의 특성(컬럼) 개수를 줄여주는 '차원 축소' 알고리즘**입니다. 데이터의 전체적인 특징(분산)은 최대한 유지하면서 복잡한 고차원 데이터를 저차원(예: 2차원)으로 압축하여, 데이터 시각화나 머신러닝 연산 속도 향상에 아주 유용하게 쓰입니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
코드 `PCA(n_components=2, random_state=42)`에 전달된 두 가지 인자의 역할과 설정값의 의미는 다음과 같습니다.

*   **`n_components=2`**
    *   **역할:** 축소할 차원의 수(남겨둘 특성의 개수)를 지정합니다.
    *   **의미:** 원래 데이터에 특성이 10개든 100개든 상관없이, 가장 중요한 정보(주성분) **딱 2개만 남기고 나머지는 압축해서 버리겠다**는 뜻입니다. 보통 2차원 산점도(그래프)로 데이터를 시각화하고 싶을 때 `2`로 설정합니다.
*   **`random_state=42`**
    *   **역할:** 난수(랜덤) 발생 시드를 고정합니다.
    *   **의미:** PCA는 내부적으로 무작위성을 포함하는 연산을 일부 거치기 때문에, 이 값을 지정하지 않으면 코드를 실행할 때마다 결과가 미세하게 바뀔 수 있습니다. `42`라는 특정 번호를 주어 **"코드를 언제 실행해도 항상 똑같은 결과가 나오도록"** 고정해 주는 안전장치입니다. (숫자 42는 관습적으로 가장 많이 쓰는 숫자 중 하나입니다.)

---

### 3. 📤 반환값/할당 변수
코드에서 `PCA(...)`를 실행한 결과를 담은 `pca` 변수가 무엇인지 설명해 드릴게요.

*   **`pca` (할당된 변수)**
    *   **설명:** 이 변수 자체는 데이터가 아니라, **"데이터를 2차원으로 압축하는 방법을 학습하고 실행해 주는 도구(모델 객체)"**입니다.
    *   **사용법:** 이후에 이 `pca` 객체에 `.fit_transform(데이터)` 같은 메서드를 붙여서, 실제로 원래 데이터를 2차원 데이터로 변환하는 작업을 수행하게 됩니다.

# 🤖 AI 파이썬 학습 노트: plt.figure

- **기록 일시**: 2026-09-28 16:51:53
- **대상 코드/함수**: `plt.figure`

---

파이썬의 데이터 시각화 라이브러리인 **Matplotlib**에서 가장 자주 쓰이는 `plt.figure` 함수에 대한 상세 해설입니다. 초보자분들이 쉽게 이해하실 수 있도록 요청하신 항목에 맞춰 정리해 드립니다.

---

### 1. 📌 함수 개요
`plt.figure`는 그림(도화지)을 새로 생성하는 함수입니다. 파이썬에서 그래프를 그리기 전에 **"여기에 새로운 그림을 그릴 테니, 도화지 한 장을 새로 꺼내줘!"**라고 지시하는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `plt.figure(figsize=(6, 5))`에서 사용된 인자의 의미는 다음과 같습니다.

*   **`figsize` (도화지의 크기 설정)**
    *   **역할:** 생성할 그래프(도화지)의 가로와 세로 크기를 인치(inch) 단위로 지정합니다.
    *   **설정된 값 `(6, 5)`의 의미:** 가로 6인치, 세로 5인치 크기의 직사각형 도화지를 만듭니다. 숫자가 클수록 화면에 더 커다란 그래프가 그려집니다.

---

### 3. 📤 반환값/할당 변수
`plt.figure(figsize=(6, 5))` 코드는 별도의 변수에 값을 할당하지 않고 단독으로 사용되었습니다. 

*   **반환값 설명:** 이 함수는 생성된 도화지(Figure 객체)를 반환하지만, 위 코드처럼 변수에 저장하지 않아도 파이썬이 **"지금부터 그리는 모든 그래프는 이 새로 만든 도화지 위에 그려라"**고 자동으로 기억(활성화)합니다. 
*   **활용 팁:** 나중에 여러 개의 그래프를 관리하거나 세부 설정을 변경하고 싶을 때는 다음과 같이 변수에 담아서 사용하기도 합니다.
    ```python
    fig = plt.figure(figsize=(6, 5))  # fig 변수에 도화지가 저장됨
    ```

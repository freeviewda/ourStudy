# 🤖 AI 파이썬 학습 노트: classification_report

- **기록 일시**: 2026-09-27 18:18:20
- **대상 코드/함수**: `classification_report`

---

파이썬의 머신러닝 라이브러리인 `scikit-learn`(sklearn)에서 자주 사용되는 `classification_report` 함수에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 친절하고 명쾌하게 정리해 드릴게요!

---

### 1. 📌 함수 개요
`classification_report`는 **머신러닝 분류(Classification) 모델의 성능을 한눈에 평가하고 요약해 주는 성적표(Report)를 만들어주는 함수**입니다. 모델이 예측한 결과가 실제 정답과 얼마나 일치하는지, 주요 평가지표(정밀도, 재현율, F1 점수 등)를 보기 쉽게 텍스트 형태로 출력해 줍니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `print(classification_report(y_test, y_pred_orig))`에서 사용된 두 개의 입력 인자의 역할은 다음과 같습니다.

*   **`y_test` (첫 번째 인자)**
    *   **역할:** 실제 정답 데이터 (True Labels)
    *   **의미:** 테스트 데이터셋에 실제로 묶여 있던 진짜 레이블(값)들입니다. 모델이 맞혀야 하는 '정답지' 역할을 합니다.
*   **`y_pred_orig` (두 번째 인자)**
    *   **역할:** 모델이 예측한 데이터 (Predicted Labels)
    *   **의미:** 학습을 마친 머신러닝 모델이 `y_test`에 대응하는 테스트 데이터를 보고 "이것일 것이다"라고 예측한 '답안지'입니다. 원래 형태(`_orig`)로 복원된 예측값을 의미합니다.

> **💡 요약하자면:** 진짜 정답(`y_test`)과 모델의 예측값(`y_pred_orig`)을 비교하여 모델이 시험을 얼마나 잘 봤는지 채점표를 만들어 달라고 함수에 요청하는 것입니다.

---

### 3. 📤 반환값 및 출력 결과
`classification_report` 함수는 별도의 변수에 값을 할당(`=` 기호 사용)하지 않고 바로 `print()` 함수 안에 넣었기 때문에, **콘솔창에 문자열 형태의 성적표(텍스트 리포트)를 바로 출력**합니다.

이 리포트에는 보통 다음과 같은 핵심 지표들이 클래스(종류)별로 예쁘게 정렬되어 나타납니다.

1.  **Precision (정밀도):** 모델이 '참(Positive)'이라고 예측한 것 중에서 **실제로 참인 것의 비율**입니다. (예: 스팸이라고 분류한 것 중 진짜 스팸의 비율)
2.  **Recall (재현율, 민감도):** 실제 '참(Positive)'인 것들 중에서 **모델이 참이라고 올바르게 맞힌 것의 비율**입니다. (예: 실제 스팸들 중 모델이 스팸이라고 찾아낸 비율)
3.  **F1-score (F1 점수):** 정밀도와 재현율의 조화 평균입니다. 어느 한쪽으로 치우치지 않고 모델이 균형 있게 잘 예측했는지 나타내는 종합 점수입니다.
4.  **Support:** 각 클래스(범주)에 속하는 **실제 데이터의 개수**입니다.
5.  **Accuracy (정확도):** 전체 데이터 중 모델이 올바르게 맞힌 전체 비율입니다. (보통 맨 아래나 요약 부분에 함께 표시됩니다.)

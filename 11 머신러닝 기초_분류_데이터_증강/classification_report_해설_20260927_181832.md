# 🤖 AI 파이썬 학습 노트: classification_report

- **기록 일시**: 2026-09-27 18:18:32
- **대상 코드/함수**: `classification_report`

---

파이썬 머신러닝 분석에서 모델의 성능을 평가할 때 가장 자주 쓰이는 `classification_report` 함수에 대해 초보자의 눈높이에 맞춰 친절하고 명쾌하게 해설해 드리겠습니다!

---

### 1. 📌 함수 개요
`classification_report`는 머신러닝 분류(Classification) 모델이 **얼마나 일을 잘했는지 종합적으로 평가(성적표를 작성)해주는 함수**입니다. 
정확도(Accuracy)뿐만 아니라 정밀도(Precision), 재현율(Recall), F1-스코어(F1-score) 등 모델의 성능을 다각도로 분석한 리포트를 텍스트 형태로 예쁘게 출력해 줍니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `print(classification_report(y_test, y_pred_smote))`에서 함수에 전달된 두 개의 인자를 살펴봅니다.

*   **첫 번째 인자: `y_test`**
    *   **역할:** 실제 정답 데이터입니다.
    *   **의미:** 테스트용 데이터셋(`X_test`)의 **진짜 레이블(참값)**로, 모델이 맞혀야 하는 정답지라고 생각하시면 됩니다.
*   **두 번째 인자: `y_pred_smote`**
    *   **역할:** 모델이 예측한 예측값 데이터입니다.
    *   **의미:** SMOTE 기법(데이터 불균형을 해소하는 방법)을 거친 학습 데이터로 만든 모델이, 테스트 데이터(`X_test`)를 보고 **"이것은 이런 결과일 것이다"라고 예측한 값**입니다.

👉 **요약하자면:** "진짜 정답(`y_test`)과 모델이 예측한 값(`y_pred_smote`)을 서로 비교해서 성적표를 만들어라!" 라는 뜻입니다.

---

### 3. 📤 반환값/출력 결과 설명
`print()` 함수 안에 이 코드가 들어가 있으므로, 변수에 값을 담는 대신 **콘솔창에 바로 텍스트 성적표가 출력**됩니다. 이 리포트에는 보통 다음과 같은 항목들이 포함됩니다.

*   **Precision (정밀도):** 모델이 '정답'이라고 예측한 것들 중, **실제로 정답인 것의 비율**입니다. (예: 스팸이라고 분류한 것 중 진짜 스팸의 비율)
*   **Recall (재현율):** 실제 '정답'인 것들 중, **모델이 정답이라고 맞힌 것의 비율**입니다. (예: 실제 스팸 중 모델이 스팸이라고 찾아낸 비율)
*   **F1-score (F1 점수):** 정밀도와 재현율의 조화 평균입니다. 두 지표 어느 한쪽으로 치우치지 않고 모델이 균형 있게 잘 예측했는지 보는 핵심 지표입니다.
*   **Support:** 각 클래스(정답의 종류)에 속하는 **실제 데이터의 개수**입니다.
*   **Accuracy (정확도):** 전체 데이터 중 모델이 올바르게 맞힌 전체 비율입니다.
*   **Macro avg / Weighted avg:** 여러 개의 클래스가 있을 때 전체 평균을 내는 방식입니다. (데이터 개수의 가중치를 반영했느냐의 차이)

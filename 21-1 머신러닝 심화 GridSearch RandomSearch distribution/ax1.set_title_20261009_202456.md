# ax1.set_title - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 20:24:56

---

파이썬 시각화 라이브러리인 맷플롯립(Matplotlib)을 사용할 때 자주 쓰는 `ax1.set_title` 함수에 대해 초보자의 눈높이에 맞춰 친절하고 명쾌하게 해설해 드릴게요!

---

### 1. 📌 함수 개요
`ax1.set_title`은 **특정 그래프(Axes 객체)의 상단에 제목(Title)을 설정해 주는 함수**입니다. 여러 개의 그래프(서브플롯)를 그릴 때, 첫 번째 그래프(`ax1`)에 어떤 데이터나 결과를 보여주는지 이름을 붙여줄 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `ax1.set_title('Test Accuracy 비교', fontsize=12, fontweight='bold')`에 사용된 3가지 인자의 역할은 다음과 같습니다.

*   **`'Test Accuracy 비교'` (위치 인자 / Title 문자열)**
    *   **역할:** 그래프 상단에 표시될 **제목의 텍스트 내용**을 지정합니다.
    *   **의미:** 이 그래프가 '테스트 정확도(Test Accuracy)를 서로 비교하고 있다'는 것을 시각적으로 알려줍니다.
*   **`fontsize=12` (키워드 인자)**
    *   **역할:** 제목 글자의 **크기(Font Size)**를 조절합니다.
    *   **의미:** 숫자가 클수록 글자가 커지며, 여기서는 12 크기로 설정하여 너무 부담스럽지 않고 깔끔한 크기로 제목을 표시했습니다.
*   **`fontweight='bold'` (키워드 인자)**
    *   **역할:** 글자의 **두께(Font Weight)**를 설정합니다.
    *   **의미:** `'bold'`는 **굵게**를 의미합니다. 그래프의 제목이 눈에 잘 띌 수 있도록 강조 효과를 줍니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값:** `Text` 객체 (생성된 제목 텍스트에 대한 정보 객체)
*   **설명:** 이 함수는 주로 그래프를 꾸미기 위한 **명령형 함수**로 사용되기 때문에, 별도의 변수에 반환값을 받아와서 다시 쓰는 경우는 초보 단계에서는 거의 없습니다. 단순히 화면에 제목을 렌더링하는 역할로 끝납니다.

---

### 4. 🎁 요약 및 실행 예시
백문이 불여일견! 아래의 간단한 코드를 직접 실행해 보며 `set_title`이 어떻게 동작하는지 눈으로 확인해 보세요.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 도화지(Figure)와 그래프(Axes) 1개 생성
fig, ax1 = plt.subplots()

# 2. 간단한 선 그래프 그리기
ax1.plot([1, 2, 3], [10, 20, 25])

# 3. ax1.set_title 함수 사용하기
ax1.set_title('Test Accuracy 비교', fontsize=12, fontweight='bold')

# 4. 그래프 화면에 출력
plt.show()
```

**[예상 결과]**
*   창이 하나 뜨고, 그 안에 꺾은선 그래프가 그려집니다.
*   그래프 바로 위 **정중앙**에 **"Test Accuracy 비교"**라는 텍스트가 **굵은 글씨(bold)**와 **적당한 크기(12)**로 깔끔하게 나타납니다.

# ax1.set_ylabel - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 20:25:00

---

파이썬의 데이터 시각화 라이브러리인 **Matplotlib**을 사용할 때 자주 쓰이는 `ax1.set_ylabel('Accuracy')` 코드에 대한 상세 해설입니다.

---

### 1. 📌 함수 개요
`ax1.set_ylabel()`은 그래프의 **세로축(Y축)에 이름(라벨)을 지정**해 주는 함수입니다. 그래프를 보는 사람이 세로축의 데이터가 무엇을 나타내는지(예: 정답률, 가격, 온도 등) 쉽게 알아볼 수 있도록 설명글을 달아주는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제공해주신 코드에서는 하나의 인자가 전달되었습니다.

* **`'Accuracy'` (문자열, string)**
  * **역할:** Y축에 표시될 텍스트(이름)를 지정합니다.
  * **설정된 값의 의미:** 영어 단어 그대로 **'정확도'**를 의미합니다. 머신러닝이나 딥러닝 모델의 학습 결과(성능)를 그래프로 그릴 때, Y축이 모델의 정확도를 나타내고 있음을 알려주기 위해 이 값을 사용했습니다.

---

### 3. 📤 반환값/할당 변수
* **반환값:** 이 함수는 별도의 데이터를 리턴하기보다, **현재 지정된 Y축 객체(Text 객체)**를 반환합니다.
* **할당 변수:** 대개 위 코드처럼 반환값을 별도의 변수에 저장(`result = ax1.set_ylabel(...)`)하지 않고, **함수 자체의 실행 목적(축 이름 표시)**만을 위해 단독으로 호출하여 사용합니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 주피터 노트북이나 파이썬 스크립트에서 직접 실행해 볼 수 있는 가장 간단한 그래프 그리기 예시입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 도화지(fig)와 축(ax1) 만들기
fig, ax1 = plt.subplots()

# 2. 데이터 준비 (예: 에포크별 정확도)
epochs = [1, 2, 3, 4, 5]
accuracy = [0.60, 0.75, 0.85, 0.90, 0.95]

# 3. 선 그래프 그리기
ax1.plot(epochs, accuracy, marker='o')

# 4. Y축 이름 지정하기 (★오늘 배운 함수!)
ax1.set_ylabel('Accuracy')

# 5. X축 이름 지정하기
ax1.set_xlabel('Epochs')

# 6. 그래프 화면에 띄우기
plt.show()
```

**[예상 결과]**
* 화면에 창이 하나 뜨면서 꺾은선 그래프가 나타납니다.
* 그래프의 **가로축(X축) 아래에는 'Epochs'**가 적히고, **세로축(Y축) 왼쪽 옆에는 세로 방향으로 'Accuracy'**라는 글자가 예쁘게 표시됩니다.

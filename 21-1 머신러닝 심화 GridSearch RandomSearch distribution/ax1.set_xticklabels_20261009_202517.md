# ax1.set_xticklabels - AI 파이썬 학습 노트

---

파이썬 데이터 시각화 라이브러리인 맷플롯립(Matplotlib)을 사용할 때 자주 쓰이는 `ax1.set_xticklabels()` 함수에 대한 상세 해설입니다. 초보자분들도 이해하기 쉽게 차근차근 설명해 드릴게요!

---

### 1. 📌 함수 개요
`ax1.set_xticklabels()`는 **그래프의 X축 눈금(Ticks)에 표시되는 텍스트(이름)를 사용자가 원하는 대로 지정하거나 수정**하는 함수입니다. 이 코드는 기존 X축 라벨을 그대로 가져온 뒤, 글자의 회전 각도를 0도로 만들어 **텍스트가 항상 수평(가로)으로 반듯하게 보이도록 정렬**할 때 주로 사용됩니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `ax1.set_xticklabels(ax1.get_xticklabels(), rotation=0)`에는 총 두 개의 인자가 전달되고 있습니다. 하나씩 살펴볼까요?

*   **첫 번째 인자: `ax1.get_xticklabels()`**
    *   **역할:** 현재 `ax1` 그래프의 X축에 이미 적혀있는 라벨(텍스트)들의 위치와 정보들을 파이썬 리스트 형태로 **가져오는(Get)** 함수입니다.
    *   **의미:** "지금 X축에 있는 글자들 그대로를 가져와서 다음 작업에 쓸 거야"라는 뜻입니다.
*   **두 번째 인자: `rotation=0`**
    *   **역할:** 가져온 X축 텍스트를 몇 도로 회전시킬지 정하는 매개변수입니다.
    *   **설정값 의미:** `0`으로 설정했으므로, 텍스트를 회전시키지 않고 **기본적인 수평(가로) 방향**으로 반듯하게 출력하라는 뜻입니다. (만약 `rotation=45`로 주면 글자가 45도 비스듬하게 기울어집니다.)

---

### 3. 📤 반환값/할당 변수
이 코드에서는 별도의 변수에 값을 대입(할당)하지 않고, 함수를 실행하여 그래프의 속성만 곧바로 변경합니다. 
*   **반환값:** Matplotlib 내부적으로 변경된 텍스트 객체(Text object)들의 리스트를 반환하지만, 보통은 위 코드처럼 **반환값을 따로 받지 않고** 화면에 그려지는 모양을 바꾸는 용도로만 사용합니다.

---

### 4. 🎁 요약 및 실행 예시
백문이 불여일견! 초보자분들이 직접 코랩(Colab)이나 주피터 노트북에 복사해서 실행해 볼 수 있는 간단한 전체 코드를 준비했습니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 도화지(fig)와 그래프(ax1) 만들기
fig, ax1 = plt.subplots()

# 2. 간단한 데이터로 막대그래프 그리기
categories = ['Apple', 'Banana', 'Cherry']
values = [10, 25, 15]
ax1.bar(categories, values)

# 3. [핵심 코드] X축 라벨을 가져와서 수평(0도)으로 정렬하기
ax1.set_xticklabels(ax1.get_xticklabels(), rotation=0)

# 4. 그래프 화면에 띄우기
plt.show()
```

**[예상 결과]**
*   X축 아래에 'Apple', 'Banana', 'Cherry'라는 과일 이름이 각각 적힙니다.
*   `rotation=0` 덕분에 이 글자들은 기울어지지 않고 **정자(가로 방향)**로 깔끔하게 출력됩니다. (글자가 길어서 겹칠 때는 `rotation=45` 등으로 바꾸어 실험해보면 차이를 쉽게 느낄 수 있습니다!)

# ax1.set_title - AI 파이썬 학습 노트

- 생성 일시: 2026-10-09 20:31:49

---

파이썬의 대표적인 시각화 라이브러리인 **Matplotlib**을 사용할 때 자주 쓰는 `ax1.set_title` 코드에 대한 상세 해설입니다. 초보자도 이해하기 쉽도록 항목별로 친절하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`ax1.set_title()`은 그래프(Axes)의 **상단 중앙에 제목(Title)을 설정**해 주는 함수입니다. 여러 개의 그래프를 그린다면, 특정 그래프(`ax1`)를 지정하여 각각 다른 제목을 붙일 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제공해주신 코드에는 위치 인자 1개와 키워드 인자 2개가 사용되었습니다. 각각의 역할은 다음과 같습니다.

*   **`'Test Accuracy Heatmap: All Models × Methods'` (위치 인자)**
    *   **역할:** 그래프 상단에 표시될 **실제 텍스트 내용**입니다.
    *   **의미:** 이 히트맵이 "모든 모델과 방법론(Methods) 간의 테스트 정확도(Test Accuracy)"를 보여주는 그래프라는 것을 설명하고 있습니다.
*   **`fontsize=14` (키워드 인자)**
    *   **역할:** 제목 글자의 **크기(Font Size)**를 조절합니다.
    *   **의미:** 기본 크기보다 조금 더 크게 설정(`14`)하여, 그래프를 보는 사람이 가장 먼저 제목을 눈치챌 수 있도록 강조했습니다.
*   **`fontweight='bold'` (키워드 인자)**
    *   **역할:** 제목 글자의 **두께(Font Weight)**를 설정합니다.
    *   **의미:** `'bold'` 값을 주어 글씨를 **굵게** 만들었습니다. 시각적으로 제목이 돋보이게 하는 효과가 있습니다.

---

### 3. 📤 반환값/할당 변수
*   `ax1.set_title()` 함수는 설정된 텍스트 객체(`matplotlib.text.Text`)를 반환합니다.
*   하지만 위 코드에서는 반환값을 별도의 변수에 저장(`=` 대입 연산자 사용)하지 않고 함수만 실행(호출)했습니다. 
*   파이썬에서는 시각화 속성을 변경할 때 반환값을 굳이 받지 않고 함수만 실행해도 그래프에 즉시 반영되기 때문에, 이처럼 단독으로 자주 사용합니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 주피터 노트북이나 파이썬 파일에서 실행해 볼 수 있는 가장 간단한 전체 코드 예시입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 도화지(Figure)와 그래프 공간(Axes) 생성
fig, ax1 = plt.subplots(figsize=(6, 4))

# 2. ax1에 제목 설정 (질문하신 코드 적용!)
ax1.set_title('Test Accuracy Heatmap: All Models × Methods', fontsize=14, fontweight='bold')

# 3. 그래프 화면에 띄우기
plt.show()
```

**[예상 결과]**
*   가로 6, 세로 4 크기의 빈 그래프 창이 하나 나타납니다.
*   그 그래프의 바로 위쪽 중앙에 **"Test Accuracy Heatmap: All Models × Methods"** 라는 문구가 **크고 굵은 글씨**로 깔끔하게 출력됩니다.

파이썬의 데이터 시각화 라이브러리인 `matplotlib`에서 사용되는 `ax1.legend(title='Method')` 코드에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 쉽고 명쾌하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`ax1.legend()`는 그래프에 **범례(Legend)**를 표시해 주는 함수입니다. 범례란 "빨간 선은 A 방법, 파란 선은 B 방법"처럼 그래프에 그려진 선이나 막대가 무엇을 의미하는지 알려주는 안내판 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시된 코드에서 사용된 인자는 다음과 같습니다.

*   **`title='Method'`**
    *   **역할:** 범례 상단에 제목(카테고리 이름)을 달아줍니다.
    *   **설정된 값의 의미:** 범례 박스 가장 위에 **'Method'**(방법)라는 제목이 표시됩니다. 여러 데이터 그룹을 어떤 기준(여기서는 '방법'별)으로 나누었는지 보는 사람에게 직관적으로 알려줄 때 유용합니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값 없음 (`= None`에 가까움)**
    *   이 코드는 별도의 변수에 값을 할당하지 않고 함수만 단독으로 호출(`ax1.legend(title='Method')`)했습니다.
    *   이 경우, 파이썬은 범례 객체를 생성하여 즉시 `ax1` 그래프 위에 그려넣고 끝납니다. (필요하다면 `legend = ax1.legend(...)` 형태로 범례 객체를 변수에 담아 나중에 세부 조작을 할 수도 있지만, 지금은 화면에 띄우는 것만으로 충분하기 때문에 생략된 형태입니다.)

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 Jupyter Notebook이나 파이썬 파일에서 실행해 보고 결과를 확인할 수 있는 가장 간단한 예제 코드입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 도화지(Figure)와 그래프 축(Axes) 생성
fig, ax1 = plt.subplots()

# 2. 임의의 데이터 선 그래프 2개 그리기 (label 지정 필수!)
ax1.plot([1, 2, 3], [1, 4, 9], label='Fast')  # 첫 번째 선
ax1.plot([1, 2, 3], [2, 3, 5], label='Slow')  # 두 번째 선

# 3. 범례 추가하기 (오늘의 핵심 코드!)
ax1.legend(title='Method')

# 4. 그래프 화면에 띄우기
plt.show()
```

**[예상 결과]**
*   그래프 우측 상단(또는 빈 공간)에 작은 네모 박스(범례)가 나타납니다.
*   박스 맨 위에는 대문자로 **`Method`** 라는 제목이 적혀 있습니다.
*   그 아래로 각각 빨간색 선 옆에는 **'Fast'**, 파란색 선 옆에는 **'Slow'** 라는 글자가 적혀 있어 어떤 선이 어떤 데이터인지 한눈에 알아볼 수 있게 됩니다.

파이썬 시각화 라이브러리인 맷플롯립(Matplotlib)에서 사용되는 `ax3.legend(title='Method')` 코드에 대한 상세 해설입니다.

---

### 1. 📌 함수 개요
`ax3.legend()`는 **그래프에 범례(Legend)를 표시해 주는 함수**입니다. 여러 개의 선이나 막대가 각각 어떤 데이터를 나타내는지 알려주는 '지도 속 범례' 같은 역할을 하며, `ax3`라는 특정 그래프 영역(Subplot)에만 범례를 쏙 골라서 생성합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드에서 사용된 인자는 `title='Method'` 하나입니다. 

*   **`title = 'Method'`**
    *   **역할:** 범례 상단에 제목(테두리 안쪽 제목)을 달아줍니다.
    *   **설정값 의미:** `'Method'`라는 문자열을 지정했으므로, 범례 박스 맨 위에 **"Method"**라는 제목이 표시됩니다. 이를 통해 이 범례가 어떤 기준(예: 데이터 분석 방법론 등)으로 나뉘었는지 보는 사람에게 명확하게 알려줄 수 있습니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값 없음 (또는 `Legend` 객체 반환):**
    *   이 코드는 별도의 변수에 값을 할당하지 않고 단독으로 실행되었습니다. 
    *   이 경우, 함수는 내부적으로 생성된 범례 객체(`matplotlib.legend.Legend`)를 반환하지만, 보통은 변수에 담지 않고 곧바로 화면에 범례를 그리는 용도로만 사용합니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 주피터 노트북이나 파이썬 파일에서 직접 실행해 볼 수 있는 가장 간단한 전체 코드 예시입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 도화지와 3번 그래프 영역(ax3) 만들기
fig, ax3 = plt.subplots()

# 2. 예시 데이터로 선 그래프 2개 그리기 (label 지정 필수!)
ax3.plot([1, 2, 3], [1, 4, 9], label='Linear')
ax3.plot([1, 2, 3], [1, 2, 3], label='Square')

# 3. ax3.legend() 함수 호출 (범례 제목을 'Method'로 지정)
ax3.legend(title='Method')

# 4. 그래프 화면에 띄우기
plt.show()
```

**[예상 결과]**
*   그래프 우측 상단(또는 빈 공간)에 네모난 박스(범례)가 생깁니다.
*   박스 맨 위에는 **`Method`**라는 제목이 적혀 있고, 
*   그 아래로 `Linear`와 `Square`라는 이름이 각각 해당하는 선의 색상 아이콘과 함께 나란히 표시됩니다.

파이썬 시각화 라이브러리인 맷플롯립(Matplotlib)에서 사용된 `ax2.legend(title='Method')` 코드에 대한 상세한 해설입니다. 초보자도 쉽게 이해할 수 있도록 항목별로 친절하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`ax2.legend()`는 **그래프에 범례(Legend)를 표시해 주는 함수**입니다. 그래프 선이나 막대가 무엇을 의미하는지 알려주는 '안내판' 역할을 하며, 여기서는 두 번째 그래프(`ax2`)에 범례를 추가하고 범례의 제목을 설정하는 역할을 합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시된 코드에서 사용된 인자는 다음과 같습니다.

*   **`title='Method'`**
    *   **역할:** 범례 상단에 제목(카테고리 이름)을 달아줍니다.
    *   **설정값 의미:** `'Method'`라는 문자열을 값으로 주었기 때문에, 범례 박스 가장 위에 **"Method"**라는 제목이 굵게 표시됩니다. 여러 데이터 그룹이 어떤 기준(여기서는 '방법'이나 '알고리즘' 등)으로 나뉘었는지 독자에게 명확하게 알려줄 때 유용합니다.

---

### 3. 📤 반환값/할당 변수
*   **반환값 없음 (할당 변수 없음)**
    *   이 코드에서는 반환값을 별도의 변수(`legend = ax2.legend(...)` 형태)에 담지 않고 바로 실행했습니다.
    *   이 경우, 파이썬은 범례 객체를 생성하여 화면(그래프)에 곧바로 그려넣고 끝냅니다. (나중에 범례의 세부 디자인을 코드로 추가 조절할 일이 없다면, 이렇게 바로 호출해도 전혀 문제없습니다.)

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 Jupyter Notebook이나 파이썬 파일에서 실행해 보고 결과를 확인할 수 있는 가장 간단한 예제 코드입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 도화지와 2개의 그래프 공간(Subplot) 만들기
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 4))

# 2. ax2에 데이터 그리기 (라벨 지정 필수!)
ax2.plot([1, 2, 3], [1, 4, 9], label='A Method')
ax2.plot([1, 2, 3], [2, 3, 5], label='B Method')

# 3. 범례 추가 및 제목 설정 (오늘 배운 핵심 코드!)
ax2.legend(title='Method')

# 4. 화면에 보여주기
plt.show()
```

**[예상 결과]**
*   오른쪽 그래프(`ax2`) 구석에 작은 박스(범례)가 생깁니다.
*   그 박스 맨 위에는 **`Method`**라는 제목이 적혀 있고,
*   그 아래로 각각 파란색 선 옆에 `A Method`, 주황색 선 옆에 `B Method`라는 글자가 표시되어 어떤 선이 어떤 방법인지 쉽게 알아볼 수 있게 됩니다.

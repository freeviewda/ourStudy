파이썬 시각화 라이브러리인 Matplotlib을 사용할 때 자주 쓰이는 `ax7.legend()` 함수에 대한 상세 해설입니다. 초보자분들도 쉽게 이해하실 수 있도록 차근차근 설명해 드릴게요!

---

### 1. 📌 함수 개요
`ax7.legend()`는 그래프에 **범례(Legend)**를 표시해 주는 함수입니다. 그래프 상의 여러 선(Line)이나 막대가 어떤 데이터를 나타내는지 이름을표 붙여주어, 보는 사람이 그래프를 쉽게 이해할 수 있도록 도와줍니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드 `ax7.legend(['GridSearch', 'RandomSearch'])`에서 사용된 인자는 단 하나입니다.

* **첫 번째 인자 (`['GridSearch', 'RandomSearch']` - 리스트 형태)**
  * **역할:** 그래프에 나타난 데이터 순서대로 범례에 표시할 이름을 지정합니다.
  * **설정된 값의 의미:** 
    * 첫 번째 항목인 `'GridSearch'`는 그래프에 그려진 첫 번째 데이터(선 등)의 이름이 됩니다.
    * 두 번째 항목인 `'RandomSearch'`는 두 번째 데이터의 이름이 됩니다.
  * *(참고)* 이 리스트의 개수는 현재 `ax7`에 그려진 데이터(그래프 요소)의 개수와 일치하는 것이 일반적입니다.

---

### 3. 📤 반환값/할당 변수
* **반환값:** 이 코드에서는 반환값을 별도의 변수(예: `leg = ax7.legend(...)`)에 저장하지 않고 함수만 실행했습니다.
* **설명:** 변수에 담지 않아도 Matplotlib이 알아서 `ax7` 그래프 영역 안에 범례를 렌더링(표시)해 줍니다. 
  * 만약 범례의 글자 크기를 바꾸거나 위치를 세밀하게 조정하고 싶다면, 반환되는 범례 객체(`matplotlib.legend.Legend`)를 변수에 담아 추가 조작을 할 수도 있습니다. (예: `legend = ax7.legend([...])`)

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 직접 Jupyter Notebook이나 파이썬 파일에서 실행해 볼 수 있는 가장 단순화된 코드입니다.

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 도화지(Figure)와 축(Axes) 생성
fig, ax7 = plt.subplots()

# 2. 임의의 데이터 두 개를 선 그래프로 그리기
ax7.plot([1, 2, 3], [4, 5, 6])  # 첫 번째 데이터 (GridSearch용)
ax7.plot([1, 2, 3], [6, 5, 4])  # 두 번째 데이터 (RandomSearch용)

# 3. 질문하신 범례(legend) 함수 호출
ax7.legend(['GridSearch', 'RandomSearch'])

# 4. 그래프 화면에 띄우기
plt.show()
```

**[예상 결과]**
* 그래프 우측 상단(또는 빈 공간)에 작은 상자가 생깁니다.
* 상자 안에는 첫 번째 선의 색상과 함께 **"GridSearch"**라는 글자가, 그 아래에는 두 번째 선의 색상과 함께 **"RandomSearch"**라는 글자가 나란히 표시되어 어떤 선이 어떤 탐색 알고리즘의 결과인지 한눈에 알아볼 수 있게 됩니다.

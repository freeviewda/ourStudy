# ax2.set_ylabel - AI 파이썬 학습 노트

---

파이썬의 데이터 시각화 라이브러리인 **Matplotlib**을 사용할 때 자주 쓰이는 `ax2.set_ylabel('F1-Score')` 코드에 대한 상세 해설입니다. 초보자의 눈높이에 맞춰 하나씩 친절하게 설명해 드릴게요!

---

### 1. 📌 함수 개요
`ax2.set_ylabel()`은 **Matplotlib 그래프에서 두 번째 Y축(세로축)의 이름(라벨)을 설정해주는 함수**입니다. 하나의 그림(Figure) 안에 여러 개의 그래프 축(Subplot)이 있을 때, `ax2`라는 이름의 두 번째 축에 '이 세로축이 무엇을 나타내는 값인지' 이름을 달아줄 때 사용합니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
코드 안에서 함수에 전달된 값은 하나입니다.

* **`'F1-Score'` (문자열, str)**
  * **역할:** Y축의 이름표로 화면에 띄울 텍스트를 지정합니다.
  * **설정된 값의 의미:** 기계학습(Machine Learning) 분류 모델의 성능 평가 지표 중 하나인 **'F1-Score'**를 Y축 레이블로 지정하겠다는 뜻입니다. 이 코드를 실행하면 `ax2` 그래프의 세로축 왼쪽에 'F1-Score'라는 글자가 예쁘게 표시됩니다.

---

### 3. 📤 반환값/할당 변수
* **반환값:** 이 함수는 별도의 새로운 데이터를 돌려주는 것이 아니라, **자기 자신(축 객체)**의 설정을 직접 바꾼 뒤 **Text 객체(축 이름 레이블의 텍스트 정보)**를 반환합니다.
* **할당 변수:** 위 코드에서는 반환값을 따로 변수에 저장(`label = ax2.set_ylabel(...)`)하지 않고, 설정 기능만 곧바로 실행하고 버리는(Discard) 방식을 사용했습니다. 그래프를 그릴 때 라벨은 보통 설정 후 수정할 일이 잘 없기 때문에 이렇게 단독으로 자주 사용합니다.

---

### 4. 🎁 요약 및 실행 예시
초보자분들이 복사해서 바로 실행해 볼 수 있는 가장 간단한 예제 코드입니다. 

**[실행 코드]**
```python
import matplotlib.pyplot as plt

# 1. 도화지와 2개의 그래프 축(Subplot) 만들기
fig, ax1 = plt.subplots()

# 2. ax1과 x축을 공유하는 두 번째 축(ax2) 만들기
ax2 = ax1.twinx()

# 3. ax2의 Y축 이름 설정하기 (오늘 배운 핵심 함수!)
ax2.set_ylabel('F1-Score')

# 4. 그래프 화면에 띄우기
plt.show()
```

**[예상 결과]**
* 화면에 빈 그래프 창이 나타납니다.
* 오른쪽(또는 왼쪽) 세로축 근처에 **`F1-Score`**라는 이름표가 깔끔하게 적혀 있는 것을 확인할 수 있습니다.

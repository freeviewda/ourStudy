### 1. 📌 함수 개요
`pivot_table`은 엑셀의 '피벗 테이블' 기능과 정확히 똑같은 역할을 하는 함수입니다. 커다란 표(데이터프레임)에서 **특정 기준(행과 열)에 따라 데이터를 보기 쉽게 요약·재배치**하여 새로운 표를 만들어 줍니다.

---

### 2. 🔍 입력 인자(매개변수) 분석
제시해주신 코드에서는 총 3개의 인자가 사용되었습니다. 하나씩 뜯어볼까요?

*   **`values='Search Time'`**
    *   **역할:** 표의 **알맹이(값)**로 채워넣을 데이터를 지정합니다.
    *   **의미:** 요약된 표 안에는 각 모델과 방법별 '검색 시간(Search Time)' 데이터가 들어가게 됩니다.
*   **`index='Model'`**
    *   **역할:** 새로운 표의 **행(Row, 가로줄)** 기준이 될 열을 지정합니다.
    *   **의미:** 표의 가장 왼쪽에 행 이름으로 '모델(Model)' 이름들이 쭈르륵 나열됩니다. (예: GPT-4, BERT 등)
*   **`columns='Method'`**
    *   **역할:** 새로운 표의 **열(Column, 세로줄)** 기준이 될 열을 지정합니다.
    *   **의미:** 표의 맨 위에 컬럼 이름으로 '방법(Method)' 이름들이 쭈르륵 나열됩니다. (예: Fine-tuning, Prompting 등)

---

### 3. 📤 반환값/할당 변수 (`pivot_time`)
*   **반환되는 데이터:** 원본 데이터(`summary_df`)에서 'Method'가 'Baseline'이 아닌 데이터들만 골라낸 뒤, **`Model`을 행으로, `Method`를 열로 하고 `Search Time`을 값으로 채워 넣은 새로운 2차원 표(DataFrame)**가 반환됩니다.
*   **`pivot_time` 변수:** 그 결과 만들어진 요약 표가 `pivot_time`이라는 이름의 변수에 쏙 담깁니다. 이제 이 변수를 이용해 표를 출력하거나 시각화를 할 수 있습니다.

---

### 4. 🎁 요약 및 실행 예시 (초보자용 실습)

백문이 불여일견! 가상의 데이터를 가지고 직접 실행되는 모습을 살펴볼까요?

#### 💻 파이썬 실습 코드
```python
import pandas as pd

# 1. 가상의 원본 데이터(summary_df) 만들기
data = {
    'Model': ['Model_A', 'Model_A', 'Model_B', 'Model_B'],
    'Method': ['Baseline', 'FastSearch', 'Baseline', 'FastSearch'],
    'Search Time': [10.5, 2.1, 12.0, 1.5]
}
summary_df = pd.DataFrame(data)

print("--- [원본 데이터] ---")
print(summary_df)
print("\n" + "="*30 + "\n")

# 2. pivot_table 적용하기 (질문하신 바로 그 코드!)
# 'Baseline'을 제외하고, Model을 행, Method를 열로, Search Time을 값으로 배치
pivot_time = summary_df[summary_df['Method'] != 'Baseline'].pivot_table(
    values='Search Time', 
    index='Model', 
    columns='Method'
)

print("--- [pivot_time 결과] ---")
print(pivot_time)
```

#### 📊 예상 결과
```text
--- [원본 데이터] ---
     Model      Method  Search Time
0  Model_A    Baseline         10.5
1  Model_A  FastSearch          2.1
2  Model_B    Baseline         12.0
3  Model_B  FastSearch          1.5

==============================

--- [pivot_time 결과] ---
Method     FastSearch
Model                
Model_A           2.1
Model_B           1.5
```

> **💡 결과 해석:** 원본에 있던 'Baseline' 데이터는 싹 빠지고, `Model`이 행(세로)으로, `Method`의 'FastSearch'가 열(가로)로 가면서 교차하는 지점에 `Search Time` 값이 예쁘게 정리된 것을 볼 수 있습니다!
